## 📊 状态机流程

```
IDLE (等待选择)
  ↓ 用户点击[买入]
TRADING (交易执行中)
  ├─→ 30秒内检测到成交弹窗 → MONITORING
  └─→ 30秒无弹窗 → 撤单 → IDLE

MONITORING (持仓监控)
  ├─→ 价格>=止盈价 → 止盈结束 → IDLE
  ├─→ 价格<=止损价 → 止损结束 → IDLE
  └─→ 持仓超时 → 强平 → IDLE
```
