# 华泰证券可转债半自动交易助手 - 设计与使用文档

## 一、系统概述

### 1.1 设计目标
为量化交易系统提供一个**安全、合规、半自动**的交易辅助工具，实现：
- 接收量化信号，自动准备委托单
- **人工最终确认**，不自动提交
- 完整的交易时段、风控、日志管理

### 1.2 核心原则
| 原则 | 说明 |
|------|------|
| **不自动提交** | 系统只填充委托信息，最终点击由人工完成 |
| **不存储密码** | 交易密码不落地，由用户在华泰软件中输入 |
| **本地运行** | 所有操作仅在本地执行，不联网传输交易信息 |
| **风控保护** | 交易时段检查、金额限制、失败熔断等多重保护 |

## 三、详细流程说明

### 3.1 启动流程

```python
# 1. 用户启动服务
python scripts/huatai_trader/main.py

# 2. 服务初始化
- 加载 config.yaml 配置
- 初始化 HuaTaiTrader 实例
- 启动 Flask HTTP服务（端口8081）
- 等待量化系统调用
```

### 3.2 交易信号处理流程

以买入为例：

```
步骤1: 量化系统发送HTTP请求
─────────────────────────────
POST http://127.0.0.1:8081/api/prepare_buy
Content-Type: application/json

{
    "code": "123257",      // 债券代码（必填）
    "name": "美诺转债",    // 债券名称（可选）
    "price": 105.20,       // 委托价格（必填）
    "lots": 1              // 手数（可选，默认1手=10张）
}

步骤2: 风控检查（自动）
─────────────────────────────
□ 是否在交易时段？（09:30-11:30, 13:00-15:00）
□ 是否超过单日最大准备次数？（默认50次）
□ 单笔金额是否在限制范围内？（1000-100000元）
□ 价格是否在有效范围？（50-200元）
□ 同一债券是否间隔过短？（默认10秒）
□ 是否处于熔断状态？（连续3次失败会熔断5分钟）

→ 任一检查不通过，返回错误，不弹窗

步骤3: 确认弹窗（人工）
─────────────────────────────
┌─────────────────────────────────────┐
│  🔔 买入信号确认                      │
│                                     │
│  债券代码: 123257                    │
│  债券名称: 美诺转债                   │
│  委托价格: 105.2 元                  │
│  委托数量: 1手 (10张)               │
│  预估金额: 1052.00 元               │
│                                     │
│  点击"准备委托"将自动填充华泰软件     │
│                                     │
│  自动关闭倒计时: 25秒                │
│                                     │
│  [准备委托]    [忽略]               │
└─────────────────────────────────────┘

→ 用户点击"准备委托"：继续执行
→ 用户点击"忽略"或超时：取消，返回错误

步骤4: 窗口操作（自动）
─────────────────────────────
1. 检查华泰软件是否运行，未运行则启动
2. 激活华泰主窗口
3. 切换到"买入"界面（通过菜单或快捷键）
4. 填充表单：
   - 证券代码: 123257
   - 数量: 10（张）
   - 价格: 105.20
5. 播放提示音
6. 高亮提示"请确认"

步骤5: 人工最终确认
─────────────────────────────
用户在华泰软件界面查看填充的信息
确认无误后，人工点击"买入"按钮提交订单

步骤6: 结果返回
─────────────────────────────
HTTP返回结果：
{
    "success": true,
    "message": "买入委托已准备: 美诺转债(123257) 1手 @ 105.2元，请确认提交",
    "data": {
        "code": "123257",
        "name": "美诺转债",
        "price": 105.20,
        "lots": 1,
        "quantity": 10,
        "amount": 1052.00,
        "side": "buy"
    }
}
```

### 3.3 卖出流程

与买入流程相同，只是：
- API端点: `POST /api/prepare_sell`
- 弹窗标题: "卖出信号确认"
- 填充的是卖出界面

## 四、API接口文档

### 4.1 买入准备

```
POST /api/prepare_buy
准备买入委托单

请求参数:
{
    "code": "123257",      // string, 必填, 债券代码
    "name": "美诺转债",    // string, 可选, 债券名称
    "price": 105.20,       // float, 必填, 委托价格
    "lots": 1              // int, 可选, 手数, 默认1
}

响应成功:
{
    "success": true,
    "message": "买入委托已准备...",
    "data": {
        "code": "123257",
        "name": "美诺转债",
        "price": 105.20,
        "lots": 1,
        "quantity": 10,
        "amount": 1052.00,
        "side": "buy"
    }
}

响应失败:
{
    "success": false,
    "error": "风控拦截: 当前非交易时段: 午间休市"
}
```

### 4.2 卖出准备

```
POST /api/prepare_sell
准备卖出委托单

请求参数: 同 prepare_buy
响应格式: 同 prepare_buy
```

### 4.3 状态查询

```
GET /api/status
获取当前服务状态

响应:
{
    "success": true,
    "data": {
        "connected": true,              // 是否已连接华泰软件
        "trading_status": "交易中",      // 当前时段状态
        "is_trading_time": true,        // 是否在交易时段
        "daily_preparations": 5,        // 今日已准备次数
        "daily_amount": 5260.00,        // 今日已准备金额
        "consecutive_failures": 0,      // 连续失败次数
        "is_fuse_tripped": false        // 是否熔断
    }
}
```

### 4.4 连接软件

```
POST /api/connect
手动连接或启动华泰软件

响应:
{
    "success": true,
    "message": "已连接到华泰交易软件"
}
```

```python

# 买入信号
def on_buy_signal(bond_code, bond_name, price):
    response = requests.post(
        'http://127.0.0.1:8081/api/prepare_buy',
        json={
            'code': bond_code,
            'name': bond_name,
            'price': price,
            'lots': 1
        }
    )
    result = response.json()
    if result['success']:
        print(f"买入准备成功: {result['message']}")

        print(f"买入准备失败: {result['error']}")
```

### 6.4 人工操作流程

1. **保持服务运行**：在后台运行 `main.py`
2. **保持华泰软件登录**：首次需要手动登录，保持会话

5. **忽略信号**：点击"忽略"或等待30秒超时

## 七、风控机制详解

### 7.1 交易时段控制
- **允许时段**：09:30-11:30, 13:00-15:00
- **非时段请求**：直接拒绝，返回错误

### 7.2 单日限额
- **最大准备次数**：默认50次（买入+卖出合计）
- **累计金额追踪**：记录当日已准备的金额总和

### 7.3 单笔限制
- **金额范围**：1000-100000元
- **价格范围**：50-200元（防止输错价格）

### 7.4 熔断机制
- **触发条件**：连续3次准备失败（窗口操作异常等）
- **冷却时间**：5分钟
- **自动恢复**：冷却后自动重置失败计数

### 7.5 重复触发保护
- **同一债券间隔**：10秒内不重复准备
- **防止误触发**：避免信号抖动导致重复弹窗

## 九、注意事项与限制

### 9.1 当前限制
1. **控件识别**：使用Tab键切换填充，依赖界面布局稳定
2. **单账户**：暂不支持多账户切换
3. **分辨率**：弹窗位置基于屏幕分辨率计算
4. **华泰版本**：不同版本控件名称可能不同，需要适配

### 9.2 需要人工处理的情况
1. **华泰软件未启动**：系统会尝试启动，但首次登录需人工输入密码
2. **网络异常**：连接超时需要人工检查网络
3. **窗口被遮挡**：需要确保华泰窗口可见
4. **价格变动**：填充的是信号触发时的价格，实际成交需人工确认

### 9.3 安全提醒
- ⚠️ 本系统**不保证盈利**，交易风险自负
- ⚠️ 请确保华泰软件版本与配置匹配
- ⚠️ 建议先用模拟盘测试后再实盘
- ⚠️ 保持服务运行期间不要关闭华泰软件
