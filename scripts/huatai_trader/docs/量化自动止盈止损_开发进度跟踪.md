## 当前系统状态

### 可运行组件

```bash
# 启动服务
cd scripts/huatai_trader
python main.py

# 访问面板
http://127.0.0.1:8081/api/auto_trade/panel
```

### API端点

| 端点 | 方法 | 说明 |
|------|------|------|
| /api/auto_trade/status | GET | 获取状态 |
| /api/auto_trade/buy/<code> | POST | 触发买入 |
| /api/auto_trade/cancel | POST | 取消当前交易 |
| /api/auto_trade/skip | POST | 跳过当前信号 |
| /api/auto_trade/panel | GET | Web面板 |

### 配置项 (config.yaml)

```yaml
auto_trader:
  enabled: true
  signal_expire_seconds: 30
  fill_timeout_seconds: 30
  popup_poll_ms: 100
  max_hold_minutes: 30
  sounds:
    enabled: true
```
