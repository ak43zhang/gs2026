# 弹窗监测详细说明

## 监测目标

在华泰交易软件(xiadan.exe)中，当用户点击"买入"按钮后，系统会弹出**成交回报窗口**，我们需要检测这个窗口来判断是否成交成功。

## 需要监测的信息

### 1. 窗口标识
```
窗口标题: 包含"成交"、"委托回报"、"成交回报"等关键词
窗口类名: 可能是 "#32770" (标准对话框) 或自定义类名
父进程:  xiadan.exe
```

### 2. 窗口内容
```
需要读取窗口内的文本，确认:
- 是否包含证券代码 (如 127045)
- 是否包含"成交"字样
- 成交数量、价格信息
```

### 3. 出现时机
```
用户在华泰点击[买入] → 0.5~2秒 → 弹窗出现
弹窗停留时间: 约3~5秒 (自动关闭或点击关闭)
```

## 注意事项

1. **弹窗可能不出现的情况**:
   - 委托未成交（价格不合适）
   - 网络延迟
   - 系统设置关闭了成交提示

2. **误判风险**:
   - 其他软件的"成交"窗口
   - 历史成交记录窗口
   - 需要结合证券代码匹配

3. **性能考虑**:
   - 检测频率: 100ms一次
   - 超时时间: 30秒
   - CPU占用: <1%
