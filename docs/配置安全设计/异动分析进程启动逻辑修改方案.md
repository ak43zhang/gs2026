# 盘中异动分析进程启动逻辑分析与修改方案

## 当前逻辑分析

### anomaly_analyzer.py（Phase 1：基础分析）

**查询条件**（`_query_pending` 函数，第83行）：
```sql
WHERE trading_date = :today  -- 硬编码为 date.today()
  AND (ai_status = 'pending' 
       OR (ai_status = 'failed' AND retry_count < 3))
ORDER BY anomaly_time ASC
```

**结论**：只分析**当天**的 pending/failed 记录。

### anomaly_correlator.py（Phase 2：主线归类）

**查询条件**（`_query_analyzed` 函数，第55行）：
```sql
WHERE trading_date = :today  -- 硬编码为 date.today()
  AND ai_status = 'analyzed'
ORDER BY anomaly_time ASC
```

**结论**：只归类**当天**的 analyzed 记录。

### 停止条件

两个进程都是：无数据 + 时间 >= 17:00 时自动停止。

---

## 问题

1. **只能分析当天数据**：`trading_date = date.today()` 硬编码
2. **无法分析历史日期**：如果某天异动未分析完，第二天就无法继续
3. **启动方式单一**：只有 `main_loop()` 一种模式

---

## 修改方案

### 方案概述

添加命令行参数支持，默认分析当天，可指定日期分析历史数据：

```bash
# 默认：分析当天实时数据（当前行为不变）
python -m gs2026.analysis.worker.realtime.anomaly_analyzer

# 指定日期：分析指定交易日未分析的数据
python -m gs2026.analysis.worker.realtime.anomaly_analyzer --date 2026-06-26

# correlator 同理
python -m gs2026.analysis.worker.realtime.anomaly_correlator --date 2026-06-26
```

```python
import argparse

def _query_pending(engine, limit: int = 1, target_date: str = None) -> list:
    """查询待分析的异动记录"""
    if target_date is None:
        target_date = date.today().strftime('%Y-%m-%d')
    
    sql = text("""
        SELECT id, trading_date, stock_code, stock_name, anomaly_type, 
               anomaly_time, price, change_pct, continuous_zt,
               related_industries, related_concepts, pre_forecast_messages,
               retry_count
        FROM stock_anomaly 
        WHERE trading_date = :target_date
          AND (ai_status = 'pending' 
               OR (ai_status = 'failed' AND IFNULL(retry_count, 0) < :max_retry)) 
        ORDER BY anomaly_time ASC, created_at ASC
        LIMIT :limit
    """)
    with engine.connect() as conn:
        result = conn.execute(sql, {'target_date': target_date, 'limit': limit, 'max_retry': MAX_RETRY_COUNT})
        columns = list(result.keys())
        rows = result.fetchall()
    return [dict(zip(columns, row)) for row in rows]


def main_loop(target_date: str = None):
    """主循环
    
    Args:
        target_date: 目标日期，None=当天实时模式，指定日期=历史补分析模式
    """
    global _should_exit
    
    is_realtime = target_date is None
    display_date = target_date or date.today().strftime('%Y-%m-%d')
    mode_str = "实时模式" if is_realtime else f"历史补分析模式({target_date})"
    
    logger.info(f"[异动分析] 启动 - {mode_str}")
    
    # ... 原有初始化逻辑 ...
    
    while not _should_exit:
        # 实时模式用当天日期，历史模式用指定日期
        query_date = target_date if target_date else date.today().strftime('%Y-%m-%d')
        pending = _query_pending(engine, limit=5, target_date=query_date)
        
        if pending:
            # ... 原有分析逻辑 ...
            pass
        else:
            # 停止条件：
            # - 实时模式：无数据且 >= 17:00
            # - 历史模式：无数据则直接停止（所有记录已分析完）
            if not is_realtime:
                logger.info(f"[异动分析] 历史模式: {target_date} 所有记录已分析完毕")
                break
            elif _should_stop(datetime.now(), False):
                logger.info(f"[异动分析] 无数据且 >= 17:00，自动停止")
                break
        
        time.sleep(3)


if __name__ == '__main__':
    parser = argparse.ArgumentParser(description='盘中异动AI分析')
    parser.add_argument('--date', type=str, default=None,
                        help='指定分析日期(YYYY-MM-DD)，不指定则分析当天实时数据')
    args = parser.parse_args()
    
    main_loop(target_date=args.date)
```

---

## 行为对比

| 特性 | 实时模式（默认） | 历史模式（--date） |
|------|------------------|-------------------|
| 查询日期 | `date.today()` | 指定日期 |
| 停止条件 | 无数据 + >= 17:00 | 无数据即停止 |
| 自动刷新 | 持续轮询 | 分析完即退出 |
| 适用场景 | 盘中实时 | 补分析历史数据 |
