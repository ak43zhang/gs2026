# 极简敏感配置加密方案

## 方案概述

**核心思路**：敏感配置本地明文使用，加密后提交 GitHub，自动解密，兼顾安全与方便。

**一句话概括**：敏感配置存 `secrets.yaml`，一键加密成 `secrets.yaml.enc` 提交 GitHub，代码运行时自动解密使用。

---

## 文件结构

```
configs/
├── settings.yaml              # 普通配置（提交 GitHub）
├── secrets.yaml.enc           # 敏感配置（加密后提交 GitHub）✅
├── secrets.yaml               # 敏感配置（本地明文，不提交）❌
└── .secrets_key               # 加密密钥（本地保存，不提交）❌
```

---

## 核心优势

| 特性 | 说明 |
|------|------|
| **简单** | 只加一个文件 + 一个脚本 |
| **方便** | 代码使用方式完全不变 |
| **安全** | GitHub 上是加密内容，无法直接读取 |
| **防丢失** | 加密文件在 GitHub，密钥自己备份 |
| **自动** | 运行代码时自动解密，无感知 |

## 技术实现

### 1. 加密脚本（encrypt_secrets.py）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
敏感配置加密工具
用法:
    python encrypt_secrets.py          # 加密
    python encrypt_secrets.py decrypt  # 解密
"""

from cryptography.fernet import Fernet
import getpass
import os
import sys


def get_password():
    """获取加密密码"""
    # 优先从环境变量读取
    pwd = os.getenv('SECRETS_PWD')
    if pwd:
        return pwd
    # 否则交互式输入
    return getpass.getpass('请输入加密密码: ')


def generate_key_from_password(password: str) -> bytes:
    """从密码生成加密密钥"""
    import hashlib
    import base64
    # 使用 SHA-256 哈希，然后 Base64 编码为 32 字节密钥
    key = hashlib.sha256(password.encode()).digest()
    return base64.urlsafe_b64encode(key)


def encrypt():
    """加密敏感配置文件"""
    password = get_password()
    key = generate_key_from_password(password)
    
    # 读取明文配置
    secrets_file = 'configs/secrets.yaml'
    if not os.path.exists(secrets_file):
        print(f'❌ 文件不存在: {secrets_file}')
        print('请先创建 configs/secrets.yaml 并写入敏感配置')
        return
    
    with open(secrets_file, 'rb') as f:
        data = f.read()
    
    # 加密
    f = Fernet(key)
    encrypted = f.encrypt(data)
    
    # 保存加密文件
    enc_file = 'configs/secrets.yaml.enc'
    with open(enc_file, 'wb') as f:
        f.write(encrypted)
    
    # 保存密钥（用于自动解密）
    key_file = '.secrets_key'
    with open(key_file, 'wb') as f:
        f.write(key)
    
    print(f'✅ 加密成功: {enc_file}')
    print(f'✅ 密钥保存: {key_file}')
    print('')
    print('下一步操作:')
    print(f'  1. 提交加密文件: git add {enc_file}')
    print(f'  2. 确保不提交明文: git add .gitignore')
    print(f'  3. 备份密钥文件: 复制 {key_file} 到安全位置（U盘/邮箱）')


def decrypt():
    """解密敏感配置文件"""
    key_file = '.secrets_key'
    enc_file = 'configs/secrets.yaml.enc'
    secrets_file = 'configs/secrets.yaml'
    
    if not os.path.exists(key_file):
        print(f'❌ 密钥文件不存在: {key_file}')
        print('请从备份恢复密钥文件')
        return
    
    if not os.path.exists(enc_file):
        print(f'❌ 加密文件不存在: {enc_file}')
        return
    
    # 读取密钥
    with open(key_file, 'rb') as f:
        key = f.read()
    
    # 读取加密文件
    with open(enc_file, 'rb') as f:
        encrypted = f.read()
    
    # 解密
    f = Fernet(key)
    try:
        data = f.decrypt(encrypted)
    except Exception as e:
        print(f'❌ 解密失败，密钥可能不正确: {e}')
        return
    
    # 保存明文
    with open(secrets_file, 'wb') as f:
        f.write(data)
    
    print(f'✅ 解密成功: {secrets_file}')


if __name__ == '__main__':
    if len(sys.argv) > 1 and sys.argv[1] == 'decrypt':
        decrypt()
    else:
        encrypt()
```

### 2. 配置加载修改（config_util.py）

```python
# 在原有 config_util.py 中添加以下代码

import os
from pathlib import Path
from cryptography.fernet import Fernet


def _load_encrypted_secrets():
    """
    加载加密的敏感配置文件
    自动解密，无感知使用
    """
    base_path = Path(__file__).parent.parent.parent.parent / "configs"
    
    secrets_file = base_path / "secrets.yaml"
    enc_file = base_path / "secrets.yaml.enc"
    key_file = Path(__file__).parent.parent.parent.parent / ".secrets_key"
    
    # 明文存在直接读取
    if secrets_file.exists():
        import yaml
        with open(secrets_file, 'r', encoding='utf-8') as f:
            return yaml.safe_load(f) or {}
    
    # 明文不存在，尝试解密
    if enc_file.exists() and key_file.exists():
        try:
            # 读取密钥
            with open(key_file, 'rb') as f:
                key = f.read()
            
            # 读取加密文件
            with open(enc_file, 'rb') as f:
                encrypted = f.read()
            
            # 解密
            f = Fernet(key)
            data = f.decrypt(encrypted)
            
            # 保存明文供后续使用
            with open(secrets_file, 'wb') as f:
                f.write(data)
            
            # 解析 YAML
            import yaml
            return yaml.safe_load(data) or {}
            
        except Exception as e:
            print(f'[Config] 解密失败: {e}')
            print('[Config] 请确保 .secrets_key 文件存在且正确')
            return {}
    
    # 都没有，返回空
    return {}


# 在原有配置加载后，合并敏感配置
_secrets = _load_encrypted_secrets()

# 合并配置（secrets 覆盖普通配置）
if _secrets:
    # 深度合并
    def deep_merge(base, override):
        for key, value in override.items():
            if key in base and isinstance(base[key], dict) and isinstance(value, dict):
                deep_merge(base[key], value)
            else:
                base[key] = value
        return base
    
    cfg = deep_merge(cfg, _secrets)
```

## 备份与恢复

### 密钥备份（重要！）

```bash
# 方式1：复制到 U 盘
cp .secrets_key /mnt/u盘/gs2026-secrets-key.backup

# 方式2：发送到邮箱（加密压缩）
zip -e secrets-key.zip .secrets_key
# 输入解压密码
mutt -s "GS2026 密钥备份" your-email@example.com -a secrets-key.zip

# 方式3：网盘（加密后上传）
gpg -c .secrets_key  # 生成 .secrets_key.gpg
mv .secrets_key.gpg ~/Dropbox/gs2026/
```

### 密钥恢复

```bash
# 从备份复制
cp /mnt/u盘/gs2026-secrets-key.backup ./.secrets_key

# 运行代码自动解密
python your_script.py
```

## 常见问题

### Q1: 忘记加密密码怎么办？
**A**: 无法恢复。需要重新创建 secrets.yaml，重新加密，重新备份密钥。

### Q2: 密钥文件丢失怎么办？
**A**: 从备份恢复。如果没有备份，同上，重新创建。

### Q3: 多人协作怎么办？
**A**: 
- 方案A：共享密钥（通过安全渠道分享 .secrets_key）
- 方案B：各自维护本地 secrets.yaml（不提交加密文件）
- 方案C：使用环境变量覆盖（服务器部署推荐）

### Q4: 如何更新敏感配置？
**A**:
```bash
# 1. 修改 configs/secrets.yaml
vim configs/secrets.yaml

# 2. 重新加密
python encrypt_secrets.py

# 3. 提交
 git add configs/secrets.yaml.enc
git commit -m "更新火山 API 密钥"
```

## 安全建议

1. **加密密码**：使用强密码（12位以上，含大小写+数字+符号）
2. **密钥备份**：至少2份备份，存放在不同位置
3. **定期轮换**：API 密钥建议每3-6个月更换
4. **权限控制**：服务器上的 .secrets_key 设置 600 权限
5. **环境隔离**：生产环境使用独立密钥
