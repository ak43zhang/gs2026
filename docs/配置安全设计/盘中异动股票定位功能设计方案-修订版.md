# 盘中异动股票快速定位功能设计方案（修订版）

## 核心思路

**不是查询新数据，而是过滤现有数据**

```
输入股票代码/名称
    │
    ├─→ 从当前已加载的异动列表中过滤出该股票
    │
    ├─→ 从当前已加载的市场主线中筛选包含该股票的主线
    │
    ├─→ 从当前已加载的最强标的中筛选属于这些主线的标的
    │
    └─→ 从当前已加载的可转债中筛选属于这些主线的可转债
```

## 数据流设计

```javascript
// 1. 页面正常加载时，获取全量数据
let _allData = {
    anomalies: [],      // 所有异动
    mainlines: [],      // 所有市场主线
    strongest: [],      // 所有最强标的
    bonds: []           // 所有可转债
};

// 2. 输入股票定位时，从_allData中过滤
function locateStock(query) {
    const stock = findStockByCodeOrName(query);  // 匹配股票
    
    // 过滤异动列表
    const filteredAnomalies = _allData.anomalies.filter(
        a => a.stock_code === stock.code
    );
    
    // 筛选包含该股票的主线
    const relatedMainlines = _allData.mainlines.filter(
        m => m.stocks.includes(stock.code)
    );
    const mainlineNames = relatedMainlines.map(m => m.name);
    
    // 筛选属于这些主线的最强标的
    const filteredStrongest = _allData.strongest.filter(
        s => mainlineNames.includes(s.mainline)
    );
    
    // 筛选属于这些主线的可转债
    const filteredBonds = _allData.bonds.filter(
        b => mainlineNames.includes(b.mainline)
    );
    
    // 渲染过滤后的数据
    renderFilteredData({
        stock: stock,
        anomalies: filteredAnomalies,
        mainlines: relatedMainlines,
        strongest: filteredStrongest,
        bonds: filteredBonds
    });
}

// 3. 清除定位，恢复全量显示
function clearLocate() {
    renderAllData(_allData);
}
```

## 股票匹配逻辑

```javascript
function findStockByCodeOrName(query) {
    query = query.trim();
    
    // 6位数字 = 按代码匹配
    if (/^\d{6}$/.test(query)) {
        return _allStocks.find(s => s.code === query);
    }
    
    // 其他 = 按名称模糊匹配
    return _allStocks.find(s => s.name.includes(query));
}
```
