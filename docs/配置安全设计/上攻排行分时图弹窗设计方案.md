# 数据监控 - 上攻排行分时图弹窗设计方案

## 需求

点击股票上攻排行/债券上攻排行中的某条数据 → 弹窗展示分时图
- 股票排行：显示正股分时图，如有转债则同时展示
- 债券排行：显示转债分时图 + 正股分时图

## 现有资源

- **API**: `/api/monitor/chart-data/<bond_code>/<stock_code>?date=YYYYMMDD`
  - 返回 `{bond: [{time, price, change_pct}], stock: [{time, price, change_pct}]}`
- **联动信号**: 点击跳转到 `/chart/<bond_code>/<stock_code>?date=YYYYMMDD` 新页面
- **ECharts**: 页面已引入（用于其他图表）

## 设计方案

### 2. 点击事件

在 `renderRanking` 中给每行 `<tr>` 添加 `onclick`：

```javascript
// 股票排行：点击行显示分时图
if (isStockRanking) {
```

### 3. 弹窗逻辑

```javascript
async function showChartModal(stockCode, bondCode, name) {
    // 显示弹窗
    document.getElementById('chart-modal').style.display = 'flex';
    document.getElementById('chart-modal-title').textContent = name + ' 分时图';
    
    // 获取数据
    const date = getCurrentDate();
    const bc = bondCode || 'none';
    const url = `/api/monitor/chart-data/${bc}/${stockCode}?date=${date}`;
    const r = await fetch(url).then(r => r.json());
    
    if (r.success) {
        // 渲染正股分时图
        renderTimeChart('chart-stock', r.data.stock, stockCode + ' 正股');
        
        // 如有转债，渲染转债分时图
        if (bondCode && r.data.bond && r.data.bond.length > 0) {
            document.getElementById('chart-bond').style.display = 'block';
            renderTimeChart('chart-bond', r.data.bond, bondCode + ' 转债');
        } else {
            document.getElementById('chart-bond').style.display = 'none';
        }
    }
}

function closeChartModal() {
    document.getElementById('chart-modal').style.display = 'none';
}

function renderTimeChart(containerId, data, title) {
    const chart = echarts.init(document.getElementById(containerId));
    const times = data.map(d => d.time);
    const prices = data.map(d => d.price);
    const pcts = data.map(d => d.change_pct);
    
    chart.setOption({
        title: { text: title, textStyle: { fontSize: 13 } },
        tooltip: { trigger: 'axis' },
        xAxis: { type: 'category', data: times },
        yAxis: { type: 'value', scale: true },
        series: [{ type: 'line', data: prices, smooth: true, lineStyle: { width: 1.5 } }],
        grid: { top: 30, bottom: 25, left: 50, right: 15 }
    });
}
```
