# 分时图弹窗修复方案

## 问题分析

### 1. 当前 Bug

**股票排行点击（有转债）：**
```javascript
const chartBondCode = item.bond_code && item.bond_code !== '-' ? item.bond_code : '';
// 结果: '' (空字符串)
```

**债券排行点击：**
```javascript
const chartBondCode = code;  // 债券代码
const chartStockCode = item.stock_code || 'none';
// 结果: stock_code 可能为 null
```

### 2. 后端 API 参数处理

后端 `get_chart_data(bond_code, stock_code, date)`：
- `bond_code=''` → 空字符串，不会触发反查
- `stock_code='none'` → 会尝试反查

### 3. 前端 showChartModal 逻辑

```javascript
const bc = bondCode || 'none';  // '' → 'none'
```

## 修复方案

### 方案 A: 修复前端点击事件

**股票排行点击：**
```javascript
// 修改前
const chartBondCode = isStockRanking ? (item.bond_code && item.bond_code !== '-' ? item.bond_code : '') : code;

// 修改后  
const chartBondCode = isStockRanking ? (item.bond_code && item.bond_code !== '-' ? item.bond_code : 'none') : code;
```

**债券排行点击：**
```javascript
// 修改前
const chartStockCode = isStockRanking ? code : (item.stock_code || 'none');

// 修改后（确保有正股代码）
const chartStockCode = isStockRanking ? code : (item.stock_code || '');
// 后端会反查
```

### 方案 B: 修复前端弹窗布局

**当前问题：**
- 无转债时隐藏 `cell-bond` 区域
- 导致布局变化

**修复后：**
- 四个位置固定
- 无数据时显示"暂无数据"或空白
- 不隐藏任何区域

```javascript
// 修改前
if (bondCode && bondCode !== 'none' && r.data.bond && r.data.bond.length > 0) {
    // 显示转债
} else {
    cellBond.style.display = 'none';  // 隐藏
    grid.classList.add('no-bond');
}

// 修改后
if (r.data.bond && r.data.bond.length > 0) {
    // 显示转债数据
} else {
    // 显示空白或"暂无转债"
    bondEl.innerHTML = '<div style="text-align:center;padding:70px 0;color:#aaa;font-size:12px;">暂无转债</div>';
}
// 不隐藏 cellBond
```

### 方案 C: 确保大盘和行业始终显示

当前后端逻辑：
- 只要有 `stock_code`，就会查询大盘和行业
- 即使 `stock_code='none'`，只要 `bond_code` 有值，会反查正股

需要确保：**债券排行点击时，也能显示大盘和行业**

当前债券排行点击传递：
- `stockCode = item.stock_code || 'none'`  
- 如果 `stock_code` 为 null，传递 'none'

后端处理 'none'：
- 不会触发反查（因为 `if not stock_code and bond_code`）
- 但大盘和行业查询在反查之后

**修复：** 无论是否有正股代码，都查询大盘和行业

4. **测试验证**
