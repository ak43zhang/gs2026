# 龙头股识别最终方案（基于现有表扩展）

## 当前现状分析

### 现有4个表

| 表名 | 用途 | 关键字段 |
|------|------|---------|
| **stock_anomaly** | 原始异动数据 | id, stock_code, anomaly_time, continuous_zt, mainline_names, ai_analysis |
| **stock_anomaly_mainline** | 市场主线表 | mainline_id, mainline_name, related_stocks, stock_count |
| **stock_anomaly_mainline_rel** | 股票-主线关系 | anomaly_id, mainline_id, **role**(龙头/跟风/补涨), evidence |
| **stock_anomaly_potential** | 潜在标的 | stock_code, rank_num, mainlines |

### 当前问题诊断

**问题1：主线多个涨停没有龙头识别**
- `stock_anomaly_mainline_rel.role` 已有龙头/跟风/补涨字段
- 但当前role可能是**单只股票独立分析**，非**同主线横向比较**
- 结果：32只AI应用涨停，role分布可能不合理（真正的龙头未被识别）

**问题2：表过度设计**
- 已有4个表，功能分散
- 龙头识别逻辑分散在 `mainline_rel.role` 和 `mainline.related_stocks`

## 最终方案：基于现有表扩展

```python
class LeaderAnalyzerV2:
    """龙头分析器V2（同主线横向比较）"""
    
    def analyze_mainline(self, mainline_name: str, date: str):
        """分析单个主线的龙头"""
        # 1. 获取该主线所有涨停股票
        stocks = self.get_stocks_by_mainline(mainline_name, date)
        
        if len(stocks) < 2:
            logger.info(f"主线 {mainline_name} 只有 {len(stocks)} 只股票，无需比较")
            return
        
        # 2. 构建横向比较Prompt
        prompt = self.build_comparison_prompt(mainline_name, stocks)
        
        # 3. AI分析
        response = self.call_ai(prompt)
        
        # 4. 解析并更新
        analysis = json.loads(response)
        for stock in analysis:
            self.update_stock_anomaly(stock)
    
    def analyze_all_mainlines(self, date: str):
        """分析当日所有主线的龙头"""
        mainlines = self.get_mainlines_by_date(date)
        
        for mainline in mainlines:
            if mainline['stock_count'] >= 3:  # 至少3只才分析龙头
                self.analyze_mainline(mainline['mainline_name'], date)
```
