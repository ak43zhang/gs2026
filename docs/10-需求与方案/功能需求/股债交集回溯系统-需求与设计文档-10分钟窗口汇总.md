# 股债交集回溯 - 10分钟窗口汇总方案（v4 - 实施版）

**版本**: v4.0  
**日期**: 2026-08-04  
**状态**: 已审核，待实施  

---

## 一、背景与问题

### 1.1 当前系统痛点

当前股债交集回溯系统返回的是**逐tick明细数据**，存在以下问题：

| 痛点 | 说明 | 影响 |
|------|------|------|
| 数据量过大 | 全天约4800个tick，每个tick可能有多个命中对 | 页面卡顿，难以快速浏览 |
| 缺乏时间维度聚合 | 同一对在一个10分钟窗口内可能出现10+次 | 时间轴过长，难以识别趋势 |
| 缺少关键分析指标 | 无法直观看到从首次命中到最高涨幅的时间差和涨幅差 | 分析人员难以判断拉升速度和力度 |
| 无窗口级统计 | 无法快速了解某个10分钟窗口内的整体情况 | 难以定位关键时间段 |

### 1.2 设计目标

将明细数据按**10分钟时间窗口聚合汇总**，提供分析友好的展示方式，帮助分析人员：

1. **快速识别**哪些股债对在哪个时间段表现突出
2. **判断拉升速度**（时间差）和**力度**（涨幅差）
3. **评估持续性**（出现次数、连续性评分）
4. **定位关键窗口**（高命中数、高涨幅差窗口）

## 二、需求规格

### 2.1 功能需求

#### 2.1.1 窗口聚合（F001）

**需求描述**: 系统需将逐tick明细数据按10分钟窗口聚合。

**窗口定义**:
- **窗口大小**: 固定10分钟
- **窗口边界**: 09:30, 09:40, 09:50, 10:00, 10:10... 14:50, 15:00
- **窗口标识**: `09:30-09:40`, `09:40-09:50`, `14:20-14:30`...
- **聚合维度**: 按 **股票代码+债券代码** 唯一对聚合

**输入**: 逐tick股债交集明细数据
**输出**: 按窗口+股票债券对分组后的汇总数据

#### 2.1.2 汇总字段计算（F002）

**需求描述**: 为每个窗口内的每个股债对计算汇总指标。

**必需字段（11个）**:

| # | 字段名 | 类型 | 计算逻辑 | 业务含义 |
|---|--------|------|----------|----------|
| 1 | `window` | string | 窗口标识 | 定位时间段 |
| 2 | `stock_code_name` | string | code + name | 快速识别股票 |
| 3 | `bond_code_name` | string | code + name | 快速识别转债 |
| 4 | `industry_name` | string | 行业名称 | 行业维度分析 |
| 5 | `appear_count` | int | count(details) | **持续性指标** |
| 6 | `first_change_pct` | float | details[0].change_pct | 入场参考 |
| 7 | `max_change_pct` | float | max(details.change_pct) | 峰值参考 |
| 8 | `time_to_max_display` | string | format(max_time - first_time) | **速度指标** |
| 9 | `gain_to_max` | float | max_pct - first_pct | **力度指标** |
| 10 | `last_change_pct` | float | details[-1].change_pct | 离场参考 |
| 11 | `window_count_avg` | float | avg(details.window_count) | 强度指标 |

#### 2.1.3 派生指标计算（F003）

**需求描述**: 计算辅助分析指标。

| 字段名 | 类型 | 计算方式 | 分析意义 |
|--------|------|----------|----------|
| `time_to_max_seconds` | int | 秒数 | 用于排序和颜色判断 |
| `continuity_score` | float | appear_count / 窗口总tick数 | 连续度评分(0-1) |
| `min_change_pct` | float | min(details.change_pct) | 窗口内最低涨幅 |
| `avg_change_pct` | float | avg(details.change_pct) | 平均涨幅水平 |

#### 2.1.4 明细保留（F004）

**需求描述**: 汇总展示的同时保留完整明细，支持展开查看。

**明细字段（7个）**:

| # | 字段名 | 说明 |
|---|--------|------|
| 1 | `time` | 精确时间点 `14:23:15` |
| 2 | `change_pct` | 当时涨幅 `0.37%` |
| 3 | `window_count` | window_count `3` |
| 4 | `rank` | 当时排名 `5` |
| 5 | `main_net_amount` | 主力净额 `1250万` |
| 6 | `amount` | 成交金额 `2.5亿` |
| 7 | `mark` | 特殊标记 `首次/最高/最后` |

#### 2.1.5 窗口筛选（F005）

**需求描述**: 支持按10分钟窗口筛选数据。

**功能**:
- 横向滚动按钮组展示所有窗口
- 每个窗口显示命中对数角标
- 支持"全部"和单窗口切换

#### 2.1.6 排序功能（F006）

**需求描述**: 支持多维度排序。

**排序字段**:
- 窗口（默认升序）
- 首次时间（升序）
- 出现次数（降序）
- 时间差（升序/降序）
- 涨幅差（降序）

#### 2.1.7 展开/收起明细（F007）

**需求描述**: 点击汇总行展开查看明细。

**交互规则**:
- 点击行任意位置或"展开"按钮展开
- 一次只展开一行（其他自动收起）
- 展开后显示时间轴+明细表格

#### 2.1.8 时间轴展示（F008）

**需求描述**: 以时间轴形式展示明细关键点。

**展示模式**:
- **精简模式（默认）**: 只显示首次、最高、最后，中间用"..."省略
- **完整模式**: 显示所有时间点

**省略规则**:
- 出现次数 <= 5: 显示全部
- 出现次数 6-10: 显示首次、中间2个、最高、最后
- 出现次数 > 10: 显示首次、最高、最后，中间用...省略

#### 2.1.9 导出功能（F009）

**需求描述**: 支持导出当前筛选结果。

**导出格式**: CSV
**导出内容**: 汇总数据 + 明细数据（可选）

#### 2.1.10 统计面板（F010）

**需求描述**: 底部显示全局统计信息。

**统计指标**:
- 总窗口数
- 总命中对数
- 平均时间差
- 最大涨幅差

#### 3.1.2 聚合算法

```python
def aggregate_by_window(tick_data: List[Dict]) -> Dict:
    """
    将逐tick数据按10分钟窗口聚合
    
    Args:
        tick_data: 原始逐tick交集数据
        
    Returns:
        按窗口分组后的汇总数据
    """
    # 1. 确定窗口边界
    windows = generate_windows("09:30", "15:00", 10)  # 10分钟窗口
    
    # 2. 按窗口+股票债券对分组
    groups = defaultdict(list)
    for record in tick_data:
        window = get_window_for_time(record['time'], windows)
        pair_key = (record['stock_code'], record['bond_code'])
        groups[(window, pair_key)].append(record)
    
    # 3. 计算每个组的汇总指标
    result = []
    for (window, pair_key), details in groups.items():
        summary = calculate_summary(window, pair_key, details)
        result.append(summary)
    
    # 4. 按窗口排序
    return sort_by_window_and_time(result)

def calculate_summary(window, pair_key, details):
    """计算单个股债对在窗口内的汇总指标"""
    sorted_details = sorted(details, key=lambda x: x['time'])
    
    first = sorted_details[0]
    last = sorted_details[-1]
    max_record = max(sorted_details, key=lambda x: x['change_pct'])
    min_record = min(sorted_details, key=lambda x: x['change_pct'])
    
    time_to_max_seconds = time_diff(max_record['time'], first['time'])
    
    return {
        'window': window,
        'stock_code': pair_key[0],
        'stock_name': first['stock_name'],
        'bond_code': pair_key[1],
        'bond_name': first['bond_name'],
        'industry_name': first['industry_name'],
        
        'first_appear_time': first['time'],
        'first_change_pct': first['change_pct'],
        
        'max_change_time': max_record['time'],
        'max_change_pct': max_record['change_pct'],
        
        'last_appear_time': last['time'],
        'last_change_pct': last['change_pct'],
        
        'time_to_max_seconds': time_to_max_seconds,
        'time_to_max_display': format_duration(time_to_max_seconds),
        
        'gain_to_max': max_record['change_pct'] - first['change_pct'],
        'appear_count': len(sorted_details),
        'window_count_avg': sum(d['window_count'] for d in sorted_details) / len(sorted_details),
        'continuity_score': len(sorted_details) / get_window_tick_count(window),
        
        'min_change_pct': min_record['change_pct'],
        'avg_change_pct': sum(d['change_pct'] for d in sorted_details) / len(sorted_details),
        
        'details': mark_key_points(sorted_details)
    }

def mark_key_points(details):
    """标记关键点：首次、最高、最后"""
    sorted_details = sorted(details, key=lambda x: x['time'])
    max_idx = max(range(len(sorted_details)), key=lambda i: sorted_details[i]['change_pct'])
    
    for i, d in enumerate(sorted_details):
        marks = []
        if i == 0:
            marks.append('first')
        if i == max_idx:
            marks.append('max')
        if i == len(sorted_details) - 1:
            marks.append('last')
        d['mark'] = ','.join(marks) if marks else ''
    
    return sorted_details
```
