## 1. 需求概述

### 1.1 背景

当前系统中，股票上攻排行和债券上攻排行分别展示，用户需要手动对比才能发现股债联动机会。为提高效率，需要自动化回溯功能，遍历历史时间轴，自动筛选符合条件的股债组合并持久化存储。

### 1.2 目标

构建一个股债交集回溯系统，能够：
- 遍历指定日期的完整时间轴（tick 级别）
- 对股票和债券分别应用过滤条件
- 计算股债交集（有映射关系的股票-债券对）
- 将结果幂等保存到 MySQL
- 支持后续查询和分析

### 1.3 范围

**包含范围**:
- 时间轴遍历（tick 级别）
- 股票过滤管道（复用前端逻辑）
- 债券过滤管道（复用前端逻辑）
- 股债交集计算
- 结果持久化（MySQL）
- 查询 API

**不包含范围**:
- 实时流式计算
- 分布式并行处理
- 复杂关联规则（除 bond_code 外）

## 2. 术语定义

| 术语 | 定义 |
|------|------|
| **Tick** | 系统数据采集的最小时间粒度，通常为 3 秒（债券）或 5 秒（股票） |
| **时间轴** | 一个交易日内所有 tick 时间点的有序集合 |
| **过滤管道** | 由多个过滤器组成的链式处理结构，数据依次经过每个过滤器 |
| **股债交集** | 同时满足股票过滤条件和债券过滤条件的股票-债券对 |
| **幂等性** | 重复执行相同操作，结果一致，不会产生重复数据 |
| **过滤快照** | 执行回溯时的完整过滤配置，用于追溯和复现 |

### 3.2 详细需求

#### F001 时间轴遍历

**需求描述**: 系统需要能够遍历指定交易日的完整时间轴。

**输入**:
- 日期（YYYYMMDD）

**输出**:
- 时间列表（["09:30:00", "09:30:03", ..., "15:00:00"]）

**规则**:
- 只遍历 tick 级别时间点（根据实际存储的时间戳）
- 从 09:30:00 到 15:00:00（交易时间）
- 只遍历有数据的时间点（从 Redis 时间戳列表获取）

#### F002/F003 数据获取

**需求描述**: 获取指定时间点的股票/债券上攻排行数据。

**输入**:
- 日期（YYYYMMDD）
- 时间（HH:MM:SS）

**输出**:
- 股票/债券数据列表（使用现有 API）

#### F004/F005 过滤管道

**需求描述**: 复用前端过滤逻辑，在后端实现相同的过滤管道。

**股票过滤器**:
| 过滤器 | 类型 | 说明 |
|--------|------|------|
| industry | predicate | 行业筛选 |
| topn_sectors | predicate | 仅前N行业（次数） |
| topn_sectors_pct | predicate | 仅前N行业（涨幅） |
| topn_window | ranking | 仅前N区间次数 |
| topn_count | ranking | 仅前N累计次数 |
| bond_filter | predicate | 仅显示有债券的 |

**债券过滤器**:
| 过滤器 | 类型 | 说明 |
|--------|------|------|
| industry | predicate | 行业筛选 |
| topn_sectors | predicate | 仅前N行业（次数） |
| topn_sectors_pct | predicate | 仅前N行业（涨幅） |
| topn_amount | ranking | 仅前N金额 |
| topn_window | ranking | 仅前N区间次数 |
| topn_count | ranking | 仅前N累计次数 |
| green_list | predicate | 排除绿名单 |

**过滤管道执行逻辑**:
1. Phase 1: 谓词型过滤器串行执行，生成候选池 S
2. Phase 2: 排名型过滤器各自基于 S 计算，取交集

#### F006 交集计算

**需求描述**: 计算股票和债券的交集。

**关联规则**:
```
股票字段 bond_code == 债券字段 code
```

**交集结果**:
- 对于每只股票，如果其 bond_code 在过滤后的债券列表中，则形成一个股债对

#### F007 结果保存

**需求描述**: 将交集结果幂等保存到 MySQL。

**幂等保证**:
- 唯一索引: (trade_date, trade_time, stock_code, bond_code)
- 写入方式: INSERT ... ON DUPLICATE KEY UPDATE

#### F009 结果查询

**需求描述**: 支持多维度查询回溯结果。

**查询条件**:
- 日期范围
- 时间范围
- 股票代码
- 债券代码
- 行业

### 7.5 后端统一 Pipeline

```python
# src/gs2026/common/pipeline.py
# 统一过滤管道 - 唯一维护点

class UnifiedPipeline:
    """
    统一过滤管道
    
    所有过滤逻辑只在此实现，前后端共用。
    """
    
    def __init__(self, config: FilterConfig):
        self.config = config
        self.stock_pipeline = self._build_stock_pipeline()
        self.bond_pipeline = self._build_bond_pipeline()
    
    def filter_stocks(self, stocks: List[Dict]) -> List[Dict]:
        """过滤股票数据"""
        return self.stock_pipeline.execute(stocks)
    
    def filter_bonds(self, bonds: List[Dict]) -> List[Dict]:
        """过滤债券数据"""
        return self.bond_pipeline.execute(bonds)
    
    def _build_stock_pipeline(self) -> Pipeline:
        """构建股票过滤管道"""
        filters = []
        cfg = self.config.stock
        
        if cfg.industry:
            filters.append(IndustryFilter(cfg.industry))
        if cfg.topn_sectors:
            filters.append(TopNSectorsFilter(cfg.topn_sectors))
        if cfg.topn_sectors_pct:
            filters.append(TopNSectorsPctFilter(cfg.topn_sectors_pct))
        if cfg.topn_window:
            filters.append(TopNWindowFilter(cfg.topn_window))
        if cfg.topn_count:
            filters.append(TopNCountFilter(cfg.topn_count))
        if cfg.bond_filter:
            filters.append(BondExistsFilter())
        
        return Pipeline(filters)
    
    def _build_bond_pipeline(self) -> Pipeline:
        """构建债券过滤管道"""
        filters = []
        cfg = self.config.bond
        
        if cfg.industry:
            filters.append(IndustryFilter(cfg.industry))
```

### 7.3 StockFilter / BondFilter（过滤管道）

**职责**: 复用前端过滤逻辑，在后端实现相同的过滤管道。

**过滤管道执行逻辑**:

```python
class Pipeline:
    """过滤管道"""
    
    def __init__(self, filters: List[Filter]):
        self.filters = filters
    
    def execute(self, data: List[Dict]) -> List[Dict]:
        """
        执行过滤管道
        
        Phase 1: 谓词型过滤器串行执行
        Phase 2: 排名型过滤器各自计算后取交集
        """
        # Phase 1: 谓词型
        S = data
        for f in self.filters:
            if f.kind == 'predicate':
                S = f.apply(S)
        
        # Phase 2: 排名型
        ranking_sets = []
        for f in self.filters:
            if f.kind == 'ranking':
                subset = f.apply(S)
                ranking_sets.append(set(item['code'] for item in subset))
        
        # 取交集
        if ranking_sets:
            intersection = ranking_sets[0]
            for s in ranking_sets[1:]:
                intersection &= s
            S = [item for item in S if item['code'] in intersection]
        
        return S
```

**过滤器基类**:

```python
class Filter(ABC):
    """过滤器基类"""
    
    kind: str  # 'predicate' | 'ranking'
    
    @abstractmethod
    def apply(self, data: List[Dict]) -> List[Dict]:
        pass

class PredicateFilter(Filter):
    """谓词型过滤器基类"""
    kind = 'predicate'

class RankingFilter(Filter):
    """排名型过滤器基类"""
    kind = 'ranking'
    
    def __init__(self, n: int, field: str):
        self.n = n
        self.field = field
    
    def apply(self, data: List[Dict]) -> List[Dict]:
        """取前N（field > 0 的记录）"""
        sorted_data = sorted(
            [d for d in data if d.get(self.field, 0) > 0],
            key=lambda x: x.get(self.field, 0),
            reverse=True
        )
        return sorted_data[:self.n]
```

### 7.4 IntersectionCalculator（交集计算器）

**职责**: 计算股票和债券的交集。

**类设计**:

```python
@dataclass
class StockBondPair:
    """股债对"""
    stock: Dict  # 股票数据
    bond: Dict   # 债券数据

class IntersectionCalculator:
    """
    交集计算器
    
    关联规则: stock['bond_code'] == bond['code']
    """
    
    def calculate(self, stocks: List[Dict], 
                  bonds: List[Dict]) -> List[StockBondPair]:
        """
        计算股债交集
        
        Args:
            stocks: 过滤后的股票列表
            bonds: 过滤后的债券列表
        
        Returns:
            股债对列表
        """
        # 建立债券 code -> 债券数据的映射
        bond_map = {b['code']: b for b in bonds}
        
        intersections = []
        for stock in stocks:
            bond_code = stock.get('bond_code')
            if bond_code and bond_code in bond_map:
                intersections.append(StockBondPair(
                    stock=stock,
                    bond=bond_map[bond_code]
                ))
        
        return intersections
```

```python
class BacktraceRepository:
    """
    回溯结果仓库
    
    使用 INSERT ... ON DUPLICATE KEY UPDATE 实现幂等写入。
    """
    
    TABLE = "backtrace_stock_bond_intersection"
    
    def __init__(self, engine=None):
        self.engine = engine or create_engine(Config.MYSQL_URI)
    
    def save_batch(self, records: List[BacktraceRecord]) -> BacktraceResult:
        """
        批量幂等保存
        
        Args:
            records: 回溯记录列表
        
        Returns:
            保存结果统计
        """
        if not records:
            return BacktraceResult(count=0)
        
        # 构建 INSERT ... ON DUPLICATE KEY UPDATE 语句
        columns = [
            'trade_date', 'trade_time',
            'stock_code', 'stock_name', 'stock_change_pct', 'stock_price',
            'stock_count', 'stock_window_count', 'stock_industry', 'stock_main_net_amount',
            'bond_code', 'bond_name', 'bond_change_pct', 'bond_price',
            'bond_count', 'bond_window_count', 'bond_industry', 'bond_main_net_amount',
            'filter_config'
        ]
        
        placeholders = ', '.join(['%s'] * len(columns))
        updates = ', '.join([f"{col} = VALUES({col})" for col in columns])
        
        sql = f"""
            INSERT INTO {self.TABLE} ({', '.join(columns)})
            VALUES ({placeholders})
            ON DUPLICATE KEY UPDATE
                {updates},
                updated_at = CURRENT_TIMESTAMP
        """
        
        # 转换为元组列表
        values = [self._record_to_tuple(r) for r in records]
        
        # 执行批量插入
        with self.engine.begin() as conn:
            conn.execute(text(sql), values)
        
        return BacktraceResult(count=len(records))
    
    def _record_to_tuple(self, record: BacktraceRecord) -> Tuple:
        """将记录转换为元组"""
```

```python
import numpy as np

def filter_by_field(data, field, threshold):

    return [data[i] for i in range(len(data)) if mask[i]]
```

| **解决方案** | 1. **热回滚**：1分钟内切换回前端过滤<br>2. **监控告警**：错误率>0.1%或响应时间>200ms告警<br>3. **自动回滚**：连续5分钟错误率>1%自动切换 |
| **回退机制** | `curl -X POST /api/admin/config -d '{"USE_BACKEND_FILTER": false}'` |
| **恢复时间** | 1分钟内 |
