## 步骤1: 成交弹窗探测

**前提:** 有一只可以秒成交的转债(正偏移/市价买入)

```bash
cd F:\pyworkspace2026\gs2026\scripts\huatai_trader
python test_popup_detect.py
```

**操作:**
1. 脚本启动后显示"开始监控"
2. 去xiadan执行一笔能成交的买入(如市价买10股某转债)
3. 成交后观察脚本是否捕获到弹窗

**成功标志:** 脚本打印 ★★★ 标记的窗口,内容含证券代码

**产出:** `popup_detect_result.json`

## 步骤2: 撤单(F3)测试

**前提:** 有一笔未成交的挂单(如极低价买入,不会成交)

```bash
python test_cancel_f3.py
```

**操作:**
1. 先去xiadan挂一笔不会成交的单(如某转债以50元极低价买入)
2. 运行脚本,跟着提示操作
3. 记录撤单面板布局和按钮位置
4. 测试实际撤单(会撤掉那笔低价单)

**成功标志:** 撤单成功,委托从列表消失

**产出:** `cancel_config.json`

## 步骤3: 强平卖出(F2)测试
