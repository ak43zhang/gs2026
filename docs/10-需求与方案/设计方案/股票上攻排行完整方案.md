## 1. 债券上攻排行悬停分时图-重新设计方案


## 一、需求概述

**目标**：在数据监控页面的债券上攻排行中，鼠标悬停某条债券时展示该债券的当日分时图（涨跌幅曲线）。

**效果**：悬停200ms后弹出深色浮层，显示涨跌幅面积图，边框颜色跟随涨跌变化（红涨绿跌）。

**数据来源**：Redis缓存优先，MySQL降级兜底。

---

## 二、架构设计

### 2.1 分层架构

```
┌─────────────────────────────────────────────────┐
│ 前端 (monitor.html)                             │

                       ▼

                       │
          ┌────────────┼────────────┐
          ▼                         ▼
┌──────────────────┐    ┌──────────────────────┐
│ Redis (缓存层)    │    │ MySQL (持久层/降级)    │
│ BondTickCache    │    │ monitor_zq_sssj_*    │
```

### 2.2 核心设计原则

| 原则 | 实现方式 |
|------|---------|
| **可插拔** | `CacheConfig.ENABLED` + 环境变量 `BOND_TICK_CACHE_ENABLED` |
| **零连接** | 复用Dashboard2全局Redis连接池，不创建新连接 |
| **天然降级** | 每次操作获取客户端，不可用时自动跳过 |
| **零侵入** | monitor_bond.py只增加钩子，不改原有逻辑 |

### 2.3 纯消费者模式（关键设计）

**背景**：Dashboard2启动时已通过`Initializer.init_redis()`初始化全局Redis连接池。

**设计**：`BondTickCache`不做任何Redis连接管理，仅作为全局连接池的消费者。

```python
# 之前（冗余，存在初始化时序问题）：
class BondTickCache:
    def __init__(self):
        self._redis = _get_redis_client()  # 自己存引用，可能为None
        self._start_health_check()          # 独立线程

# 之后（纯消费者，零额外连接）：
class BondTickCache:
    @classmethod
    def _redis(cls):
        """每次操作时获取，复用全局连接池"""
        from gs2026.utils.redis_util import _get_redis_client
        return _get_redis_client()
```

**好处**：
- 零新Redis连接（复用Dashboard2已有连接池）
- 零初始化代码（无`__init__`连接逻辑）
- 零健康检查线程（不需要独立线程）
- 零时序依赖（请求到达时全局池必然已就绪）
- 天然降级（客户端为None时自动跳过）

### 4.1 BondTickCache（bond_tick_cache.py）

```python
    _instance = None
    _fail_count = 0
    _disabled_until = 0  # 降级恢复时间戳
    
    @classmethod
    def _redis(cls):
        """复用全局Redis连接池（零额外连接）"""
        # 降级中：检查是否到了恢复时间
        if cls._disabled_until > 0:
            if time.time() < cls._disabled_until:
                return None
            cls._disabled_until = 0
            cls._fail_count = 0
        from gs2026.utils.redis_util import _get_redis_client
        return _get_redis_client()

        """同步写入 - Pipeline批量操作"""
        r = self._redis()
```

### 4.2 API路由（bond_tick_api.py）

```python
@bp.route('/<bond_code>')
def get_ticks(bond_code):
    date = request.args.get('date', today())
    
    # 1. Redis优先
    if is_cache_enabled():
        ticks = get_bond_ticks(bond_code, date)
    
    # 2. MySQL降级（使用config_util全局引擎，非pd.read_sql）
    if not ticks:
        ticks = _query_mysql(bond_code, date)
        # 异步回填Redis
        if ticks and is_cache_enabled():
            _backfill_to_redis(bond_code, date, ticks)
    
    return jsonify({source: 'redis'/'mysql', data: ticks})
```

**MySQL降级优化**：
- 使用`config_util.get_engine()`复用连接池（非`get_mysql_tool()`创建新引擎）
- 使用原生SQLAlchemy `text()` + `fetchall()`（非`pd.read_sql`）
- 减少开销：无DataFrame转换

**诊断端点**：`GET /api/bond/tick/status` 返回Redis连接状态、缓存命中统计。

### 8.3 每Tick写入开销（monitor_bond.py）— Pipeline批量优化

**优化前（逐条异步）**：

| 指标 | 数值 |
|------|------|
| 每tick线程数 | 300个（每债券1个线程） |
| 网络往返次数 | 300次 |

**优化后（Pipeline批量）**：

| 指标 | 数值 |
|------|------|
| 每tick线程数 | **1个** |
| 网络往返次数 | **1次** |
| 写入总耗时 | **5-10ms** |
| 对主流程影响 | 0ms（异步） |

**实现方式**：

```python
def _write_to_redis_cache(df_now, time_full, date_str):
    def do_batch_write():
        r = _get_redis_client()
        pipe = r.pipeline()
        for _, row in df_now.iterrows():
            pipe.hset(key, time_full, json_data)   # 300条HSET
            pipe.sadd(index_key, bond_code)         # 300条SADD
            pipe.expire(key, expire_sec)            # 300条EXPIRE
        pipe.expire(index_key, expire_sec)
        pipe.execute()  # 单次网络往返，~900条命令打包

    threading.Thread(target=do_batch_write, daemon=True).start()
```

**提升**：性能提升30-60倍，线程资源减少99.7%（300→1）。

## 九、实施中遇到的问题与解决

### 9.1 初始连接问题

**问题**：BondTickCache自己创建Redis连接，存在初始化时序问题（可能在Dashboard2的init_redis之前执行）。

**解决**：改为纯消费者模式，不创建连接，每次操作时从全局池获取。

### 9.2 测试数据代码错误

**问题**：手动填充测试数据时使用了错误的债券代码（111060/113064），实际三江转债=123273，盛德转债=123270。

**解决**：从MySQL查询真实代码，用正确代码重新填充Redis。

### 9.3 前端不传date参数

**问题**：`loadBondTickData(bondCode)` 没有传递日期参数，API默认使用当天日期（周日无数据）。

**解决**：使用页面已有的`getSelectedDate()`函数传递监控日期。

### 9.4 MySQL降级过慢

**问题**：`pd.read_sql + get_mysql_tool()` 每次创建新引擎，单查询6-15秒。

**解决**：改用`config_util.get_engine()`复用连接池 + 原生SQLAlchemy查询。

### 9.5 快速滑动误触发

**问题**：鼠标从第一条滑到第三条时，第一条就开始展示。

**解决**：添加200ms进入延迟，鼠标停留足够时间才触发。

```javascript
let _tickChart = null;
let _tickPopupTimer = null;

async function showTickPopup(bondCode, bondName, event) {
    if (bondCode === 'none' || !bondCode) return;
    
    const popup = document.getElementById('bond-tick-popup');
    const nameEl = document.getElementById('tick-bond-name');
    const sourceEl = document.getElementById('tick-source');
    const chartDiv = document.getElementById('tick-chart');
    
    // 定位（鼠标右侧）
    const rect = event.target.getBoundingClientRect();
    popup.style.left = (rect.right + 10) + 'px';
    popup.style.top = rect.top + 'px';
    popup.style.display = 'block';
    
    nameEl.textContent = bondName || bondCode;
    sourceEl.textContent = '加载中...';
    sourceEl.className = 'source-tag';
    chartDiv.innerHTML = '<div style="text-align:center;padding:60px;color:#999;">加载中...</div>';
    
    // 防抖：延迟加载避免快速滑动时频繁请求
    clearTimeout(_tickPopupTimer);
    _tickPopupTimer = setTimeout(async () => {
        const startTime = Date.now();
        try {
            const response = await fetch(`/api/bond/tick/${bondCode}`);
            const result = await response.json();
            const loadTime = Date.now() - startTime;
            
            if (result.success && result.data.length > 0) {
                // 显示来源
                const isRedis = result.source === 'redis';
                sourceEl.textContent = isRedis ? `⚡缓存 ${loadTime}ms` : `📊数据库 ${loadTime}ms`;
                sourceEl.className = 'source-tag ' + (isRedis ? '' : 'mysql');
                
                // 渲染图表
                renderTickChart(chartDiv, result.data);
            } else {
                sourceEl.textContent = '无数据';
                chartDiv.innerHTML = '<div style="text-align:center;padding:60px;color:#999;">暂无分时数据</div>';
            }
        } catch (e) {
            sourceEl.textContent = '错误';
            chartDiv.innerHTML = '<div style="text-align:center;padding:60px;color:#f00;">加载失败</div>';
        }
    }, 100); // 100ms防抖
}

function hideTickPopup() {
    clearTimeout(_tickPopupTimer);
    const popup = document.getElementById('bond-tick-popup');
    popup.style.display = 'none';
    if (_tickChart) {
        _tickChart.dispose();
        _tickChart = null;
    }
}

    const option = {
        grid: { top: 10, right: 10, bottom: 20, left: 40 },
        xAxis: {
            type: 'category',
            data: data.map(d => d.time),

        },
        yAxis: {
            type: 'value',
            min: minPrice,
            max: maxPrice,
            scale: true,
            splitLine: { lineStyle: { color: '#eee' } }
        },
        series: [{
            type: 'line',
            data: prices,
            smooth: true,
            symbol: 'none',
            lineStyle: { width: 1.5, color: '#1890ff' },
            areaStyle: {
                color: {
                    type: 'linear',
                    x: 0, y: 0, x2: 0, y2: 1,
                    colorStops: [
                        { offset: 0, color: 'rgba(24,144,255,0.3)' },
```

## 二、方案概述

### 2.1 核心设计
- **区间定义**：15分钟固定窗口（09:30-09:45, 09:45-10:00...）
- **计算方式**：内存缓存为主，数据库兜底
- **字段名称**：`window_count`（区间次数）
- **展示名称**："区间次数"

### 2.2 技术架构
```

│  monitor_stock  │────▶│  内存缓存模块   │────▶│  数据库写入     │
│  monitor_bond   │     │  (高性能O(1))  │     │  (持久化)       │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                              │
                              ▼
                       ┌─────────────────┐
                       │  宕机恢复机制  │
                       │  (数据库重建)  │
                       └─────────────────┘
```

## 三、详细设计

### 3.1 区间划分规则

| 当前时间范围 | 区间起始 | 统计范围示例 |
|-------------|---------|-------------|
| 09:30:00-09:44:59 | 09:30:00 | 09:30:05统计09:30:00-09:30:05(5秒) |
| 09:45:00-09:59:59 | 09:45:00 | 09:50:00统计09:45:00-09:50:00(5分钟) |
| 10:00:00-10:14:59 | 10:00:00 | 10:00:00重置为0，新区间开始 |

### 3.2 计算逻辑

```python
# 15分钟取整计算
def calculate_window_start(time_str: str) -> str:
    hh, mm, _ = time_str.split(':')
    hour, minute = int(hh), int(mm)
    window_start = (minute // 15) * 15
    return f"{hour:02d}:{window_start:02d}:00"

# 每次写入时：本区间内已出现次数 + 1
window_count = current_count + 1
```

### 3.3 内存缓存设计

**数据结构**：
```python
# key: (date, window_start, code)
# value: count
_window_count_cache: Dict[Tuple[str, str, str], int] = {}
```

**核心操作**：
- `get_window_count(code, date, time)`：获取并递增
- `_clear_old_window_cache(date, current_window)`：跨区间清理
- `_rebuild_from_db(...)`：宕机恢复

### 3.4 宕机恢复机制

**场景**：程序重启后，内存缓存为空

**恢复流程**：
1. 第一笔数据写入，缓存未命中
2. 自动查询数据库：统计本区间内该代码已出现次数
3. 重建缓存，后续写入正常

**SQL重建查询**：
```sql
SELECT COUNT(*) FROM {table} 
WHERE code = '{code}' 
AND time >= '{window_start}' 
AND time < '{current_time}'
```

### 3.2 计算逻辑

```python
# 15分钟取整计算
def calculate_window_start(time_str: str) -> str:
    hh, mm, _ = time_str.split(':')
    hour, minute = int(hh), int(mm)
    window_start = (minute // 15) * 15
    return f"{hour:02d}:{window_start:02d}:00"

# 每次写入时：本区间内已出现次数 + 1
window_count = current_count + 1
```

### 3.4 宕机恢复机制

**场景**：程序重启后，内存缓存为空

**恢复流程**：
1. 第一笔数据写入，缓存未命中
2. 自动查询数据库：统计本区间内该代码已出现次数
3. 重建缓存，后续写入正常

## 性能分析

### 端到端耗时分解（实测 2026-05-18）

| 步骤 | 函数 | 耗时 | 占比 |
|------|------|------|------|
| 1. 获取排行数据 | `get_stock_ranking()` | 4ms | 0% |
| 2. 补充债券/行业信息 | `_enrich_stock_data()` | 2ms | 0% |

## 优化方案

### P0：单例数据库引擎

**问题**：每次请求创建新 `Engine`

```python
# 优化前（每次请求）
engine = create_engine(Config.MYSQL_URI)  # ~200ms

# 优化后（模块级单例）
_shared_engine = None
def _get_shared_engine():
    global _shared_engine
    if _shared_engine is None:
        _shared_engine = create_engine(Config.MYSQL_URI, pool_recycle=3600, pool_pre_ping=True)
    return _shared_engine
```

### P1：DataFrame 进程级内存缓存

**问题**：每次请求加载完整 5124 行 DataFrame

```python
# 优化后：同一 tick 内缓存，不重复加载
_df_cache = None
_df_cache_key = None

def get_cached_sssj_df(redis_key):
    global _df_cache, _df_cache_key
    if _df_cache_key == redis_key and _df_cache is not None:
        return _df_cache
    df = redis_util.load_dataframe_by_key(redis_key, use_compression=False)
    if df is not None and not df.empty:
        _df_cache = df
        _df_cache_key = redis_key
    return df
```

### P2：`_get_latest_sssj_time` 使用共享引擎

**问题**：MySQL 回退时每次 `MysqlTool()` 新建连接

```python

engine = _get_shared_engine()
```

## 8. 股票上攻排行-最大累计主力净额字段设计方案


## 一、字段定义

| 属性 | 值 |
|------|-----|
| 字段名 | `max_cumulative_main_net` |
| 含义 | 当日累计主力净额的历史最大值（实时峰值） |
| 默认值 | 0 |
| 类型 | float |
| 计算 | 每tick: `max(prev_max, current_cumulative)` |

## 二、业务意义

### 2.1 核心用途
用于判断主力是否开始流出，通过比较当前累计值与历史峰值。

### 2.2 场景示例

```
时间线示例：
  09:35 累计净额 = +500万  → max = 500万
  10:20 累计净额 = +800万  → max = 800万（新高）
  11:30 累计净额 = +600万  → max = 800万（维持峰值，主力开始流出）
  14:00 累计净额 = +200万  → max = 800万（持续流出）
  
判断逻辑：
  if current_cumulative < max_cumulative * 0.8:
      提示"主力已开始流出，峰值回落超过20%"
```

### 2.3 使用场景

| 场景 | 判断条件 | 提示 |
|------|---------|------|
| 主力持续流入 | current ≈ peak | "资金持续流入，维持高位" |
| 主力开始流出 | current < peak * 0.8 | "⚠️ 主力开始流出，峰值回落" |
| 主力大幅撤离 | current < peak * 0.5 | "🔴 主力大幅撤离，谨慎操作" |

## 三、计算逻辑设计

### 3.1 初始化位置

**文件**: `src/gs2026/monitor/monitor_stock.py`  
**位置**: L560附近（与cumulative_main_net一起初始化）

```python
# 初始化最大累计主力净额
df_now['max_cumulative_main_net'] = 0.0
```

### 3.2 计算位置

**文件**: `src/gs2026/monitor/monitor_stock.py`  
**位置**: L693-720（cumulative_main_net计算之后）

```python
# 1. 计算累计主力净额（已存在）
df_now['cumulative_main_net'] = df_now['cumulative_main_net_prev'] + df_now['main_net_amount']

# 2. 计算最大累计主力净额（与历史峰值比较）
if 'max_cumulative_main_net' in df_prev_main.columns:
    # 当前累计值 vs 历史峰值，取大者
    df_now['max_cumulative_main_net'] = df_prev_main['max_cumulative_main_net'].combine(
        df_now['cumulative_main_net'], 
        max
    )
else:
    # 首次，直接取当前累计值
    df_now['max_cumulative_main_net'] = df_now['cumulative_main_net']
```

### 3.3 计算顺序

```
┌─────────────────────────────────────────────────────────┐
│  每tick计算顺序（派生字段引擎）                              │
├─────────────────────────────────────────────────────────┤
│  1. main_net_amount      ← 当前tick主力净额               │
│  2. cumulative_main_net  ← 累计值（必须第2算）            │
│  3. main_net_count       ← 非零次数                       │
│  4. max_cumulative_main_net ← 峰值（依赖cumulative）      │
└─────────────────────────────────────────────────────────┘
```

## 四、关键决策

| 决策 | 说明 |
|------|------|
| **与cumulative一起计算** | 必须先算完cumulative，再算max |
| **用combine而不是max()** | 逐元素比较两个Series |
| **不取绝对值** | 关注净流入峰值（正值），流出是负值但峰值关心最高点 |

```python
def get_prev_timestamp_with_data(table_name: str, current_time: str, redis_client=None) -> str:
    """
    获取上一个有数据的时间点（用于主力净额计算）
    
    与上攻排行的15秒周期解耦
    """
    prev_time = None
    
    # 方法1: Redis时间戳列表
    if redis_client:
        try:
            ts_key = f"{table_name}:timestamps"
            all_ts = redis_client.lrange(ts_key, 0, -1)
            
            if all_ts:
                timestamps = sorted([
                    t.decode('utf-8') if isinstance(t, bytes) else t
                    for t in all_ts
                ])
                
                # 找当前时间之前的最新时间
                for ts in reversed(timestamps):
                    if ts < current_time:
                        prev_time = ts
                        break
        except Exception as e:
            logger.warning(f"从Redis获取时间戳失败: {e}")
    
    # 方法2: MySQL查询（备用）
    if not prev_time:
        try:
            from sqlalchemy import create_engine, text
            from gs2026.config import Config
            engine = create_engine(Config.MYSQL_URI)
            
            query = text(f"""
                SELECT MAX(time) as prev_time
                FROM {table_name}
                WHERE time < :current_time
                LIMIT 1
            """)
            
            with engine.connect() as conn:
                result = conn.execute(query, {"current_time": current_time})
                row = result.fetchone()
                if row and row[0]:
                    prev_time = row[0]
        except Exception as e:
            logger.warning(f"从MySQL获取上一时间失败: {e}")
    
    return prev_time


def load_dataframe_by_time(table_name: str, time_str: str, use_compression: bool = False) -> pd.DataFrame:
    """
    根据时间点加载DataFrame（用于主力净额计算）
    
    优先Redis，其次MySQL
    """
    import pandas as pd
    
    # 1. 优先Redis
    redis_key = f"{table_name}:{time_str}"
    df = load_dataframe_by_key(redis_key, use_compression=use_compression)
    
    if df is not None and not df.empty:
        return df
    
    # 2. MySQL回退
    try:
        from sqlalchemy import create_engine, text
        from gs2026.config import Config
        engine = create_engine(Config.MYSQL_URI)
        
        query = text(f"SELECT * FROM {table_name} WHERE time = :time_str")
        
        with engine.connect() as conn:
            df = pd.read_sql(query, conn, params={"time_str": time_str})
            return df
    except Exception as e:
        logger.error(f"从MySQL加载数据失败: {e}")
        return pd.DataFrame()
```

```python
def calculate_cumulative_main_net_v3(df_now: pd.DataFrame, 
                                    df_prev_main: pd.DataFrame) -> pd.DataFrame:
    """
    计算累计主力净额（直接使用df_prev_main中的cumulative_main_net）
    
    【关键】不复查MySQL，直接使用已加载的df_prev_main
    
    Args:
        df_now: 当前时刻数据（包含main_net_amount）
        df_prev_main: 上一个有数据的时间点数据（包含cumulative_main_net）
    
    Returns:
        添加了cumulative_main_net的DataFrame
    """
    # 初始化累计值为当前值
    df_now['cumulative_main_net'] = df_now['main_net_amount'].fillna(0)
    
    if df_prev_main is None or df_prev_main.empty:
        return df_now
    
    try:
        # 检查df_prev_main是否有cumulative_main_net字段
        if 'cumulative_main_net' not in df_prev_main.columns:
            return df_now
        
        # 【关键】直接使用df_prev_main中的cumulative_main_net
        prev_cumulative = df_prev_main[df_prev_main['cumulative_main_net'] != 0][['stock_code', 'cumulative_main_net']].copy()
        
        if prev_cumulative.empty:
            return df_now
        
        # 类型统一
        df_now['stock_code'] = df_now['stock_code'].astype(str)
        prev_cumulative['stock_code'] = prev_cumulative['stock_code'].astype(str)
        
        # 合并
        df_now = df_now.merge(
            prev_cumulative,
            on='stock_code',
            how='left',
            suffixes=('', '_prev')
        )
        
        # 新的累计值 = 上一累计值 + 当前值
        df_now['cumulative_main_net_prev'] = df_now['cumulative_main_net_prev'].fillna(0)

        df_now = df_now.drop(columns=['cumulative_main_net_prev'], errors='ignore')
        
    except Exception as e:
        logger.error(f"计算累计主力净额失败: {e}")
        df_now['cumulative_main_net'] = df_now['main_net_amount'].fillna(0)
    
    return df_now
```

## 一、需求背景

### 现状问题
1. **行业上攻排行**（3列：排名、代码、名称+次数）占据1/3宽度，但内容很少，空间浪费

3. 三个面板等宽（各33.3%），股票排行列多（9列）显示拥挤

### 解决方案
- 调整grid比例：股票:债券:行业 = 3:2:1
- 股票排行增加"主力净额"字段
- 主力净额跟随涨跌幅，从monitor_gp_sssj实时查询

## 二、数据流分析

### 当前涨跌幅获取逻辑

```
data_service.get_stock_ranking()
    → 从 Redis 获取: code, name, count
    → 或从 MySQL rank_stock 表获取: code, name, count, date

_enrich_change_pct()
    → 从 Redis 获取最新时间戳
    → 从 monitor_gp_sssj_{date} 表批量查询 change_pct
    → 填充到每个 stock 对象

_enrich_stock_data()
    → 补充债券代码、债券名称、行业信息
```

### 关键发现
**涨跌幅 `change_pct` 不是从 Redis 获取的，而是实时从 `monitor_gp_sssj` 表查询的！**

每次 API 调用：
1. 从 Redis 获取基础排行数据（code, name, count）— **~5ms**
2. 从 MySQL `monitor_gp_sssj` 批量查询涨跌幅 — **~20ms（1次查询60条）**

---

## 三、设计方案

### 3.1 核心设计原则

**主力净额跟随涨跌幅，采用完全相同的获取逻辑**

理由：
1. 数据一致性：都来自同一表（monitor_gp_sssj），同一时间点
2. 代码简洁：只需修改 `_enrich_change_pct` 函数，同时查询两个字段
3. 无需修改 Redis：减少复杂度
4. 性能可接受：仅增加约5ms

```python
        if time_str:
            query_time = time_str
        else:
            sssj_table = f"monitor_gp_sssj_{date}"
            ts_key = f"{sssj_table}:timestamps"
            latest_ts = client.lindex(ts_key, 0)
```

## 1. 需求概述

### 1.1 背景
债券上攻排行中，某些可转债对应的正股可能同时出现在股票上攻排行中。需要对这种"股债联动"情况进行视觉标记，便于快速识别强势联动标的。

### 1.2 标记规则
**触发条件**：债券的正股代码出现在当前（或最近）股票上攻排行中。

**标记方式**：
- 前缀标记：`★[排名]债券代码`
- 示例：`★[3]128123` 表示正股在股票排行第3位

## 2. 核心挑战

### 2.1 挑战一：时序问题
股票和债券监控可能异步执行，导致债券计算时股票排行数据尚未生成。

**解决方案**：延迟标记法（带降级）

```python
def get_stock_attack_codes_robust(
    date_str: str, 
    time_str: str,
    max_lookback: int = None
) -> Dict[str, int]:
    """
    健壮地获取股票上攻排行代码（带降级处理）
    
    依次尝试：
    1. 当前周期实时数据
    2. 上一周期数据（3秒前）
    3. 最近N个周期内的数据
    4. 返回空（放弃标记）
    """
    from datetime import datetime, timedelta
    
    if max_lookback is None:
        max_lookback = STOCK_BOND_LINK_CONFIG['max_lookback_periods']
    
    try:
        current_dt = datetime.strptime(f"{date_str} {time_str}", "%Y%m%d %H:%M:%S")
    except ValueError:
        logger.error(f"[股债联动] 时间格式错误: {date_str} {time_str}")
        return {}
    
    # 依次尝试当前周期和回看周期
    for i in range(max_lookback + 1):
        try_time = current_dt - timedelta(seconds=3 * i)
        try_time_str = try_time.strftime("%H:%M:%S")
        
        codes = _get_stock_codes_from_redis(date_str, try_time_str)
        if codes:
            if i == 0:
                logger.debug(f"[股债联动] 使用实时股票排行: {try_time_str}, {len(codes)}只")
            else:
                logger.info(f"[股债联动] 使用{i}周期前股票排行: {try_time_str}, {len(codes)}只")
            return codes
    
    # 最后尝试：获取任何可用的股票排行
    codes = _get_latest_stock_codes(date_str)
    if codes:
        logger.info(f"[股债联动] 使用最新可用股票排行（非实时）, {len(codes)}只")
        return codes
    
    logger.warning(f"[股债联动] 无法获取股票排行，跳过标记")
    return {}


def _get_stock_codes_from_redis(date_str: str, time_str: str) -> Dict[str, int]:
    """从Redis获取股票排行代码"""
    codes = {}
    
    try:
        # 方法1：从rank key获取
        rank_key = f"rank:stock:code_{date_str}"
        r = redis_util._get_redis_client()
        rank_data = r.zrevrange(rank_key, 0, -1, withscores=True)
        
        for idx, (code, score) in enumerate(rank_data, 1):
            code_str = code.decode('utf-8') if isinstance(code, bytes) else code
            codes[code_str] = idx
        
        if codes:
            return codes
            
        # 方法2：从top30表获取
        gp_table = f"monitor_gp_top30_{date_str}"
        df = redis_util.load_dataframe_by_key(
            f"{gp_table}:{time_str}", 
            use_compression=False
        )
        if df is not None and not df.empty:
            for idx, row in df.iterrows():
                code = str(row.get('code', ''))
                if code:
                    codes[code] = idx + 1
                    
    except Exception as e:
        logger.debug(f"[股债联动] 从Redis获取股票排行失败: {e}")
    
    return codes


def _get_latest_stock_codes(date_str: str) -> Dict[str, int]:
    """获取最近可用的股票排行"""
    codes = {}
    
    try:
        gp_table = f"monitor_gp_top30_{date_str}"
        pattern = f"{gp_table}:*"
        r = redis_util._get_redis_client()
        keys = r.keys(pattern)
        
        if not keys:
            return {}
        
        # 找到最新的时间戳
        latest_time = None
        for key in keys:
            key_str = key.decode('utf-8') if isinstance(key, bytes) else key
            time_part = key_str.split(':', 1)[1] if ':' in key_str else None
            if time_part and (latest_time is None or time_part > latest_time):
                latest_time = time_part
        
        if latest_time:
            return _get_stock_codes_from_redis(date_str, latest_time)
            
    except Exception as e:
        logger.warning(f"[股债联动] 获取最近股票排行失败: {e}")
    
    return codes
```

#### 函数2：标记债券代码

```python
def mark_bond_with_stock_link(df_bond: pd.DataFrame, stock_codes: dict) -> pd.DataFrame:
    """
    为债券添加股债联动标记
    
    Args:
        df_bond: 债券数据DataFrame（需包含stock_code字段）
        stock_codes: 股票排行代码字典 {股票代码: 排名}
    
    Returns:
        添加标记后的DataFrame
    """
    if not stock_codes:
        # 无股票排行数据，添加空标记
        df_bond['is_stock_ranked'] = False
        df_bond['stock_rank_pos'] = None
        df_bond['bond_code_display'] = df_bond['code'].astype(str)
        return df_bond
    
    # 检查正股是否在股票排行中
    df_bond['stock_rank_pos'] = df_bond['stock_code'].map(stock_codes)
    df_bond['is_stock_ranked'] = df_bond['stock_rank_pos'].notna()
    
    # 生成标记后的债券代码
    def _mark_code(row):
        if row['is_stock_ranked']:
            prefix = STOCK_BOND_LINK_CONFIG['mark_prefix']
            if STOCK_BOND_LINK_CONFIG['include_rank'] and pd.notna(row['stock_rank_pos']):
                # 包含排名：★[3]128123
                return f"{prefix}[{int(row['stock_rank_pos'])}]{row['code']}"
            else:
                # 仅前缀：★128123
                return f"{prefix}{row['code']}"
        return str(row['code'])
    
    df_bond['bond_code_display'] = df_bond.apply(_mark_code, axis=1)
    
    # 记录统计
    ranked_count = df_bond['is_stock_ranked'].sum()
    if ranked_count > 0:
        logger.info(f"[股债联动] 标记{int(ranked_count)}只债券（正股在上攻排行中）")
    
    return df_bond
```

### 1. 新增函数：获取最早时间戳

```python
def get_earliest_time_from_redis(table_name: str) -> Optional[str]:
    """
    从Redis获取表中最早的时间戳
    
    Args:
        table_name: 表名如 monitor_gp_sssj_20260427
        
    Returns:
        最早时间戳如 "09:27:42"，无数据返回None
    """
    try:
        r = get_redis_client()
        # 获取所有时间戳key
        pattern = f"{table_name}:*"
        keys = r.keys(pattern)
        if not keys:
            return None
        
        # 提取时间戳并排序
        times = []
        for key in keys:
            key_str = key.decode('utf-8') if isinstance(key, bytes) else key
            # 格式: monitor_gp_sssj_20260427:09:30:00
            time_part = key_str.split(':', 1)[1] if ':' in key_str else None
            if time_part:
                times.append(time_part)
        
        if not times:
            return None
            
        # 返回最早时间
        times.sort()
        return times[0]
    except Exception as e:
        logger.error(f"获取最早时间戳失败: {e}")
        return None
```

### 方案A: 实时查询Redis（推荐）

在 `_process_stock_ranking` 中增加涨跌幅查询：

```python
def _enrich_change_pct(self, stocks: list, date: str, time_str: str = None) -> list:
    """
    为股票数据添加涨跌幅
    
    从Redis的monitor_gp_top30表获取指定时间的change_pct_now
    """
    if not stocks:
        return stocks
    
    try:
        from gs2026.utils import redis_util
        client = redis_util._get_redis_client()
        
        # 构建表名
        table_name = f"monitor_gp_top30_{date}"
        
        # 确定查询时间
        if time_str:
            # 时间轴回放模式 - 使用指定时间
            query_time = time_str
        else:
            # 实时模式 - 获取最新时间
            ts_key = f"{table_name}:timestamps"
            latest_ts = client.lindex(ts_key, 0)  # 获取最新时间戳
            if latest_ts:
                query_time = latest_ts.decode('utf-8') if isinstance(latest_ts, bytes) else latest_ts
            else:
                # 无时间戳数据，返回原数据
                for stock in stocks:
                    stock['change_pct'] = None
                return stocks
        
        # 从Redis获取该时间点的DataFrame
        redis_key = f"{table_name}:{query_time}"
        df = redis_util.load_dataframe_by_key(redis_key, use_compression=False)
        
        if df is None or df.empty:
            # Redis无数据，返回原数据
            for stock in stocks:
                stock['change_pct'] = None
            return stocks
        
        # 构建code -> change_pct映射
        change_pct_map = {}
        for _, row in df.iterrows():
            code = str(row.get('code', '')).zfill(6)
            change_pct = row.get('change_pct_now') or row.get('change_pct')
            if code and change_pct is not None:
                change_pct_map[code] = float(change_pct)
        
        # 为每只股票添加涨跌幅
        for stock in stocks:
            code = stock.get('code', '').zfill(6)
            stock['change_pct'] = change_pct_map.get(code)
        
        return stocks
        
    except Exception as e:
        print(f"获取涨跌幅失败: {e}")
        # 出错时返回原数据，change_pct为null
        for stock in stocks:
            stock['change_pct'] = None
        return stocks
```

```python
                return stocks
```

```python
def get_mappings_batch(self, stock_codes: list) -> dict:
    """批量获取股票映射"""
    today = datetime.now().strftime('%Y-%m-%d')
    mapping_key = f"{REDIS_KEY_PREFIX}:{today}"
    
    pipe = self.redis_client.pipeline()
    for code in stock_codes:
        pipe.hget(mapping_key, code)
    
    results = pipe.execute()
    
    mappings = {}
    for code, data in zip(stock_codes, results):
        if data:
            mappings[code] = json.loads(data)
    
    return mappings
```
