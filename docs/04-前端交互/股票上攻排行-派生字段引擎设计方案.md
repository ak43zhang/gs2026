## 版本信息
- **版本**: v1.0
- **日期**: 2026-05-12
- **状态**: 待实施

## 一、设计目标

| 目标 | 说明 |
|------|------|
| 不侵入主流程 | 主循环只调一个函数，内部扩展对外透明 |
| 新增字段极简 | 新增一个派生字段只需3处改动 |
| 一次查询 | 所有派生字段随sssj表一次写入、一次读取 |
| 高效计算 | 向量化操作，避免逐行循环 |

## 二、架构设计

### 2.1 文件结构

gs2026/monitor/
  monitor_stock.py             主循环，调用 calculate_all_derived()
  monitor_derived_fields.py    派生字段注册表 + 计算引擎（新增）

### 2.2 注册表模式

每个派生字段通过注册表定义：
- name: 字段名（存入sssj表的列名）
- default: 默认值（不在top30中时的值）
- dtype: 数据类型（int/float）
- calc: 计算函数 calc(prev_value, in_top30) -> new_value

### 2.3 数据流

每3秒tick（monitor_stock.py）:
  1. 计算主力净额
  2. 计算top30 -> 返回top30_codes集合
  3. calculate_all_derived(df_now, df_prev_main, top30_codes)
     遍历注册表，查上一tick各字段值，应用calc函数
  4. save_dataframe_async(df_now, sssj_table)
     写入MySQL + Redis（包含所有派生字段）

前端请求排行（routes/monitor.py）:
  Redis: monitor_gp_sssj -> 一次读取 change_pct + cumulative_main_net + 所有派生字段

## 三、连续上攻次数（首个派生字段）

### 3.1 字段定义

| 属性 | 值 |
|------|-----|
| 字段名 | consecutive_attacks |
| 含义 | 当前tick该股票连续出现在top30中的次数 |
| 默认值 | 0（不在top30中） |
| 数据类型 | int |

### 3.2 计算逻辑

每个tick:
  在top30中的股票:
    if 上一tick也在top30中（上一tick的consecutive_attacks > 0）:
      consecutive_attacks = 上一tick的值 + 1
    else:
      consecutive_attacks = 1（首次进入top30）
  不在top30中的股票:
    consecutive_attacks = 0

### 3.3 注册代码

DERIVED_FIELDS = [
    {
        name: consecutive_attacks,
        default: 0,
        dtype: int,
        calc: lambda prev, in_top30: (prev + 1) if in_top30 else 0,
    },
]

### 3.4 存储位置

monitor_gp_sssj_{date} 表，作为新增列，与 cumulative_main_net 同级。

### 3.5 前端展示

| 值范围 | 样式 |
|--------|------|
| >=10 | 红色加粗（streak-hot） |
| >=5 | 橙色加粗（streak-warm） |
| <5 | 默认样式 |

## 四、扩展指南

### 新增派生字段（3步）

步骤1: monitor_derived_fields.py 注册
  {
      name: new_field_name,
      default: 0,
      dtype: int,
      calc: lambda prev, in_top30: ...,
  },

步骤2: routes/monitor.py 添加到展示列表
  DERIVED_DISPLAY_FIELDS = [consecutive_attacks, new_field_name]

步骤3: monitor.html 前端
  STOCK_COLUMNS追加 + renderStockCell追加
