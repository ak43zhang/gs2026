# 债券上攻排行 - 过滤条件面板化改造方案

> 日期：2026-07-12  
> 状态：已通过审核  
> 涉及文件：`src/gs2026/dashboard2/templates/monitor.html`

## 背景

债券上攻排行当前有 3 个过滤条件（仅前N行业、仅前N金额、隐藏绿名单）以内联方式直接放在 `<h2>` 标题中，存在以下问题：

- 标题区拥挤，空间紧张
- 新增过滤条件需要修改 HTML 结构
- 无法统一管理过滤状态

## 设计目标

1. 参照「列设置 ⚙️」面板模式，将过滤条件收入弹出面板
2. 通过配置数组 `BOND_FILTERS` 驱动渲染，后续扩展只需加配置项
3. 标题区仅显示 🔍 按钮 + 已激活过滤数量角标

## 效果对比

| | 改前 | 改后 |
|--|------|------|
| 标题区 | 3 个内联控件挤在 h2 里 | 仅显示 🔍 按钮 + 激活数量角标 |
| 交互 | 直接操作内联控件 | 点击 🔍 → 弹出面板 → 操作 → 实时生效 |
| 扩展性 | 改 HTML | 在 `BOND_FILTERS` 数组加一项即可 |

/* 过滤设置面板 */

.filter-settings-btn .filter-badge { position: absolute; top: -2px; right: -2px; background: #667eea; color: #fff; font-size: 9px; width: 14px; height: 14px; border-radius: 50%; display: flex; align-items: center; justify-content: center; }

### 改动2：HTML — 债券排行标题区改为按钮式

将当前债券排行 `<h2>` 中的 3 个内联 filter-label 移除，改为 🔍 按钮：

**改前（h2 内左侧 span）：**
```
💹 债券上攻排行 + 仅前N行业label + 仅前N金额label + 隐藏绿名单label + 行业tag
```

**改后：**
```
💹 债券上攻排行 + 行业tag（保留）
右侧：🔍按钮 + ⚙️按钮 + 刷新指示器
```

追加面板 HTML：
```html
<div class="col-settings-overlay" id="bond-filter-overlay" onclick="closeBondFilterPanel()"></div>
<div class="filter-panel" id="bond-filter-panel" style="display:none;top:40px;right:40px;"></div>
```

### 改动3：JavaScript — 过滤配置数组 + 面板渲染

新增 `BOND_FILTERS` 配置数组和面板控制函数：

```javascript
const BOND_FILTERS = [
    { key: 'topn_industry', label: '仅前N行业', type: 'checkbox_number', ... },
    { key: 'topn_amount',   label: '仅前N金额', type: 'select', ... },
    { key: 'green_list',    label: '隐藏绿名单', type: 'checkbox', ... },
];
```

- `toggleBondFilterPanel()` — 打开/关闭面板
- `closeBondFilterPanel()` — 关闭面板
- `renderBondFilterPanel()` — 根据 BOND_FILTERS 渲染面板内容
- `updateBondFilterBadge()` — 更新 🔍 按钮上的激活数量角标

### 改动4：现有过滤函数末尾追加角标更新

在 `toggleBondTopNFilter()`、`toggleBondGreenFilter()`、`rerenderBondRanking()` 末尾追加 `updateBondFilterBadge()` 调用。

## 扩展方式

以后新增过滤条件只需：

1. 在 `BOND_FILTERS` 数组追加配置项
2. 实现对应的 `toggleXxxFilter()` 和 `filterBondByXxx()` 函数
3. 在 `rerenderBondRanking()` 中串联调用

面板自动渲染新条件，无需修改 HTML 结构。

## 主题适配

面板样式需要在 storm/stormy 暗色主题中适配（与 col-settings-panel 同处理）：

```css
body[data-weather] .filter-panel { background: var(--weather-bg) !important; color: var(--weather-text); }
```
