## API 修改

在 `get_chart_data` 中新增两个查询：

```python
# 1. 大盘均值（直接从 monitor_gp_apqd 表读取）
market_sql = f"""
    SELECT time, avg_change_pct as change_pct
    FROM monitor_gp_apqd_{date}
    ORDER BY time ASC
"""

# 2. 行业均值（从 monitor_bk_apqd 表按行业名查询）
# 先从 monitor_gp_sssj 获取该股票的 bk_name
bk_sql = f"""
    SELECT DISTINCT bk_name FROM monitor_gp_sssj_{date}
    WHERE stock_code = '{stock_code}' LIMIT 1
"""
# 再查行业均值
industry_sql = f"""
    SELECT time, avg_change_pct as change_pct
    FROM monitor_bk_apqd_{date}
    WHERE bk_name = '{bk_name}'
    ORDER BY time ASC
"""
```

## 性能评估

| 查询 | 表大小 | 预估耗时 |
|------|--------|----------|

| 正股分时 | ~4000行 | ~500ms |

**总计：~1s** 比之前的方案快很多！
