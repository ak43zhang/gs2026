# 龙头股识别优化方案v7 - 流通市值持久化+历史数据支持

## 背景

- 需要保存流通市值数据供历史分析使用
- 需要支持上上交易日等历史数据分析
- 当前方案需要对历史数据有效

# 如果表中不存在，自动调用adata获取并保存

### 数据回填
如果需要回填历史数据，可以：
1. 手动调用 `stock_spot_em()` 采集指定日期
2. 或者批量脚本回填

## 优点

1. **数据持久化**：市值数据保存到MySQL，可重复使用
2. **历史数据支持**：支持上上交易日等历史数据分析
3. **自动补全**：历史数据不存在时自动调用adata获取并保存
4. **性能优化**：查询过的数据直接从MySQL读取，无需重复调用adata
5. **幂等性**：重复采集不会导致数据重复

## 注意事项

1. **存储空间**：每日全量数据约5000条，长期存储需要考虑空间
2. **数据时效性**：流通股本变动不频繁，但股价每日变化
3. **采集时机**：建议在每日收盘后采集，盘中数据可能不完整
