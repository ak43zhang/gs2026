# 龙头股识别优化实施完成报告

## 实施内容

### 1. 新增函数（anomaly_analyzer.py）

| 函数 | 功能 |
|------|------|
| `_get_mainline_all_stocks()` | 获取指定主线的所有股票（按涨停时间排序） |
| `_recalculate_roles_by_rule()` | 基于规则重新计算role |
| `_calculate_leader_score()` | 计算龙头强度评分0-100 |
| `_batch_update_roles()` | 批量更新股票的role |
| `_update_mainlines_with_role_recalc()` | 带role重新计算的版本 |

### 2. 修改文件

- `anomaly_analyzer.py`: 新增5个函数
- `anomaly_correlator.py`: 导入新函数并替换调用

### 3. 规则

| 排名 | role | 评分 |
|------|------|------|
| 第1只 | 龙头 | 100 |
| 第2只 | 补涨 | 85 |
| 第3只 | 补涨 | 70 |
| 第4只 | 跟风 | 55 |
| 第5只及以后 | 跟风 | 递减 |

连板数修正：
- 2连板以上可从跟风提升为补涨
- 每连板+10分
