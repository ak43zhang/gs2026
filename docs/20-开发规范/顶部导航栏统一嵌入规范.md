# 顶部导航栏统一嵌入规范（开发标准）

**版本**: v1.0  
**制定日期**: 2026-08-04  
**适用范围**: 所有新增页面模板（.html）

---

## 一、背景

全站顶部主导航栏由 `static/js/nav.js` 统一动态生成，通过 `initNav(activeKey)` 渲染。

**历史遗留问题**：
- 旧方案 `{% include 'nav.html' %}` 已被废弃，仅 backtrace.html 曾使用
- 现已统一为 JS 动态方案

---

## 二、标准三要素（必须遵循）

### 要素1：head 引入 nav.css
在 `base.css` + `components.css` 之后，页面自身CSS之前：

```html
<link rel="stylesheet" href="{{ url_for('static', filename='css/base.css') }}">
<link rel="stylesheet" href="{{ url_for('static', filename='css/components.css') }}">
<link rel="stylesheet" href="{{ url_for('static', filename='css/nav.css') }}">
<!-- 页面自身CSS -->
<link rel="stylesheet" href="{{ url_for('static', filename='css/your_page.css') }}">
```

### 要素2：body 首行放导航占位符
```html
<body>
    <div id="nav-placeholder"></div>
    <!-- 页面主体内容 -->
```

### 要素3：body 末尾引入 nav.js 并初始化
```html
    <script src="{{ url_for('static', filename='js/nav.js') }}"></script>
    <script>initNav('<activeKey>');</script>
</body>
</html>
```

---

## 三、activeKey 取值规范

| activeKey | 对应主菜单 | 适用页面 |
|-----------|-----------|---------|
| `'dashboard'` | 首页/仪表盘 | dashboard.html |
| `'monitor'` | 实时监控 | monitor.html |
| `'picker'` | 智能选股 | stock_picker.html, range_analysis.html, backtrace.html |
| `'review'` | 分析中心/复盘 | review.html, market_review.html |

> 若新增大类菜单，需先在 `nav.js` 的菜单定义中新增，再使用新 activeKey。

---

## 四、禁止事项

❌ **禁止使用**（已废弃）：
```html
{% set page_title = '...' %}
{% set active_page = '...' %}
{% include 'nav.html' %}
```

## 六、检查清单

新增页面接入导航栏时，自查：

- [ ] head 包含 `nav.css`
- [ ] body 首行是 `<div id="nav-placeholder"></div>`
- [ ] body 末尾有 `nav.js` 引入 + `initNav('<activeKey>')`
- [ ] activeKey 正确（与页面所属大类一致）
- [ ] 顶部导航栏与其他同类页面视觉一致
- [ ] 当前菜单项高亮正确
- [ ] 无控制台报错
