# 音效开发统一规范（开发标准）

**版本**: v1.0
**制定日期**: 2026-08-05
**适用范围**: 全站所有需要声音提示的功能（前端 Web 页面 + 后端脚本/服务）
**参考实现**: `scripts/huatai_trader/auto_trader.py`（后端）、`dashboard2/templates/monitor.html`（前端）

---

## 一、背景与原则

项目内出现声音提示的场景越来越多（华泰自动交易命中/成交提示、数据监控命中提示、股债交集命中提示等）。为避免各处实现风格不一、难以维护，特制定本规范。

### 核心原则

1. **场景决定方式**：判断逻辑在**哪一端**，声音就在**哪一端**播放。
   - 逻辑在**后端 Python**（本机脚本/服务，声音需从运行机器发出）→ 用**后端方式**。
   - 逻辑在**前端 JS**（Web 页面，声音应从"看页面的那台电脑"发出）→ 用**前端方式**。
2. **文件驱动**：所有语音/音效统一用**音频文件**（`.mp3`）承载，不硬编码合成参数。
3. **配置化**：音效类型 → 文件路径通过**配置字典/映射**管理，新增音效只改配置。
4. **全局开关**：每类音效必须有 `enabled` 开关，支持一键静音，并持久化用户选择。
5. **失败降级**：文件缺失/播放失败时，降级到系统提示音（后端 `winsound` / 前端 Web Audio 蜂鸣），**绝不抛异常打断主流程**。
6. **防重复**：同一事件同一批只播一次；是否需要节流按业务定（如 3 秒 tick 场景无需额外节流）。

## 二、后端音效方式（Python，本机运行）

### 2.1 适用场景

- 华泰自动交易一类**本机脚本/服务**：进程就跑在用户电脑上，`winmm` 播放直接从本机音箱出声。
- 判断逻辑在后端、且能确定"服务机 == 用户机"时。

### 2.2 参考实现（`auto_trader.py`）

```python
def _play_sound(self, sound_type: str):
    """播放提示音"""
    if not self.sounds.get('enabled', True):
        return
    try:
        sound_file = self.sounds.get(sound_type)
        if sound_file and Path(sound_file).exists():
            # 播放自定义音频（Windows 原生 winmm，支持 mp3）
            import ctypes
            winmm = ctypes.windll.winmm
            winmm.mciSendStringW('close notify_sound', None, 0, 0)
            winmm.mciSendStringW(
                f'open "{sound_file}" type mpegvideo alias notify_sound', None, 0, 0)
            winmm.mciSendStringW('play notify_sound', None, 0, 0)
        else:
            # 降级：系统默认提示音
            import winsound
            winsound.MessageBeep(winsound.MB_ICONEXCLAMATION)
    except Exception as e:
        logger.debug(f"[XxxModule] 播放声音失败: {e}")
```

### 2.3 关键点

| 要点 | 说明 |
|------|------|
| 播放 API | `ctypes.windll.winmm.mciSendStringW`，先 `close` 再 `open ... type mpegvideo alias` 再 `play` |
| 配置结构 | `self.sounds = config.get('sounds', {})`，形如 `{'enabled': True, 'hit': '路径.mp3', 'filled': '...'}` |
| 类型驱动 | `_play_sound('hit')` / `_play_sound('filled')`，按 `sound_type` 取文件 |
| 全局开关 | `self.sounds.get('enabled', True)` |
| 降级 | `winsound.MessageBeep(...)` |
| 异常隔离 | `try/except` 包裹，失败仅 `logger.debug`，不打断交易/主流程 |
| 非阻塞 | `mciSendStringW('play ...')` 异步返回，不阻塞线程 |

### 2.4 新增后端音效步骤

1. 把 `.mp3` 放到模块目录（如 `scripts/huatai_trader/xxx.mp3`）。
2. 在该模块的 `sounds` 配置里加一项：`'新类型': '<mp3绝对路径>'`。
3. 在事件触发处调用 `self._play_sound('新类型')`。

## 三、前端音效方式（Web 页面，浏览器播放）

### 3.1 适用场景

- **数据监控**一类 **Web 页面**：判断逻辑在前端 JS，声音应从**浏览器所在机器**发出（谁看页面谁听声）。
- 跨机器访问、判断在前端时，**一律用前端方式**（不要绕到后端 winmm，否则声音会响在服务器那台机）。

### 3.2 标准实现（音频文件驱动 + 配置 + 开关 + 降级）

音频文件统一放在 `dashboard2/static/sounds/`，通过 `url_for('static', filename='sounds/xxx.mp3')` → `/static/sounds/xxx.mp3` 引用。

```javascript
// ==================== 【统一音效模块】 ====================
// 音效配置表：类型 → 文件（借鉴华泰后端 sounds 字典的思路）
const SOUND_FILES = {
    zhongla: '/static/sounds/zhongla.mp3',   // 交集命中："中啦中啦"
    // 后续新增音效在此登记
};
const _audioCache = {};                       // 预加载缓存，避免每次 new Audio 卡顿

function _getAudio(type) {
    if (!_audioCache[type]) {
        const url = SOUND_FILES[type];
        if (!url) return null;
        _audioCache[type] = new Audio(url);
    }
    return _audioCache[type];
}

// 全局开关（持久化）
function isSoundEnabled(key) {
    return localStorage.getItem(key) !== 'false';   // 默认开启
}

// 统一播放入口
function playSound(type, enabledKey) {
    if (enabledKey && !isSoundEnabled(enabledKey)) return;
    try {
        const a = _getAudio(type);
        if (a) {
            a.currentTime = 0;                       // 重置以支持连续触发
            a.play().catch(err => {
                console.warn('[SOUND] play blocked/fail, fallback beep', err);
                _fallbackBeep();                     // 降级：Web Audio 蜂鸣
            });
        } else {
            _fallbackBeep();
        }
    } catch (e) {
        console.warn('[SOUND]', e);
        _fallbackBeep();
    }
}

// 降级蜂鸣（复用页面已有的 Web Audio 合成音）
function _fallbackBeep() {
    try {
        const ctx = new (window.AudioContext || window.webkitAudioContext)();
        const osc = ctx.createOscillator(), gain = ctx.createGain();
        osc.connect(gain); gain.connect(ctx.destination);
        osc.frequency.value = 700; osc.type = 'sine';
        gain.gain.setValueAtTime(0.2, ctx.currentTime);
        gain.gain.exponentialRampToValueAtTime(0.01, ctx.currentTime + 0.3);
        osc.start(); osc.stop(ctx.currentTime + 0.3);
    } catch (e) {}
}
```

### 3.3 关键点

| 要点 | 说明 |
|------|------|
| 播放 API | 浏览器原生 `new Audio(url).play()` |
| 音频位置 | `dashboard2/static/sounds/*.mp3`，URL `/static/sounds/xxx.mp3` |
| 配置结构 | `SOUND_FILES` 映射表（对应后端 `sounds` 字典） |
| 预加载 | `_audioCache` 缓存 `Audio` 对象，避免首次播放卡顿 |
| 连续触发 | 播放前 `currentTime = 0` |
| 全局开关 | `localStorage` 持久化，按 `enabledKey` 区分不同功能的开关 |
| 降级 | `play()` 返回的 Promise catch → Web Audio 蜂鸣 |
| 异常隔离 | `try/catch` + Promise catch，不打断渲染 |

### 3.4 浏览器自动播放限制（重要）

浏览器要求**用户有过交互后**才允许自动播放音频。本项目场景天然满足——音效由用户**点击按钮**开启的功能触发，点击本身即完成"用户交互"授权。若某音效在无任何点击的纯自动场景播放，需在页面首次点击时静默 `play()` 一次并 `pause()` 以解锁。

### 3.5 新增前端音效步骤

1. 把 `.mp3` 放到 `dashboard2/static/sounds/`。
2. 在 `SOUND_FILES` 里登记：`新类型: '/static/sounds/xxx.mp3'`。
3. 在事件触发处调用 `playSound('新类型', '开关localStorage键')`。
4. 如需静音开关，加一个 UI 按钮 toggle 对应的 `localStorage` 键。

## 四、方式选择决策表

| 判断逻辑位置 | 服务机与用户机关系 | 选择方式 |
|--------------|-------------------|----------|
| 后端 Python | 服务=本机（脚本类） | **后端** winmm |
| 前端 JS | 任意（Web 页面） | **前端** Audio |
| 后端 Python | 服务与用户**可能分离** | **前端**（后端推事件，前端播） |

> 一句话：**Web 页面用前端方式，本机脚本用后端方式。** 判断在哪端就在哪端播。

## 五、音频文件规范

| 项 | 要求 |
|----|------|
| 格式 | `.mp3`（winmm 与浏览器均原生支持） |
| 前端存放 | `dashboard2/static/sounds/` |
| 后端存放 | 各模块自身目录（如 `scripts/huatai_trader/`） |
| 命名 | 语义化小写下划线，如 `zhongla.mp3`、`notify.mp3` |
| 时长 | 建议 ≤ 2 秒（提示音不宜过长） |
| 音量 | 生成时归一化，避免忽大忽小 |

### 5.1 语音音效生成（TTS）

项目 `.venv` 已装 `edge_tts`，可生成中文语音音效（如"中啦中啦"童声）：

```python
import asyncio, edge_tts
async def gen(text, out, rate='+15%', pitch='+50Hz', voice='zh-CN-XiaoyiNeural'):
    await edge_tts.Communicate(text, voice, rate=rate, pitch=pitch).save(out)
# zh-CN-XiaoyiNeural = 小艺女声，提高 pitch + 加快 rate 可得可爱童声效果
asyncio.run(gen('中啦中啦～', 'zhongla.mp3'))
```

> `edge_tts` 生成需联网；生成一次落地为文件后，运行期播放**不依赖网络**。
