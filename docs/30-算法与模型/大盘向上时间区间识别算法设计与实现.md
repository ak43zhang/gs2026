## 一、背景与需求

### 1.1 业务场景

在量化交易中，需要识别大盘（市场均值）的向上时间区间，用于：
- 验证大盘指标字段（mkt_weighted_slope_2m、mkt_change_1m_pct、mkt_price_acceleration）计算正确性
- 为交易策略提供大盘趋势判断依据
- 过滤噪音，识别真正有效的向上时段

### 1.2 核心挑战

- **数据特性**：大盘涨幅远小于个股/债券，1分钟涨幅通常在0.1%以内
- **噪音干扰**：短暂波动导致区间碎片化
- **阈值选择**：过于严格会漏识别，过于宽松会引入噪音

## 二、算法设计演进

### 2.1 初始方案（三条件判定）

`python
# 初始判定条件
is_up = (
    (mkt_weighted_slope_2m > 0.1) &      # 斜率>0.1
    (mkt_change_1m_pct > 0.05) &         # 涨幅>0.05%
    (mkt_price_acceleration > 0)         # 加速度>0
)
`

### 2.2 优化方案（加入时间连续性）

`python
# 优化后判定条件
is_up = (
    (mkt_weighted_slope_2m > 0.05) &     # 降低斜率阈值
    (mkt_change_1m_pct > 0.03) &         # 降低涨幅阈值
    (mkt_price_acceleration > -0.01)     # 允许轻微负加速度
)

# 时间连续性过滤
min_duration = 3  # 最少持续3分钟
`

## 三、实现细节

### 3.1 核心算法

`python
def detect_up_intervals(df, min_duration=3):
    \"\"\"
    检测大盘向上时间区间
    
    Args:
        df: DataFrame，包含大盘指标字段
        min_duration: 最小持续时间（分钟）
    
    Returns:
        list: 向上区间列表 [(start_time, end_time), ...]
    \"\"\"
    # 判定条件
    is_up = (
        (df['mkt_weighted_slope_2m'] > 0.05) &
        (df['mkt_change_1m_pct'] > 0.03) &
        (df['mkt_price_acceleration'] > -0.01)
    )
    
    # 标记连续区间
    df['up_group'] = (is_up != is_up.shift()).cumsum()
    
    # 过滤持续时间
    intervals = []
    for group_id, group_df in df[is_up].groupby('up_group'):
        if len(group_df) >= min_duration:
            intervals.append((
                group_df.index[0],
                group_df.index[-1]
            ))
    
    return intervals
`

### 3.2 参数调优

| 参数 | 初始值 | 优化值 | 说明 |
|------|--------|--------|------|
| 斜率阈值 | 0.1 | 0.05 | 降低敏感度 |
| 涨幅阈值 | 0.05% | 0.03% | 降低敏感度 |
| 加速度阈值 | 0 | -0.01 | 允许轻微回调 |
| 最小持续时间 | 3分钟 | 3分钟 | 过滤噪音 |

## 五、应用场景

### 5.1 交易信号过滤

`python
def filter_by_market_trend(signals, up_intervals):
    \"\"\"根据大盘趋势过滤交易信号\"\"\"
    filtered_signals = []
    for signal in signals:
        signal_time = signal['time']
        # 检查是否在向上区间内
        in_up_interval = any(
            start <= signal_time <= end
            for start, end in up_intervals
        )
        if in_up_interval:
            filtered_signals.append(signal)
    return filtered_signals
`

### 5.2 大盘指标验证

`python
def validate_mkt_fields(df, up_intervals):
    \"\"\"验证大盘指标字段计算正确性\"\"\"
    for start, end in up_intervals:
        interval_df = df.loc[start:end]
        # 验证斜率、涨幅、加速度的一致性
        slope_check = (interval_df['mkt_weighted_slope_2m'] > 0).mean()
        change_check = (interval_df['mkt_change_1m_pct'] > 0).mean()
        print(f\"区间 {start} - {end}: 斜率正率{slope_check:.1%}, 涨幅正率{change_check:.1%}\")
`
