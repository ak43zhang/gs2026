## 后端改造详情

### 文件
`src/gs2026/monitor/monitor_bond.py`

### 核心变更

#### 改造前
```python
# 查询全部记录
SELECT * FROM quant_screen_hits WHERE trade_date = :date

# 分类处理
- 已结算：跳过
- 持仓中：UPDATE current_price, current_return_pct
- 触发：UPDATE exit_*, is_locked
```

#### 改造后
```python
# 只查未结算
SELECT * FROM quant_screen_hits WHERE trade_date = :date AND is_locked = 0

# 只处理触发
- 已结算：不查询（不存在于结果中）
- 持仓中：不UPDATE
- 触发：UPDATE exit_*, is_locked
```

### 性能提升

| 指标 | 改造前 | 改造后 | 提升 |
|------|--------|--------|------|
| 每tick查询量 | 全部记录 | 未结算记录 | 减少50%+ |
| 每tick UPDATE | 持仓中+触发 | 仅触发 | 减少90%+ |
| 数据库压力 | 高 | 极低 | 显著降低 |

## 关键计算逻辑确认

### 触发优先级
1. 止盈（最高）
2. 止损
3. 超时（最低）

### 出场价取值
| 触发类型 | exit_price | 说明 |
|---------|-----------|------|
| 止盈 | `take_profit_price`（预设阈值） | 触发价计算 |
| 止损 | `stop_loss_price`（预设阈值） | 触发价计算 |
| 超时 | `current_price`（当时最新价） | 实际价格 |

### 盈/损统计
```
盈数 = 止盈触发 + (超时触发 AND 收益 >= 0)
损数 = 止损触发 + (超时触发 AND 收益 < 0)
持仓数 = is_locked = 0
```
