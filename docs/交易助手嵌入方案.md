# 交易助手嵌入 Monitor_bond 完整方案

## 一、方案概述

### 1.1 设计目标
- **最快响应**：在数据到达 monitor_bond 时立即处理，无需经过前端
- **完全可插拔**：不影响原有功能，可随时启用/禁用
- **方案过滤**：支持按方案名称过滤命中
- **多重通知**：支持声音、Windows弹窗、控制台日志

### 步骤4：在命中检测后调用

找到 `monitor_bond.py` 中命中检测的代码位置（通常在 `apply_scheme_conditions` 或类似的函数中），在检测到命中后添加：

```python
def on_bond_hit(bond_code, bond_name, price, scheme_name, **kwargs):
    """
    债券命中回调
    
    在检测到命中时调用，触发交易助手
    """
    global _trader_enabled, _trader_adapter
    
    if not _trader_enabled or not TRADER_CONFIG['enabled']:
        return
    
    try:
        # 调用交易助手
        result = _trader_adapter.on_hit(
            bond_code=bond_code,
            bond_name=bond_name,
            price=price,
            scheme_name=scheme_name,
            lots=TRADER_CONFIG.get('default_lots', 1)
        )
        
        if result:
            logger.info(f"[trader] 交易助手触发成功: {bond_code}")
        else:
            logger.debug(f"[trader] 交易助手未触发: {bond_code}")
            
    except Exception as e:
        logger.error(f"[trader] 交易助手调用失败: {e}")
```

## 四、通知方式详解

### 4.1 声音通知
- **触发时机**：命中通过风控检查后
- **声音类型**：Windows系统提示音
- **配置**：`'sound': True/False`

### 4.2 Windows弹窗通知
- **触发时机**：交易助手准备成功/失败
- **显示位置**：屏幕右下角
- **显示时长**：5秒
- **依赖**：需要安装 `win10toast`（可选）
- **安装**：`pip install win10toast`
- **配置**：`'windows_toast': True/False`

### 4.3 控制台日志
- **触发时机**：所有操作
- **日志级别**：INFO
- **配置**：`'console': True/False`

### 4.4 弹窗确认（交易助手自带）
- **触发时机**：调用交易助手HTTP接口后
- **显示位置**：屏幕右下角
- **超时时间**：30秒
- **交互**：用户点击"准备委托"或"忽略"

## 五、风控机制

### 5.1 方案过滤
- **白名单**：`allowed_schemes` - 只允许列表中的方案触发
- **黑名单**：`blocked_schemes` - 禁止列表中的方案触发
- **优先级**：白名单 > 黑名单（如果都在白名单，无视黑名单）

### 5.2 交易时段控制
- **允许时段**：09:30-11:30, 13:00-15:00
- **非时段处理**：直接跳过，不触发

### 5.3 单日限额
- **最大触发次数**：默认50次
- **计数重置**：每日自动重置

### 5.4 金额限制
- **单笔最小金额**：1000元
- **单笔最大金额**：100000元
- **价格有效范围**：50-200元

### 5.5 重复触发保护
- **同一债券间隔**：默认5分钟
- **缓存键**：`债券代码_日期`

```
   ↓
```

## 八、故障排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 交易助手服务未启动 | 8081端口被占用 | 检查端口占用，或修改配置端口 |
| 华泰软件未连接 | 软件未启动或未登录 | 启动华泰软件并登录 |
| 弹窗不显示 | 被其他窗口遮挡 | 检查屏幕右下角 |
| 方案过滤不生效 | 方案名称不匹配 | 检查配置中的方案名称是否准确 |
| 重复触发 | 间隔时间太短 | 调整 `min_interval_seconds` |
| 无声音提示 | 系统静音或配置关闭 | 检查系统音量和 `sound` 配置 |

## 九、安全声明

1. **不自动提交**：系统只填充委托信息，不自动点击"买入"
2. **不存储密码**：交易密码由用户在华泰软件中输入
3. **本地运行**：所有操作仅本地执行
4. **可审计**：所有操作记录日志
5. **风险自负**：使用者需自行承担交易风险
