# 大盘日内走势形态识别器设计方案

> 创建时间：2026-07-23  
> 状态：已实施（脚本已生成并验证）  
> 脚本：`scripts/detect_market_shape.py`

---

## 一、背景

当前 `detect_market_trend.py` 只能识别局部波动区间（向上/向下/震荡/过渡），回答"最近2分钟在涨还是跌"。

但**回答不了"今天整体是什么走势"**——单边下行、低开高走、V型反转、横盘震荡等**日内结构形态**。

这个脚本就是解决这个问题。

---

## 二、数据基础

```
数据源：monitor_zq_sssj_{date} 表的 ext_indicators JSON 列
核心字段：mkt_vs_open_pct（大盘相对开盘涨跌幅）
加载方式：取一只全天成交的债券（同一时刻大盘值相同），解析JSON
```

### 净值曲线

用 `mkt_vs_open_pct` 画出全天轨迹：
```
  涨跌幅(%)
    │
  +1% ┤                        ● (最高点)
    │  │  ┌──┐            ┌──┐
  0% ┼──┘  │   ────────┘  │      ● (收盘)
    │      │              │
 -1% ┤                        ● (最低点)
    └──────────────────────────────→ 时间
```

## 三、结构指标

```python
# 基于净值曲线自动计算
day_high_pct       # 日内最高涨幅
day_low_pct        # 日内最低跌幅
day_high_time      # 最高点时刻
day_low_time       # 最低点时刻
open_pct           # 开盘值(~0)
close_pct          # 收盘/当前值
total_range        # 全天振幅 = high - low
high_pos           # 最高点时间位置比例(0~1)
low_pos            # 最低点时间位置比例(0~1)

# 衍生量
recovery_from_low  # 从最低点回升 = close - low
drawdown_from_high # 从最高点回落 = high - close
down_leg           # 开盘到最低的下跌幅度
up_leg             # 开盘到最高的上涨幅度
```

## 四、7种形态判定（盘后模式）

### 判定优先级

```
1. 横盘震荡（振幅太小，无方向）
2. 单边下行（高点≈开盘，全程跌）
3. 单边上行（低点≈开盘，全程涨）
4. V型反转（最低点在中段）
5. 倒V(冲高回落)（最高点在中段）
6. 低开高走(反转向上)（低点在前半段）
7. 高开低走(反转向下)（真高开+高点在前半段）
8. 混合/震荡（兜底）
```

### 关键阈值（自适应，基于当天振幅R）

| 阈值 | 计算 | 说明 |
|------|------|------|
| 横盘 | R < 0.5% | 全天振幅过小 |
| 显著转折 | R × 0.5 | 超过振幅一半才算"有效转折" |
| 真高开/低开 | R × 0.3 | 最高/最低点距开盘超过30%振幅 |
| 接近开盘 | R × 0.2 | 最高/最低点距开盘不到20%振幅 |

### 各形态判定逻辑

| 形态 | 判定条件 |
|------|---------|
| **横盘震荡** | `total_range < 0.5%` |
| **单边下行** | `high < R×0.3(未冲高)` AND `close接近low(回落超R×0.5)` AND `low_pos>50%(低点在尾段)` |
| **单边上行** | `low > -R×0.3(未下探)` AND `close接近high(涨幅超R×0.5)` AND `high_pos>50%(高点在尾段)` |
| **V型反转** | `low_pos 25%~75%(中段)` AND `下跌段>R×0.5` AND `回升段>R×0.5` |
| **倒V** | `high_pos 25%~75%(中段)` AND `上涨段>R×0.5` AND `回落段>R×0.5` |
| **低开高走** | `low_pos < 50%(前半段)` AND `回升 > R×0.5` |
| **高开低走** | `high > R×0.3(真冲高)` AND `high_pos < 50%(前半段)` AND `回落 > R×0.5` |

## 五、盘中实时阶段判断

### 阶段机

基于"开盘到截止时刻"的数据，判断**当前处于什么阶段**：

| 阶段 | 判定条件 | 含义 |
|------|---------|------|
| **下行中** | 刚创最低点(`<3分钟`) 且 无回升 | 还在跌 |
| **上行中** | 刚创最高点(`<3分钟`) 且 无回落 | 还在涨 |
| **反转向上确认** | 脱离最低点>10分钟 且 回升>振幅50% | 可能真反转 |
| **反转向下确认** | 脱离最高点>10分钟 且 回落>振幅50% | 可能真反转 |
| **下行后反弹初期** | 脱离最低点3~10分钟 但回升不足50% | 可能是下跌中继反弹 |
| **上行后回落初期** | 脱离最高点3~10分钟 但回落不足50% | 可能是上涨中继回调 |
| **横盘** | 振幅<0.5% | 无方向 |

### 输出字段

```python
{
    'stage': '反转向上确认',
    'detail': '脱离最低点15分钟，回升0.8%(>0.75%)',
    'cur': -0.35,          # 当前涨跌幅
    'high': 0.12,          # 日内最高
    'low': -0.55,          # 日内最低
    'high_time': '09:35:00',
    'low_time': '11:20:00',
    'mins_since_low': 15,
    'mins_since_high': 230,
    'recovery': 0.80,
    'drawdown': 0.47,
}
```

## 六、命令行使用

```bash
# 盘后：识别整天走势形态
python scripts/detect_market_shape.py 20260713 --mode eod

# 盘中：判断某时刻的阶段（回溯测试）
python scripts/detect_market_shape.py 20260713 --mode realtime --time 13:30

# 直接修改CONFIG运行
python scripts/detect_market_shape.py
```

### CONFIG参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `date` | '20260713' | 分析日期 |
| `mode` | 'eod' | eod盘后形态 / realtime盘中阶段 |
| `realtime_time` | '13:30' | 盘中模式的截止时刻 |
| `flat_range` | 0.5 | 横盘振幅阈值% |
| `significant_ratio` | 0.5 | 显著转折占全天振幅比例 |
| `breakout_ratio` | 0.3 | 真高开/低开占全天振幅比例 |
| `edge_ratio` | 0.2 | 极值接近开盘容差比例 |
| `rt_confirm_minutes` | 10 | 反转确认所需持续分钟 |
| `rt_just_extreme_min` | 3 | 极值"刚创出"的分钟界限 |

## 八、与其他脚本的关系

| 脚本 | 定位 | 回答的问题 |
|------|------|-----------|
| `detect_market_trend.py` | **局部区间识别** | 最近2分钟在涨还是跌？有多少时间在趋势中？ |
| `detect_market_shape.py` | **全局形态分类** | 今天整体是什么走势？单边/反转/震荡？ |
| `detect_market_up.py` | (已废弃，功能合并到trend) | — |

**配合使用**：
1. 先用 `detect_market_shape.py` 判断"今天是什么走势"
2. 再用 `detect_market_trend.py` 找到具体的向上/向下区间
3. 最后用 `detect_market_shape.py --mode realtime` 盘中确认当前阶段

---

## 九、局限与注意事项

1. **盘中无法预测未来**：实时阶段只是描述当前状态，不能保证"反转确认后一定继续涨"
2. **形态的模糊地带**：比如早盘冲高0.3%之后回落，到底算"高开低走"还是"单边下行带小反弹"——这在形态学中本就是连续的，判定有主观成分
3. **V型/倒V依赖振幅**：如果全天振幅只有0.3%，判定会偏保守（因为显著转折门槛低）
