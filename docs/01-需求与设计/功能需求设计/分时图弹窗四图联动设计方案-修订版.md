# 分时图弹窗优化：四图联动设计方案（修订版）

## 展示内容

1. **大盘均值分时图**：所有股票每个时间点的 change_pct 平均值
2. **行业均值分时图**：该股票所属行业内所有股票每个时间点的 change_pct 平均值
3. **正股分时图**
4. **转债分时图**（无转债时隐藏，其他3个占满）

## 数据计算逻辑

### 大盘均值
```sql
-- 从 monitor_gp_sssj_{date} 按时间分组求平均
SELECT time, AVG(change_pct) as avg_change_pct
FROM monitor_gp_sssj_{date}
WHERE time >= '09:30:00'
GROUP BY time
ORDER BY time ASC
```

### 行业均值
```sql
-- 先获取该股票的行业
-- 再获取同行业所有股票代码
-- 按时间分组求平均
SELECT t.time, AVG(t.change_pct) as avg_change_pct
FROM monitor_gp_sssj_{date} t
WHERE t.stock_code IN (同行业股票代码列表)
  AND t.time >= '09:30:00'
GROUP BY t.time
ORDER BY t.time ASC
```

## 性能考虑

大盘均值和行业均值的 SQL 查询可能较慢（90万行 GROUP BY），优化方案：
1. **缓存**：大盘均值每个时间点只需算一次，可以缓存
2. **Redis 优先**：如果 Redis 中有按时间点存储的统计数据，直接使用
3. **采样**：先 SQL 计算全量，再在前端采样到300点
