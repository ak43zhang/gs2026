# 斜率指标统一计算函数重构与多窗口扩展设计

> 版本: v1.0  
> 日期: 2026-07-17  
> 状态: 待实施

---

## 一、背景与问题

### 1.1 当前问题

1. **代码重复**: `monitor_bond.py`（实时）和 `backfill_unified.py`（回填）各自独立实现了斜率计算逻辑，修改一处不会同步另一处
2. **指标不足**: 只有2分钟窗口斜率，无法区分"真上涨"和"下跌中的短暂反弹"
3. **维护成本高**: 新增指标需要改两个文件，容易遗漏导致实时和历史数据不一致

### 1.2 业务需求

| 需求 | 说明 |
|------|------|
| 多窗口趋势判断 | 15分钟控制大方向，5分钟控制中期方向，2分钟捕捉入场时机 |
| 个股+大盘双维度 | 既看个股自身趋势，也看市场整体环境 |
| 一处修改全局生效 | 新增/修改指标只改一个函数，实时和回填自动同步 |

## 二、指标设计

### 2.1 完整指标清单

#### 个券指标

| 字段名 | 中文名 | 窗口 | half_life | 最少数据点 | 说明 |
|--------|--------|------|-----------|-----------|------|
| `weighted_slope_2m` | 加权斜率(2m) | 2分钟 | 30s | 5 | 短期趋势(已有) |
| `weighted_slope_5m` | 加权斜率(5m) | 5分钟 | 60s | 10 | 中期趋势 **新增** |
| `weighted_slope_15m` | 加权斜率(15m) | 15分钟 | 180s | 20 | 中长期趋势 **新增** |
| `change_1m_pct` | 1分钟涨幅% | 1分钟 | - | 2 | 即时涨幅(已有) |
| `price_acceleration` | 价格加速度 | - | - | - | 斜率差分(已有) |

#### 大盘指标

| 字段名 | 中文名 | 窗口 | half_life | 最少数据点 | 说明 |
|--------|--------|------|-----------|-----------|------|
| `mkt_weighted_slope_2m` | 大盘加权斜率(2m) | 2分钟 | 30s | 5 | 短期大盘(已有) |
| `mkt_weighted_slope_5m` | 大盘加权斜率(5m) | 5分钟 | 60s | 10 | 中期大盘 **新增** |
| `mkt_weighted_slope_15m` | 大盘加权斜率(15m) | 15分钟 | 180s | 20 | 中长期大盘 **新增** |
| `mkt_change_1m_pct` | 大盘1分钟涨幅% | 1分钟 | - | 2 | 即时大盘涨幅(已有) |
| `mkt_price_acceleration` | 大盘价格加速度 | - | - | - | 大盘斜率差分(已有) |

### 2.2 参数设计依据

| 窗口 | half_life | 有效响应延迟 | 设计意图 |
|------|-----------|-------------|----------|
| 2分钟 | 30s | ~30秒 | 快速捕捉短期动量变化 |
| 5分钟 | 60s | ~1分钟 | 中期趋势确认，过滤1-2分钟噪音 |
| 15分钟 | 180s | ~3分钟 | 大方向判断，过滤5分钟级别波动 |

> **half_life的含义**: 距当前时间 half_life 秒之前的数据点权重衰减到50%。  
> half_life越大 → 越多历史数据参与 → 越稳定但越滞后

### 2.3 多窗口配合逻辑

```
15分钟斜率 > 0  →  大方向上涨（过滤下跌中的反弹）
 + 5分钟斜率 > 0  →  中期确认上涨
  + 2分钟斜率 > 0.1 →  短期有强动量 → 入场!

15分钟斜率 > 0 但 2分钟斜率 < 0  →  大方向上涨，短期回调 → 不入场，等待
15分钟斜率 < 0 且 2分钟斜率 > 0  →  下跌中反弹 → 过滤！
```

## 三、架构设计

### 3.1 统一函数设计

在 `monitor_bond.py` 中定义两个统一计算函数：

```python
def calc_bond_ext_indicators(price_history, prev_slope=None):
    """
    【统一个券扩展指标计算函数】
    
    参数:
        price_history: deque/list of (timestamp_float, price_float)
                       时间升序排列的价格序列
                       调用方需确保数据窗口足够(建议保留15分钟以上)
        prev_slope: float or None
                    上一tick的 weighted_slope_2m，用于计算 price_acceleration
                    首次调用传 None
    
    返回: dict
        {
            'weighted_slope_2m': float | None,    # 加权斜率(2m)
            'weighted_slope_5m': float | None,    # 加权斜率(5m)
            'weighted_slope_15m': float | None,   # 加权斜率(15m)
            'change_1m_pct': float | None,        # 1分钟涨幅%
            'price_acceleration': float | None,   # 价格加速度
        }
    
    计算逻辑:
        1. 从 price_history 尾部取最近 N 秒数据
        2. 调用 _calc_weighted_slope 计算各窗口斜率
        3. 计算 change_1m_pct = (当前价 - 60秒前价) / 60秒前价 × 100
        4. 计算 acceleration = 当前slope_2m - prev_slope
    
    调用方:
        - monitor_bond.py 实时计算 (每tick ~3秒调用一次)
        - backfill_unified.py 历史回填 (逐行调用)
    """

def calc_mkt_ext_indicators(mkt_price_history, prev_slope=None):
    """
    【统一大盘扩展指标计算函数】
    
    参数:
        mkt_price_history: deque/list of (timestamp_float, mkt_avg_price_float)
                           时间升序排列的大盘均价序列
                           调用方需确保数据窗口足够(建议保留15分钟以上)
        prev_slope: float or None
                    上一tick的 mkt_weighted_slope_2m
    
    返回: dict
        {
            'mkt_weighted_slope_2m': float | None,    # 大盘加权斜率(2m)
            'mkt_weighted_slope_5m': float | None,    # 大盘加权斜率(5m)
            'mkt_weighted_slope_15m': float | None,   # 大盘加权斜率(15m)
            'mkt_change_1m_pct': float | None,        # 大盘1分钟涨幅%
            'mkt_price_acceleration': float | None,   # 大盘价格加速度
        }
    
    调用方: 同上
    """
```

### 3.2 调用关系

```
monitor_bond.py
├── _calc_weighted_slope(prices, times, half_life)  ← 底层EWLR算法
├── calc_bond_ext_indicators(history, prev)          ← 统一个券计算
├── calc_mkt_ext_indicators(history, prev)           ← 统一大盘计算
│
├── [实时] compute_ext_indicators(df_now)
│       维护 _price_cache (per-bond deque)
│       调用 calc_bond_ext_indicators()
│
└── [实时] compute_mkt_ext_indicators(df_now)
        维护 _mkt_price_cache (单个deque)
        调用 calc_mkt_ext_indicators()

backfill_unified.py
├── from gs2026.monitor.monitor_bond import (
│       calc_bond_ext_indicators,
│       calc_mkt_ext_indicators
│   )
├── backfill_ext_indicators():  构建缓存 → 调用 calc_bond_ext_indicators()
└── backfill_mkt_ext_indicators(): 构建缓存 → 调用 calc_mkt_ext_indicators()
```

### 3.3 缓存设计

| 缓存 | 作用 | maxlen | 保留时间 | 内存 |
|------|------|--------|----------|------|
| `_price_cache[code]` | 个券价格序列 | 300 | 900s(15min) | 400×300×16B = **1.9MB** |
| `_mkt_price_cache` | 大盘均价序列 | 300 | 900s(15min) | 300×16B = **5KB** |

> 较之前(maxlen=60, 150s)，个券缓存扩大5倍，内存从0.4MB增至1.9MB，完全可接受

## 四、前端字段对照表

### 4.1 回测条件可用字段

| 字段名 | 前端中文名 | 典型范围 | 回测条件示例 |
|--------|-----------|----------|-------------|
| `weighted_slope_2m` | 加权斜率(2m) | -0.3 ~ +0.3 | > 0.1 (短期强势) |
| `weighted_slope_5m` | 加权斜率(5m) | -0.2 ~ +0.2 | > 0.05 (中期上涨) |
| `weighted_slope_15m` | 加权斜率(15m) | -0.15 ~ +0.15 | > 0 (大方向向上) |
| `change_1m_pct` | 1分钟涨幅% | -1.0 ~ +1.0 | > 0.1 |
| `price_acceleration` | 价格加速度 | -0.1 ~ +0.1 | > 0 (加速中) |
| `mkt_weighted_slope_2m` | 大盘加权斜率(2m) | -0.2 ~ +0.2 | > 0.03 |
| `mkt_weighted_slope_5m` | 大盘加权斜率(5m) | -0.15 ~ +0.15 | > 0.02 |
| `mkt_weighted_slope_15m` | 大盘加权斜率(15m) | -0.1 ~ +0.1 | > 0 (大盘方向向上) |
| `mkt_change_1m_pct` | 大盘1分钟涨幅% | -0.5 ~ +0.5 | > -0.1 |
| `mkt_price_acceleration` | 大盘价格加速度 | -0.05 ~ +0.05 | > 0 |

### 4.2 常用策略组合

| 策略 | 条件 | 效果 |
|------|------|------|
| 大方向+短期动量 | `mkt_weighted_slope_15m > 0` AND `weighted_slope_2m > 0.1` | 只在大盘上涨中捕捉强势票 |
| 三窗口共振 | `weighted_slope_15m > 0` AND `weighted_slope_5m > 0.05` AND `weighted_slope_2m > 0.1` | 个股三级趋势全部向上 |
| 过滤反弹 | `mkt_weighted_slope_15m > 0` AND `mkt_weighted_slope_5m > 0` | 确保不是下跌中的反弹 |
| 逆势强票 | `mkt_weighted_slope_15m < -0.02` AND `weighted_slope_5m > 0.05` | 大盘跌但个股依然上涨 |
| 加速突破 | `weighted_slope_5m > 0.05` AND `price_acceleration > 0.02` | 中期上涨且正在加速 |

## 五、数据有效性

### 5.1 Warmup 时间

| 指标 | 最早有效时间 | 说明 |
|------|-------------|------|
| `weighted_slope_2m` | 开盘后~15秒(5个点) | 很快生效 |
| `weighted_slope_5m` | 开盘后~30秒(10个点) | 较快生效 |
| `weighted_slope_15m` | 开盘后~60秒(20个点) | 约1分钟后有值 |

> 注: 虽然15分钟窗口需要15分钟数据最优，但20个点(~60秒)即可产出有效值(精度较低)。  
> 真正稳定的15分钟斜率需在9:45之后。条件设置时建议配合 time_start ≥ 09:45:00。

### 5.2 回填覆盖

| 场景 | 是否自动覆盖 |
|------|-------------|
| 新增指标后跑 backfill | ✅ 自动填充所有新字段 |
| 历史数据每天前60秒 | ⚠️ 15m斜率精度较低，正常现象 |
| 跨天无连续性 | ✅ 每天独立计算，不跨天 |
