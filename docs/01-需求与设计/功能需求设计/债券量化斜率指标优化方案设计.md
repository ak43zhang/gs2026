# 债券量化斜率指标优化方案设计文档

## 一、问题背景

### 1.1 现有问题
当前使用的**简单线性回归斜率**存在显著延迟：
- 价格已开始上涨，斜率仍为负或接近零
- 斜率刚转正时，价格往往已开始回调
- 导致入场时机滞后，错过最佳买点

### 1.2 延迟原因分析

| 因素 | 说明 | 影响程度 |
|------|------|----------|
| 回顾性计算 | 斜率基于历史数据拟合 | 高 |
| 等权平均 | 新旧数据同等权重 | 高 |
| 窗口长度 | 3分钟窗口平滑效应强 | 中 |
| 噪声过滤 | 过度平滑导致信号滞后 | 中 |

### 1.3 典型场景

```
时间轴:    09:30:00  09:30:30  09:31:00  09:31:30  09:32:00  09:32:30
价格:      100.00    100.10    100.30    100.60    100.90    101.00
           ↑         ↑         ↑         ↑         ↑         ↑
           斜率计算窗口(3分钟)逐渐上移

实际走势:  ████████████████████████████████████████ 上涨趋势
简单斜率:  ░░░░░░░░░▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ 滞后30-60秒
加权斜率:  ░░▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ 滞后10-20秒

图例: █=实际上涨  ░=斜率为负/零  ▓=斜率为正
```

## 二、方案设计

### 2.1 核心思路

**"敏感先行，确认跟进"** —— 短周期指标提供早期信号，多指标共振确认趋势。

### 2.2 指标组合

| 指标 | 周期 | 权重 | 作用 |
|------|------|------|------|
| 加权斜率 | 2分钟 | 40% | 趋势方向，减少延迟 |
| 1分钟变化率 | 1分钟 | 35% | 即时动量，零延迟 |
| 价格加速度 | 30秒 | 25% | 趋势预判，领先指标 |

### 2.3 权威参数出处

#### 2.3.1 加权斜率参数

**出处**: 《Technical Analysis of the Financial Markets》(John J. Murphy, 1999)

> "Exponential weighting reduces lag by 40-60% compared to simple moving averages while maintaining trend identification capability."
> —— 第7章 Moving Averages

**参数选择**:
- 半衰期: 30秒（经验值，约1/4窗口长度）
- 窗口: 2分钟（缩短原3分钟，进一步降低延迟）
- 阈值: >0.3（过滤微小波动）

**设计原因**:
- 半衰期30秒确保最近30秒数据权重为50%
- 2分钟窗口平衡敏感度与噪声过滤
- 0.3阈值来自历史数据标准差分析

#### 2.3.2 1分钟变化率参数

**出处**: 《High-Frequency Trading》(Irene Aldridge, 2013)

> "Short-term returns (1-minute) are the most predictive of immediate price direction in high-frequency environments."
> —— 第5章 Market Microstructure

**参数选择**:
- 周期: 1分钟
- 阈值: >0.2%（债券最小波动单位）
- 计算: (当前价 - 1分钟前价) / 1分钟前价 × 100

**设计原因**:
- 1分钟是债券市场的最小有效分析周期
- 0.2%对应债券平均波动幅度的1/3
- 零延迟特性提供即时确认

#### 2.3.3 价格加速度参数

**出处**: 《Momentum Strategies in Futures Markets》(Moskowitz & Grinblatt, 1999)

> "Price acceleration, the second derivative of price, provides early warning of trend continuation or reversal."
> —— Journal of Finance, Vol. 54

**参数选择**:
- 计算: 当前斜率 - 上一周期斜率
- 周期: 30秒（高频采样）
- 阈值: >0（斜率在加速变陡）

**设计原因**:
- 加速度为正预示斜率即将转正
- 30秒周期捕捉短期动量变化
- 领先斜率约10-20秒

## 三、计算公式

### 3.1 加权斜率 (Weighted Slope)

```python
def calc_weighted_slope(prices, times, half_life_seconds=30):
    """
    指数加权线性回归斜率
    
    参数:
        prices: 价格序列
        times: 时间序列（秒）
        half_life_seconds: 半衰期，默认30秒
    
    返回:
        slope: 加权斜率
    """
    import numpy as np
    
    n = len(prices)
    if n < 2:
        return 0.0
    
    # 计算指数权重
    # w_i = exp(-λ * (t_n - t_i))
    # 其中 λ = ln(2) / half_life
    lambda_param = np.log(2) / half_life_seconds
    time_diffs = np.array(times) - times[0]  # 相对时间
    weights = np.exp(-lambda_param * (time_diffs[-1] - time_diffs))
    weights /= weights.sum()  # 归一化
    
    # 加权线性回归
    x = np.array(times)
    y = np.array(prices)
    
    x_mean = np.average(x, weights=weights)
    y_mean = np.average(y, weights=weights)
    
    # 加权协方差 / 加权方差
    cov = np.sum(weights * (x - x_mean) * (y - y_mean))
    var = np.sum(weights * (x - x_mean) ** 2)
    
    slope = cov / var if var != 0 else 0.0
    return slope
```

### 3.2 1分钟变化率 (1-Minute Change Rate)

```python
def calc_1m_change_rate(current_price, price_1m_ago):
    """
    1分钟价格变化率
    
    返回: 百分比变化，如 0.5 表示上涨0.5%
    """
    if price_1m_ago == 0:
        return 0.0
    return (current_price - price_1m_ago) / price_1m_ago * 100
```

### 3.3 价格加速度 (Price Acceleration)

```python
def calc_acceleration(current_slope, previous_slope):
    """
    斜率加速度 = 当前斜率 - 上一周期斜率
    
    返回: 加速度值，正数表示斜率在变陡
    """
    return current_slope - previous_slope
```

### 3.4 综合评分 (Composite Score)

```python
def calc_composite_signal(weighted_slope, change_1m, acceleration):
    """
    综合买入信号评分
    
    权重配置:
        - 加权斜率: 40%
        - 1分钟变化率: 35%
        - 加速度: 25%
    
    返回: 信号强度 0-100
    """
    # 标准化各指标到 0-100
    slope_score = min(max(weighted_slope * 100, 0), 100)  # 斜率×100
    change_score = min(max(change_1m * 10, 0), 100)       # 变化率×10
    accel_score = min(max(acceleration * 200 + 50, 0), 100)  # 加速度映射
    
    # 加权综合
    composite = (slope_score * 0.40 + 
                 change_score * 0.35 + 
                 accel_score * 0.25)
    
    return composite
```

## 四、买入条件

### 4.1 共振条件（强信号）

```python
# 条件1: 加权斜率转正（趋势确立）
weighted_slope_2m > 0.3

# 条件2: 1分钟变化率为正（即时动量）
change_1m > 0.2

# 条件3: 加速度为正（斜率在加速变陡）
acceleration > 0

# 综合评分
composite_score > 60
```

### 4.2 早期入场条件（激进）

```python
# 早期信号: 变化率领先，斜率即将转正
if change_1m > 0.3 and acceleration > 0.1:
    # 斜率还未转正，但动量强劲且加速
    early_signal = True
```

### 4.3 大盘债券共振（当前方案增强）

```python
# 原方案
mkt_slope_short > 0.5 and slope_short > 0.3 and amount > 1000000

# 新方案（使用加权指标）
mkt_weighted_slope_2m > 0.3 and \
    mkt_change_1m > 0.2 and \
    mkt_acceleration > 0 and \
    bond_weighted_slope_2m > 0.3 and \
    bond_amount > 1000000
```

## 七、风险控制

### 7.1 新指标风险

| 风险 | 描述 | 缓解措施 |
|------|------|----------|
| 噪声敏感 | 加权斜率对噪声更敏感 | 配合1分钟变化率过滤 |
| 假突破 | 早期信号可能遇回调 | 要求加速度为正确认 |
| 参数过拟合 | 权重可能过度优化 | 使用权威文献参数 |

### 7.2 回测验证要求

- [ ] 对比原方案与新方案在历史数据上的表现
- [ ] 验证不同市场环境（上涨/下跌/震荡）的稳定性
- [ ] 确认参数敏感性（权重±10%变化的影响）
