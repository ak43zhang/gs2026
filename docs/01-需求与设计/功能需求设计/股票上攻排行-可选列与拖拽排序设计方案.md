## 一、背景与需求

### 1.1 现状
股票上攻排行固定8列，列顺序和显隐硬编码在 `renderRanking()` 函数中：

| # | 字段名 | 表头 | 说明 |
|---|--------|------|------|
| 1 | `#` | # | 排名 |
| 2 | `code` | 代码 | 股票代码 |
| 3 | `name` | 名称 | 股票名称 |
| 4 | `change_pct` | 涨跌幅 | 可排序 |
| 5 | `count` | 次数 | 可排序 |
| 6 | `main_net_amount` | 主力净额 | 可排序 |
| 7 | `bond_code` + `bond_name` | 债券代码 + 债券名称 | 两列 |
| 8 | `industry` | 行业 | 可排序 |

### 1.2 需求
1. 后续可能增加十几个计算列
2. 列可选（显隐切换）
3. 列可拖拽排序
4. 列太多时可横向滚动
5. 固定列（#、代码、名称）始终可见

## 二、架构设计

### 2.1 列配置对象

```javascript
const STOCK_COLUMNS = [
    // 固定列（不可隐藏、不可拖动）
    { key: '#',       label: '#',       fixed: true },
    { key: 'code',    label: '代码',    fixed: true },
    { key: 'name',    label: '名称',    fixed: true },
    // 可选列（可隐藏、可拖动、可排序）
    { key: 'change_pct',      label: '涨跌幅',   sortable: true, default: true },
    { key: 'count',           label: '次数',     sortable: true, default: true },
    { key: 'main_net_amount', label: '主力净额',  sortable: true, default: true },
    { key: 'bond_code',       label: '债券代码',  sortable: true, default: true },
    { key: 'bond_name',       label: '债券名称',  sortable: false, default: true },
    { key: 'industry',        label: '行业',     sortable: true, default: true },
    // 未来新增列只需在此追加
];
```

### 2.2 用户配置持久化

```javascript
const COL_STORAGE_KEY = 'stock_ranking_columns_v1';
// 存储格式：[{key: 'change_pct', visible: true}, ...]
// 保存到 localStorage
```

### 2.3 核心函数

| 函数 | 说明 |
|------|------|
| `getStockColConfig()` | 读取用户列配置（合并新增列） |
| `saveStockColConfig(cfg)` | 保存列配置到localStorage |
| `getVisibleStockCols()` | 获取当前可见列（按用户顺序） |
| `toggleColSettings(e)` | 打开/关闭列设置面板 |
| `renderColSettingsPanel()` | 渲染设置面板（checkbox + 拖拽） |
| `onColVisibleChange(key, visible)` | 列显隐切换回调 |
| `bindColDragEvents()` | 绑定HTML5拖拽事件 |
| `renderStockCell(col, item, sortSt)` | 按列key渲染单元格 |

## 三、UI设计

### 3.1 列设置面板

```
┌──────────────────┐
│ 列设置（拖拽排序）│
├──────────────────┤
│ ☑ 涨跌幅     ≡  │  ← 勾选控制显隐
│ ☑ 次数       ≡  │  ← ≡ 可拖拽排序
│ ☑ 主力净额   ≡  │
│ ☑ 债券代码   ≡  │
│ ☑ 债券名称   ≡  │
│ ☑ 行业       ≡  │
└──────────────────┘
```

### 3.2 横向滚动

- 固定列（#、代码、名称）使用 `position: sticky`
- 可选列区域 `overflow-x: auto` 可左右滑动
- 固定列右侧有阴影分隔线

### 3.3 触发方式

- 点击 ⚙️ 图标弹出设置面板
- 点击遮罩层关闭面板

## 五、拖拽排序实现

使用 HTML5 原生 Drag & Drop API：
- `draggable="true"` 使列项可拖动
- `dragstart` → 记录拖动源索引
- `dragover` → 允许放置 + 高亮目标
- `drop` → 重排配置数组 + 保存 + 重新渲染
- 不引入新框架

## 六、新增列流程

后续新增一个计算列只需3步：

```javascript
// 1. 在 STOCK_COLUMNS 中追加
{ key: 'turnover_rate', label: '换手率', sortable: true, default: false }

// 2. 在 renderStockCell() 中添加渲染逻辑
case 'turnover_rate':
    return `<td>${item.turnover_rate ? item.turnover_rate.toFixed(2) + '%' : '-'}</td>`;

// 3. 后端API返回该字段
```
