**设计日期**: 2026-07-10  
**设计人**: AI Assistant  
**状态**: 已审核通过，待实施

---

## 一、需求背景

### 1.1 当前痛点
- 单日回测无法评估策略在区间内的稳定性
- 重复回测相同参数浪费计算资源
- 无法快速对比历史回测结果

### 1.2 目标
- 支持日期区间回测（自动识别交易日）
- 智能缓存机制（相同参数直接返回结果）
- 历史记录管理（前10次回测快速加载）

## 三、关键决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 日期参数格式 | `date_start` + `date_end` | 清晰明确，支持单日和区间 |
| 最大回测区间 | 30天 | 防止性能问题，前端限制 |
| 跨日持仓 | 不支持 | 简化逻辑，每日独立计算 |
| 缓存存储 | Redis | TTL 7天，支持分布式 |
| 历史记录 | 前10条 | 前端列表展示，点击加载 |
| 并行执行 | ThreadPoolExecutor(4) | IO密集型，4线程平衡性能和资源 |

## 四、数据结构设计

```

TTL: 7天

Hash 计算：SHA256(参数JSON，排序后)
参数包括：
  - conditions, tp_pct, sl_pct, window_minutes
  - dedup, time_start, time_end
  - price_offset, offset_mode
  - date_start, date_end
  - timeline_mode, initial_capital

Value 结构：
{
    "meta": {
        "created_at": "2026-07-10T05:30:00",
        "hash": "sha256_hash",
        "params": { /* 完整参数 */ }
    },
    "result": {
        "summary": { /* 汇总结果 */ },
        "trades": [ /* 交易明细 */ ],
        "daily_results": [ /* 每日明细 */ ]
    }
}
```

## 五、API 设计

### 5.1 执行回测（修改）

```http
POST /api/monitor/backtest/bond

Request:
{
    "date_start": "20260701",           // 新增：开始日期
    "date_end": "20260710",             // 新增：结束日期（可选，不传则单日）
    "conditions": [...],
    "take_profit_pct": 0.5,
    "stop_loss_pct": 0.3,
    "window_minutes": 5,
    "dedup": "first_per_minute",
    "time_start": "09:30:00",
    "time_end": "15:00:00",
    "price_offset": 0.0,
    "offset_mode": "fixed",
    "timeline_mode": false,
    "initial_capital": 1000000,
    "return_calc_method": "compound"
}

Response:
{
    "success": true,
    "cached": false,                    // 新增：是否命中缓存
    "cache_hash": "sha256_hash",        // 新增：缓存标识
    "summary": {
        "mode": "range",                 // range 或 timeline
        "date_start": "20260701",
        "date_end": "20260710",
        "trade_days": 8,
        "total_signals": 156,
        "avg_daily_signals": 19.5,
        "win_rate": 62.5,
        "profit_factor": 2.3,
        "total_return_pct": 12.5,
        "return_volatility": 3.2,        // 收益波动率
        "max_consecutive_loss_days": 2, // 最大连续亏损天数
        "daily_results": [               // 每日明细
            {
                "date": "20260701",
                "total_signals": 20,
                "tp_count": 12,
                "sl_count": 5,
                "timeout_count": 3,
                "daily_return_pct": 1.5
            }
        ]
    },
    "trades": [ /* 所有交易明细 */ ]
}
```

## 六、后端实现

### 6.1 新增文件清单

| 文件 | 功能 |
|------|------|
| `backtest_cache.py` | 缓存管理类（BacktestCache） |

### 6.2 修改文件清单

| 文件 | 修改内容 |
|------|----------|
| `backtest_bond.py` | 新增区间回测函数、交易日历查询、结果汇总 |
| `monitor.py` | 新增API路由、修改回测接口、缓存集成 |

### 6.3 核心函数

#### `run_bond_backtest_range()`
区间回测主入口，并行执行多日回测，汇总结果。

#### `get_trade_dates()`
从 `data_jyrl` 表查询区间内的交易日。

#### `aggregate_range_results()`
汇总多日回测结果，计算跨日指标（波动率、连续亏损等）。

#### `BacktestCache` 类
- `compute_hash()`: 计算参数哈希
- `get()`: 获取缓存
- `set()`: 写入缓存并更新历史
- `get_history()`: 获取历史列表
- `delete_history()`: 删除历史
