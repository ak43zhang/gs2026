# 债券趋势指标设计 — 双窗口斜率 + 放量高点偏离 + 日内高点距离

## 文档信息
- **创建日期**: 2026-07-08
- **功能位置**: 监控采集（monitor_bond.py）+ 量化回测条件
- **数据表**: `monitor_zq_sssj_{date}`

---

## 一、需求背景

### 核心目标
在债券sssj表中增加趋势类指标，用于量化回测的入场条件筛选：
1. 判断当前债券是在**真正上涨**还是**下跌中的小反弹**
2. 判断是否已有**前期放量大高点**（冲高回落场景）
3. 所有指标必须**增量计算**，每tick O(1)，零IO

### 需要解决的问题

| 问题 | 说明 |
|------|------|
| 趋势 vs 反弹 | 3分钟涨不代表大趋势向上，可能只是回落中的小反弹 |
| 开盘前10分钟有效性 | 大部分行情在前10分钟发生，指标必须在此期间有效 |
| 程序宕机恢复 | 内存缓存丢失后必须能自愈 |
| Redis不可用 | 指标计算不能依赖Redis |

## 二、指标设计

### 新增4个字段

| 字段名 | 类型 | 含义 | 窗口 | 开盘后有效时间 |
|--------|------|------|------|--------------|
| `slope_short` | DOUBLE | 3分钟滚动线性回归斜率 | 60 tick | 3分钟 |
| `slope_long` | DOUBLE | 15分钟滚动线性回归斜率 | 300 tick | 15分钟 |
| `peak_vol_bias` | DOUBLE | 放量高点偏离度(%) | 全天累积 | 即时 |
| `high_distance` | DOUBLE | 日内最高点距离(%) | 全天累积 | **即时** |

---

### 2.1 `slope_short` — 3分钟滚动斜率

**定义**: 最近60个tick的 change_pct 线性回归斜率

**数学公式**:
```
给定窗口内数据点 (x_i, y_i), x_i=0,1,...,n-1, y_i=change_pct

slope = (n·Σ(x_i·y_i) - Σx_i·Σy_i) / (n·Σ(x_i²) - (Σx_i)²)

由于x是等差序列0..n-1:
  Σx = n(n-1)/2
  Σx² = n(n-1)(2n-1)/6
```

**含义**:
- slope_short > 0: 近3分钟涨幅在增大（近期向上）
- slope_short < 0: 近3分钟涨幅在减小（近期向下）
- |slope_short| 越大: 动量越强

**实现**: 定长队列 deque(maxlen=60)，每tick append新值，自动弹出旧值

---

### 2.2 `slope_long` — 15分钟滚动斜率

**定义**: 最近300个tick的 change_pct 线性回归斜率

**含义**: 中期趋势方向。与 slope_short 组合可区分"真趋势"和"小反弹"

**开盘前15分钟的行为**: 
- 窗口未满时，基于所有已有数据计算（等同于"开盘至今斜率"）
- 数学上斜率值不受样本量影响（同一趋势下100点和300点算出的斜率一致）
- 不满窗口 ≠ 不准确，只是等效窗口更短

---

### 2.3 `peak_vol_bias` — 放量高点偏离度

**定义**: 当前价格相对于今日最大成交额时刻价格的偏离百分比

**公式**:
```
peak_vol_bias = (current_price - price_at_max_volume) / price_at_max_volume × 100
```

**含义**:
- ≈ 0: 当前就在放量最大的位置
- < 0: 当前价格低于前期放量高点（冲高回落场景）
- > 0: 当前价格高于前期放量点（放量在低位，后续上涨）

**实现**: 每tick比较 amount 与 max_amount，更新时记录对应price

---

### 2.4 `high_distance` — 日内最高点距离

**定义**: 当前涨跌幅与今日最高涨跌幅的差值

**公式**:
```
max_change_pct = max(所有历史tick的change_pct)  // 每tick增量更新
high_distance = current_change_pct - max_change_pct
```

**含义**:
- = 0: 当前正在创日内新高
- < 0: 已从日内最高点回落（值越小回落越深）

**核心价值**: **开盘第1个tick即有效**，不需要任何历史窗口。可在开盘前10分钟替代slope_long判断是否在真正上涨。

## 三、组合判断逻辑

### 3.1 场景识别表

| slope_long | slope_short | high_distance | 场景 |
|-----------|-------------|---------------|------|
| 正 | 正 | = 0 | ✅ 真趋势上涨（正在创新高） |
| 正 | 正 | < 0 | 上涨趋势但未超前高 |
| 负 | 正 | < -0.3% | ⚠️ **小反弹**（大方向跌，短期涨，远离高点） |
| 正 | 负 | < 0 | 回调中（大趋势涨但短期回落） |
| 负 | 负 | < 0 | 持续下跌 |

### 3.2 推荐回测条件组合

**场景A: 真上涨（开盘15分钟后）**
```json
{"field": "slope_short", "op": ">", "value": 0.005},
{"field": "slope_long", "op": ">", "value": 0.001}
```

**场景B: 真上涨（开盘前10分钟，slope_long还没意义时）**
```json
{"field": "slope_short", "op": ">", "value": 0.005},
{"field": "high_distance", "op": ">=", "value": -0.1}
```
含义：近期在涨 + 距离今日最高点不超过0.1%（正在创新高附近）

**场景C: 过滤小反弹**
```json
{"field": "slope_long", "op": ">", "value": 0}
```
小反弹场景下 slope_long < 0，此条件自动过滤

**场景D: 冲高回落后企稳（抄底）**
```json
{"field": "slope_short", "op": ">", "value": 0},
{"field": "peak_vol_bias", "op": "<", "value": -0.5},
{"field": "slope_long", "op": ">", "value": -0.001}
```

## 四、容灾设计

### 4.1 故障恢复矩阵

| 故障场景 | slope_short | slope_long | peak_vol_bias | high_distance |
|---------|-------------|------------|---------------|---------------|
| 正常运行 | ✅ 准确 | ✅ 准确 | ✅ 准确 | ✅ 准确 |
| 冷启动（开盘） | 3分钟后满窗口 | 15分钟后满窗口 | 从头积累，准确 | **即时准确** |
| 宕机重启（盘中） | 3分钟后恢复 | 15分钟后恢复 | MySQL恢复，即时准确 | MySQL恢复，即时准确 |
| Redis宕机 | 无影响 | 无影响 | 无影响 | 无影响 |
| Redis无数据 | 无影响 | 无影响 | 无影响 | 无影响 |
| MySQL也不可用 | 无影响 | 无影响 | 降级：从当前积累 | 降级：从当前积累 |

### 4.2 恢复机制

**slope_short / slope_long**: 纯自愈（滚动窗口自然填充，无需外部恢复）

**peak_vol_bias / high_distance**: 启动时ONE-TIME恢复
```python
# 启动首tick时执行一次（失败不阻塞）
SELECT bond_code, MAX(amount) as max_amt, MAX(change_pct) as max_cpct, ...
FROM monitor_zq_sssj_{today}
GROUP BY bond_code
```

### 4.3 日期切换

当日期变化时（新一天开盘），自动清空所有缓存：
```python
if current_date != _indicator_date:
    _slope_buf_short = {}
    _slope_buf_long = {}
    _peak_vol_state = {}
    _high_state = {}
    _indicator_date = current_date
```

## 五、性能保证

| 环节 | 耗时 | 说明 |
|------|------|------|
| 常规tick（500只债券） | < 10ms | deque操作 + 线性代数 |
| 首次恢复（MySQL） | ~200ms | ONE-TIME，启动时一次 |
| Redis | 0ms | **完全不依赖Redis** |
| 内存占用 | ~15MB | 500只 × (60+300) floats × 8 bytes |
| 日期切换 | < 1ms | 清空dict |

## 六、实现代码

### 6.1 核心计算模块

```python
from collections import deque

WINDOW_SHORT = 60    # 3分钟
WINDOW_LONG = 300    # 15分钟

# 进程级缓存
_slope_buf_short = {}   # { bond_code: deque(maxlen=60) }
_slope_buf_long = {}    # { bond_code: deque(maxlen=300) }
_peak_vol_state = {}    # { bond_code: {'max_amount': float, 'price_at_max': float} }
_high_state = {}        # { bond_code: {'max_cpct': float} }
_indicator_date = None
_indicator_recovered = False


def _calc_slope(buf):
    """从deque计算线性回归斜率"""
    n = len(buf)
    if n < 3:
        return 0.0
    sum_x = n * (n - 1) / 2
    sum_x2 = n * (n - 1) * (2 * n - 1) / 6
    sum_y = 0.0
    sum_xy = 0.0
    for i, y in enumerate(buf):
        sum_y += y
        sum_xy += i * y
    denom = n * sum_x2 - sum_x * sum_x
    if denom == 0:
        return 0.0
    return (n * sum_xy - sum_x * sum_y) / denom


def _recover_indicators(engine, date):
    """ONE-TIME启动恢复（从MySQL获取今日max_amount和max_change_pct）"""
    global _peak_vol_state, _high_state, _indicator_recovered
    if _indicator_recovered:
        return
    try:
        table = f"monitor_zq_sssj_{date}"
        sql = text(f"""
            SELECT bond_code, MAX(amount) as max_amt, MAX(change_pct) as max_cpct
            FROM {table}
            GROUP BY bond_code
        """)
        # 另外获取max_amount对应的price
        sql2 = text(f"""
            SELECT t.bond_code, t.price
            FROM {table} t
            INNER JOIN (
                SELECT bond_code, MAX(amount) as max_amt FROM {table} GROUP BY bond_code
            ) m ON t.bond_code = m.bond_code AND t.amount = m.max_amt
            GROUP BY t.bond_code
        """)
        with engine.connect() as conn:
            # max_change_pct
            rows = conn.execute(sql).fetchall()
            for r in rows:
                code, max_amt, max_cpct = r[0], float(r[1]), float(r[2])
                _peak_vol_state[code] = {'max_amount': max_amt, 'price_at_max': 0}
                _high_state[code] = {'max_cpct': max_cpct}
            # price_at_max_amount
            rows2 = conn.execute(sql2).fetchall()
            for r in rows2:
                if r[0] in _peak_vol_state:
                    _peak_vol_state[r[0]]['price_at_max'] = float(r[1])
        _indicator_recovered = True
        print(f"[indicators] 恢复成功: {len(rows)} 只债券")
    except Exception as e:
        print(f"[indicators] 恢复失败(降级运行): {e}")
        _indicator_recovered = True


def compute_indicators(df_now, current_date, engine=None):
    """
    计算4个趋势指标（增量，常规路径零IO）
    
    Args:
        df_now: 当前tick的DataFrame
        current_date: 当前日期 YYYYMMDD
        engine: SQLAlchemy engine（仅启动恢复时使用）
    """
    global _slope_buf_short, _slope_buf_long
    global _peak_vol_state, _high_state
    global _indicator_date, _indicator_recovered

    # 日期切换 → 清空
    if _indicator_date != current_date:
        _slope_buf_short = {}
        _slope_buf_long = {}
        _peak_vol_state = {}
        _high_state = {}
        _indicator_recovered = False
        _indicator_date = current_date

    # 首次恢复
    if not _indicator_recovered and engine:
        _recover_indicators(engine, current_date)

    # 计算
    slopes_s = []
    slopes_l = []
    biases = []
    high_dists = []

    for _, row in df_now.iterrows():
        code = row['bond_code']
        cpct = float(row['change_pct'])
        price = float(row['price'])
        amount = float(row['amount'])

        # --- slope_short ---
        if code not in _slope_buf_short:
            _slope_buf_short[code] = deque(maxlen=WINDOW_SHORT)
        _slope_buf_short[code].append(cpct)
        slopes_s.append(round(_calc_slope(_slope_buf_short[code]), 6))

        # --- slope_long ---
        if code not in _slope_buf_long:
            _slope_buf_long[code] = deque(maxlen=WINDOW_LONG)
        _slope_buf_long[code].append(cpct)
        slopes_l.append(round(_calc_slope(_slope_buf_long[code]), 6))

        # --- peak_vol_bias ---
        if code not in _peak_vol_state:
            _peak_vol_state[code] = {'max_amount': 0, 'price_at_max': price}
        pv = _peak_vol_state[code]
        if amount > pv['max_amount']:
            pv['max_amount'] = amount
            pv['price_at_max'] = price
        bias = (price - pv['price_at_max']) / pv['price_at_max'] * 100 if pv['price_at_max'] > 0 else 0
        biases.append(round(bias, 4))

        # --- high_distance ---
        if code not in _high_state:
            _high_state[code] = {'max_cpct': cpct}
        hs = _high_state[code]
        if cpct > hs['max_cpct']:
            hs['max_cpct'] = cpct
        high_dists.append(round(cpct - hs['max_cpct'], 4))

    df_now['slope_short'] = slopes_s
    df_now['slope_long'] = slopes_l
    df_now['peak_vol_bias'] = biases
    df_now['high_distance'] = high_dists
    return df_now
```

## 十、开盘前10分钟使用建议

| 时段 | 推荐条件 | 原因 |
|------|---------|------|
| 开盘0-3分钟 | `high_distance >= -0.1` | slope尚未满窗口，用high_distance判断是否在高位 |
| 开盘3-15分钟 | `slope_short > X AND high_distance >= -0.1` | slope_short已有效，high_distance辅助确认 |
| 开盘15分钟后 | `slope_short > X AND slope_long > Y` | 双斜率组合区分真趋势vs反弹 |

## 十一、与现有指标的关系

| 已有指标 | 新指标 | 区别 |
|---------|--------|------|
| change_pct（当前涨幅） | slope_short | change_pct是位置，slope是方向 |
| min1_change_pct（1分钟涨幅） | slope_short | min1是瞬时速度，slope是持续趋势 |
| amount_rank（金额排名） | peak_vol_bias | rank是相对排名，bias是与量价高点的关系 |
