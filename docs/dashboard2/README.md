## 关键信息摘要

### Bug 概要

**问题**: 峰值净额列始终显示 100% 回落

**根因**: 后端字段 `main_net_amount` 与前端期望字段 `cumulative_main_net` 不匹配

**修复**: 后端添加 `cumulative_main_net` 字段赋值

**状态**: 待实施

### 核心字段

| 字段名 | 说明 | 示例值 |
|--------|------|--------|
| main_net_amount | 主力净额（显示用） | -248.1万 |
| cumulative_main_net | 累计主力净额（计算用） | -248.1万 |
| max_cumulative_main_net | 峰值净额 | 66.1万 |
| consecutive_attacks | 连续上攻次数 | 3 |
| main_net_count | 净额次数 | 25 |

### 关键计算

**回落百分比**:
```
回落百分比 = (峰值 - 当前) / 峰值 × 100%
```

**状态判断**:
- 强势: 当前 ≥ 峰值 × 0.95 → 绿色 →
- 正常: 峰值 × 0.8 ≤ 当前 < 峰值 × 0.95 → 无标记
- 回落: 当前 < 峰值 × 0.8 → 红色 ↓
