## 一、Redis新结构设计

### 核心问题

当前：3960个tick × 90行业 = 35万个小hash，区间查询慢。

### 新方案：行业时间序列（Sorted Set）

每个行业一个sorted set，member=tick时间，score=环比值。

```
Key: monitor_hy_top30_{date}:ts:{industry_code}
Type: Sorted Set
Value: {tick_time: delta_pct}

Key: monitor_hy_top30_{date}:codes
Type: Set
Value: [881001, 881002, ...]

Key: monitor_hy_top30_{date}:names
Type: Hash
Value: {881001: "教育", 881002: "电子", ...}
```

### 存储示例

```
monitor_hy_top30_20260729:ts:881001 → [
  ("09:30:03", 0.0),
  ("09:30:06", 0.05),
  ("09:30:09", 0.03),
  ...
]

monitor_hy_top30_20260729:ts:881002 → [
  ("09:30:03", 0.0),
  ("09:30:06", -0.02),
  ...
]
```

### 查询流程（区间10:16:06-11:23:45）

```python
# 1. 获取所有行业codes（1次Redis）
codes = client.smembers(f"monitor_hy_top30_{date}:codes")

# 2. pipeline批量取区间内数据（90次ZRANGEBYSCORE打包成1次网络）
pipe = client.pipeline()
for code in codes:
    pipe.zrangebyscore(
        f"monitor_hy_top30_{date}:ts:{code}",
        "10:16:06", "11:23:45",
        withscores=True
    )
results = pipe.execute()

# 3. 计算累计Δ并排序（内存计算）
stats = []
for code, ticks in zip(codes, results):
    cumulative = sum(score for _, score in ticks)
    stats.append({'code': code, 'cumulative': cumulative})
stats.sort(key=lambda x: x['cumulative'], reverse=True)
```

### 复杂度对比

| 维度 | 旧方案 | 新方案 |
|------|--------|--------|
| Key数量 | 3960个 | 90个 |
| 区间查询 | O(n)遍历 | O(log n + m) |
| 网络往返 | 400次 | 1次pipeline |
| 400tick查询 | ~2秒 | ~50ms |

## 二、MySQL索引优化

### 当前问题

```sql
-- 当前查询（无索引，全表扫描）
SELECT code, name, SUM(delta_change_pct) 
FROM monitor_hy_top30_20260729
WHERE time BETWEEN '10:16:06' AND '11:23:45'
GROUP BY code, name;
-- 扫描35万行，慢
```

### 优化方案

```sql
-- 1. 复合索引：时间+行业，加速范围查询和分组
ALTER TABLE monitor_hy_top30_20260729 
ADD INDEX idx_time_code_delta (time, code, delta_change_pct);

-- 2. 覆盖索引查询（无需回表）
SELECT code, 
       MAX(name) as name,  -- name是函数依赖，可用MAX
       SUM(delta_change_pct) as cumulative
FROM monitor_hy_top30_20260729
WHERE time BETWEEN '10:16:06' AND '11:23:45'
GROUP BY code
ORDER BY cumulative DESC
LIMIT 10;
```

### 预期效果

- 扫描行数：35万 → 约400行（区间内tick数）
- 查询时间：从秒级降到毫秒级

## 三、完整改造清单

### 1. monitor_stock.py - Redis写入改造

```python
def _save_industry_delta_to_redis(df: pd.DataFrame, date_str: str, time_full: str):
    """新结构：每个行业一个sorted set"""
    client = redis_util._get_redis_client()
    EXPIRE = 64800  # 18小时
    
    codes_key = f"monitor_hy_top30_{date_str}:codes"
    name_key = f"monitor_hy_top30_{date_str}:names"
    
    for _, row in df.iterrows():
        code = str(row['code']).strip()
        delta = float(row['delta_change_pct'])
        name = str(row['name'])
        
        # 1. 添加到行业时间序列
        ts_key = f"monitor_hy_top30_{date_str}:ts:{code}"
        client.zadd(ts_key, {time_full: delta})
        client.expire(ts_key, EXPIRE)
        
        # 2. 加入行业集合
        client.sadd(codes_key, code)
        
        # 3. 存名称（幂等，只更新一次）
        client.hset(name_key, code, name)
    
    # 统一设置过期
    client.expire(codes_key, EXPIRE)
    client.expire(name_key, EXPIRE)
```

### 2. range_analysis_service.py - Redis查询改造

```python
def _query_range_from_redis(date: str, start_time: str, end_time: str):
    """新结构查询：sorted set zrangebyscore"""
    client = redis_util._get_redis_client()
    
    # 1. 获取所有行业
    codes = client.smembers(f"monitor_hy_top30_{date}:codes")
    if not codes:
        return empty
    
    # 2. pipeline批量查询区间内数据
    pipe = client.pipeline()
    for code in codes:
        pipe.zrangebyscore(
            f"monitor_hy_top30_{date}:ts:{code}",
            start_time, end_time,
            withscores=True
        )
    results = pipe.execute()
    
    # 3. 获取名称
    names = client.hgetall(f"monitor_hy_top30_{date}:names")
    
    # 4. 计算累计并排序
    stats = []
    for code, ticks in zip(codes, results):
        code_str = code.decode() if isinstance(code, bytes) else code
        cumulative = sum(float(s) for _, s in ticks) if ticks else 0
        name = names.get(code, code_str)
        stats.append({
            'code': code_str,
            'name': name.decode() if isinstance(name, bytes) else name,
            'cumulative_value': cumulative,
            'avg_stock_count': 0
        })
    
    stats.sort(key=lambda x: x['cumulative_value'], reverse=True)
    strongest = stats[:10]
    weakest = stats[-10:][::-1]
    
    return {...}
```

### 3. range_analysis_service.py - MySQL查询优化

```python
def query_range_industry(date: str, start_time: str, end_time: str, metric: str = 'change_pct'):
    # Redis优先
    if metric == 'delta_pct':
        result = _query_range_from_redis(date, start_time, end_time)
        if result.get('strongest_rank'):
            return result
    
    # MySQL降级（带索引优化）
    return _query_range_from_mysql(date, start_time, end_time, metric)

def _query_range_from_mysql(date, start_time, end_time, metric):
    """MySQL查询使用覆盖索引"""
    table = f"monitor_hy_top30_{date}"
    value_col = 'delta_change_pct' if metric == 'delta_pct' else 'avg_change_pct'
    
    # 使用覆盖索引的查询
    df = pd.read_sql(text(f"""
        SELECT code, 
               MAX(name) as name,
               SUM({value_col}) as cumulative_value,
               AVG(total) as avg_stock_count
        FROM {table}
        WHERE time >= :s AND time <= :e
        GROUP BY code
        ORDER BY cumulative_value DESC
    """), conn, params={'s': start_time, 'e': end_time})
    
    # 取前10强/前10弱
    strongest = df.head(10).to_dict('records')
    weakest = df.tail(10).iloc[::-1].to_dict('records')
    return {...}
```
