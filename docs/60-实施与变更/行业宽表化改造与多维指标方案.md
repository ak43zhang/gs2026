## 一、需求理解（请确认）

### 1.1 两个独立需求

| 需求 | 维度 | 说明 |
|------|------|------|
| **需求A：上攻排行** | 行业上攻强度 | 现有功能，用 final_score 验证行业强度（保持不变）|
| **需求B：涨幅验证** | 行业涨幅 | 新需求，用 avg_change_pct 验证行业涨幅作用 |

**你的核心思路**：
- 不改之前的区间测算设计（两个需求并存）
- **改造上攻排行存储的表**：存所有行业（而非只top5）
- 这样一张"时间×行业"宽表可以：
  - 基于行业做上攻排行筛选（需求A）
  - 基于涨跌幅或其他指标计算其他需求（需求B）
  - 维度 = 行业，或 时间×行业
  - 在此基础上完善区间最强行业指标

### 1.2 关键约束

```
【约束1】保证兼容之前的上攻排行（不能破坏现有功能）
【约束2】表存所有行业（支持多维度筛选）
【约束3】在宽表基础上增加区间最强/最弱行业指标
```

## 三、改造方案

### 3.1 设计原则

```
1. 兼容优先：上攻排行（final_score + top5）逻辑完全不动
2. 宽表已在：monitor_hy_top30 已存全部行业，无需大改存储
3. 增量扩展：在宽表上增加"涨幅维度"的排名字段和排行统计
4. 统一数据源：区间测算、涨幅排行都查这张宽表
```

### 3.2 方案总览

```
┌─────────────────────────────────────────────────────────────────┐
│  monitor_hy_top30_{date}（宽表，已存全部行业，改造：加涨幅排名）  │
│  现有字段（不动）:                                                │
│    code, name, count, total, avg_change_pct, final_score,        │
│    industry_cumulative_main_net, rank(按final_score), time...    │
│  【新增字段】:                                                    │
│    rank_by_change_pct    按涨幅排名（1=涨幅最高）                 │
│    change_pct_percentile 涨幅分位（可选）                        │
└─────────────────────────────────────────────────────────────────┘
                    │                          │
        ┌───────────┘                          └───────────┐
        ▼                                                   ▼
┌──────────────────────┐                    ┌──────────────────────┐
│ 需求A：上攻排行       │                    │ 需求B：涨幅排行/区间   │
```

### 3.3 存储层改造（monitor_stock.py）

#### 改造1：宽表增加涨幅排名字段

```python
# calculate_industry_topn 第8步后，增加按涨幅的排名
# 现有：all_industries 已按 final_score 排序并有 rank

def _add_change_pct_rank(result_df: pd.DataFrame) -> pd.DataFrame:
    """在行业宽表中增加按涨幅的排名（不影响现有final_score排名）"""
    if result_df is None or result_df.empty:
        return result_df
    if 'avg_change_pct' in result_df.columns:
        # rank_by_change_pct: 1=涨幅最高，N=涨幅最低（最弱）
        result_df['rank_by_change_pct'] = (
            result_df['avg_change_pct']
            .rank(ascending=False, method='first')
            .astype(int)
        )
    return result_df

# INDUSTRY_RESULT_COLUMNS 增加 'rank_by_change_pct'
```

**效果**：宽表每tick的90个行业，既有 `rank`（上攻）又有 `rank_by_change_pct`（涨幅）。
- `rank_by_change_pct == 1` → 该tick涨幅最强板块
- `rank_by_change_pct == N`（最大）→ 该tick涨幅最弱板块

#### 改造2：上攻排行保持不动（兼容）

```python

hy_top5_df = hy_all_df.head(5)              # 上攻top5不变
update_rank_redis(hy_top5_df, 'industry')   # 上攻排行不变
```

**关键**：`hy_all_df.head(5)` 仍是按 final_score 的top5，上攻排行**语义完全不变**。

### 3.4 区间测算数据源（基于宽表）

**无需APQD表扩展**（v2.0方案里的APQD扩展可以取消），直接查宽表：

```python
# services/range_analysis_service.py

def query_range_industry(date, start_time, end_time):
    """区间最强/最弱行业聚合（基于宽表 monitor_hy_top30）"""
    table = f"monitor_hy_top30_{date}"
    
    # 查区间内每个tick的涨幅最强(rank_by_change_pct=1)和最弱(=max)
    # 方式1：SQL直接取每tick的最强最弱
    sql_strongest = f"""
        SELECT time, code, name, avg_change_pct
        FROM {table}
        WHERE time >= %s AND time <= %s AND rank_by_change_pct = 1
        ORDER BY time
    """
    # 最弱：每tick rank_by_change_pct 最大的
    sql_weakest = f"""
        SELECT t1.time, t1.code, t1.name, t1.avg_change_pct
        FROM {table} t1
        INNER JOIN (
            SELECT time, MAX(rank_by_change_pct) as max_rank
            FROM {table}
            WHERE time >= %s AND time <= %s
            GROUP BY time
        ) t2 ON t1.time = t2.time AND t1.rank_by_change_pct = t2.max_rank
        WHERE t1.time >= %s AND t1.time <= %s
    """
    
    # 聚合：统计每个行业当选最强/最弱的次数
    from collections import Counter
    strongest_rows = execute_query(sql_strongest, (start_time, end_time))
    weakest_rows = execute_query(sql_weakest, (start_time, end_time, start_time, end_time))
    
    strongest_counter = Counter()
    weakest_counter = Counter()
    # ... 统计次数、均涨幅、名称（同v2.0聚合逻辑）
    
    return {
        'strongest_rank': [...],  # 区间最强（当选rank1次数最多）
        'weakest_rank': [...],    # 区间最弱
        'total_ticks': ...,
    }
```

**优势**：
- 宽表已有全部行业+涨幅+排名，一次查询搞定
- 上攻排行、涨幅排行、区间测算共用一张表
- 未来加"主力净额区间排行"等，同样查这张表

### 4.2 服务层 `services/range_analysis_service.py`

```python
from collections import Counter
from gs2026.utils.mysql_util import execute_query

def get_available_dates():
    """查有 monitor_hy_top30_* 表的日期"""
    rows = execute_query("SHOW TABLES LIKE 'monitor_hy_top30_%'")
    dates = []
    for r in rows:
        t = list(r.values())[0]
        dates.append(t.replace('monitor_hy_top30_', ''))
    return sorted(dates, reverse=True)

def get_timestamps(date):
    """某日所有tick时间戳"""
    table = f"monitor_hy_top30_{date}"
    rows = execute_query(f"SELECT DISTINCT time FROM {table} ORDER BY time")
    return [r['time'] for r in rows]

def query_range_industry(date, start_time, end_time, metric='change_pct'):
    """
    区间聚合：统计每个行业当选"最强/最弱"的次数
    metric=change_pct: 用 rank_by_change_pct（涨幅维度）
    """
    table = f"monitor_hy_top30_{date}"
    
    # 最强：每tick rank_by_change_pct=1
    strongest_rows = execute_query(f"""
        SELECT time, code, name, avg_change_pct
        FROM {table}
        WHERE time >= %s AND time <= %s AND rank_by_change_pct = 1
        ORDER BY time
    """, (start_time, end_time))
    
    # 最弱：每tick rank_by_change_pct 最大
    weakest_rows = execute_query(f"""
        SELECT t1.time, t1.code, t1.name, t1.avg_change_pct
        FROM {table} t1
        INNER JOIN (
            SELECT time, MAX(rank_by_change_pct) AS mr
            FROM {table}
            WHERE time >= %s AND time <= %s
            GROUP BY time
        ) t2 ON t1.time = t2.time AND t1.rank_by_change_pct = t2.mr
        WHERE t1.time >= %s AND t1.time <= %s
        ORDER BY t1.time
    """, (start_time, end_time, start_time, end_time))
    
    total_ticks = len(set(r['time'] for r in strongest_rows))
    
    def _aggregate(rows):
        counter = Counter()
        pct_sum, name_map = {}, {}
        for r in rows:
            c = str(r['code'])
            counter[c] += 1
            pct_sum[c] = pct_sum.get(c, 0.0) + float(r['avg_change_pct'] or 0)
            name_map[c] = r['name']
        return [
            {
                'code': c, 'name': name_map.get(c, c), 'count': cnt,
                'ratio': round(cnt / total_ticks, 4) if total_ticks else 0,
                'avg_change_pct': round(pct_sum[c] / cnt, 4)
            }
            for c, cnt in counter.most_common(10)
        ]
    
    return {
        'strongest_rank': _aggregate(strongest_rows),
        'weakest_rank': _aggregate(weakest_rows),
        'total_ticks': total_ticks,
        'time_range': [start_time, end_time]
    }

def get_industry_trend(date, code, start_time, end_time):
    """某行业区间涨幅时序（画折线）"""
    table = f"monitor_hy_top30_{date}"
    rows = execute_query(f"""
        SELECT time, avg_change_pct, rank_by_change_pct
        FROM {table}
        WHERE code = %s AND time >= %s AND time <= %s
        ORDER BY time
    """, (code, start_time, end_time))
    return {
        'times': [r['time'] for r in rows],
        'change_pcts': [round(float(r['avg_change_pct'] or 0), 4) for r in rows],
        'ranks': [int(r['rank_by_change_pct'] or 0) for r in rows]
    }
```

```javascript
    await queryRange();  // 默认查全天
}

// 3. 双滑块拖动（起始/结束）
function onSliderChange(which, idx) {
    if (which === 'start') {
        _startIdx = Math.min(idx, _endIdx);
    } else {
        _endIdx = Math.max(idx, _startIdx);
    }
    updateRangeLabel();
    // 防抖：拖动停止300ms后查询
    debounce(queryRange, 300)();
}

function updateRangeLabel() {
    const s = _timestamps[_startIdx];
    const e = _timestamps[_endIdx];
    const cnt = _endIdx - _startIdx + 1;
    document.getElementById('rangeLabel').textContent = 
        `已选: ${s} ~ ${e}  (共 ${cnt} 个tick)`;
}

// 4. 区间查询（核心）
async function queryRange() {
    const start = _timestamps[_startIdx];
    const end = _timestamps[_endIdx];
    const metric = document.getElementById('metricSelect').value;
    
    const r = await fetchJSON(
        `/api/range-analysis/range?date=${_currentDate}&start_time=${start}&end_time=${end}&metric=${metric}`
    );
    
    renderStrongestRank(r.data.strongest_rank);
    renderWeakestRank(r.data.weakest_rank);
    renderConclusion(r.data);  // 结论文案
}

// 5. 渲染最强榜
function renderStrongestRank(rank) {
    const html = rank.map((it, i) => `
        <tr onclick="showTrend('${it.code}', '${it.name}')" style="cursor:pointer">
            <td>${i + 1}</td>
            <td>${it.name}</td>
            <td>${it.count}次</td>
            <td>${(it.ratio * 100).toFixed(0)}%</td>
            <td style="color:#e74c3c">+${it.avg_change_pct.toFixed(2)}%</td>
        </tr>
    `).join('');
    document.getElementById('strongestBody').innerHTML = html;
}

// 6. 结论文案
function renderConclusion(data) {
    const s = data.strongest_rank[0];
    const w = data.weakest_rank[0];
    let txt = '';
    if (s) txt += `该区间大盘上涨主要由【${s.name}】板块带动（当选最强${s.count}次）。`;
    if (w) txt += `下跌主要受【${w.name}】板块拖累（当选最弱${w.count}次）。`;
    document.getElementById('conclusion').textContent = txt;
}

// 7. 点击榜单显示趋势图
async function showTrend(code, name) {
    const start = _timestamps[_startIdx];
    const end = _timestamps[_endIdx];
    const r = await fetchJSON(
        `/api/range-analysis/industry-trend?date=${_currentDate}&code=${code}&start_time=${start}&end_time=${end}`
    );
    if (!_trendChart) _trendChart = echarts.init(document.getElementById('trendChart'));
    _trendChart.setOption({
        title: { text: `${name} 区间涨幅趋势` },
        tooltip: { trigger: 'axis' },
        xAxis: { type: 'category', data: r.data.times },
        yAxis: { type: 'value', name: '平均涨幅%' },
        series: [{ 
            name: '平均涨幅', type: 'line', data: r.data.change_pcts,
            smooth: true, areaStyle: {}
        }]
    });
}

document.addEventListener('DOMContentLoaded', init);
```
