## 一、需求理解（请确认）

### 1.1 核心需求

在 `monitor_stock.py` 计算大盘数据时，**新增两个tick级指标**：
- **最强板块**：当前tick所有行业中，平均涨幅最大的板块
- **最弱板块**：当前tick所有行业中，平均涨幅最小的板块

**计算依据**：行业（板块）平均涨幅 + 与上一tick平均涨幅的对比。

### 1.2 后续扩展（本次设计预留）

- **区间涨幅最强板块**：时间区间内，某板块作为"最强板块"出现的次数最多
- **区间涨幅最弱板块**：同理，出现"最弱"次数最多
- 其他区间×板块维度指标

### 1.3 应用场景

- 前端滑动时间区间 → 直接展示该区间的最强/最弱板块
- **判断大盘上涨/下跌是被哪个板块带动的**

### 1.4 功能位置

智能选股页面，在「交叉行概选股」「涨停行概选股」之后，新增第3个入口「**区间测算**」。

**关键**：`avg_change_pct`（行业平均涨幅）+ `time`（时间戳）已具备，这就是区间测算的核心数据源。

### 4.2 各层详细设计

#### 【指标计算层】新增函数

```python
# monitor_stock.py 新增

# 上一tick最强/最弱板块缓存（用于环比对比）
_prev_industry_avg = {}  # {industry_code: avg_change_pct}

def calc_strongest_weakest_industry(industry_stats: pd.DataFrame, 
                                     time_full: str) -> dict:
    """
    从行业统计中计算最强/最弱板块（tick级）
    
    Args:
        industry_stats: calculate_industry_topn 中的行业统计DataFrame
                        （含 industry_code, industry_name, avg_change_pct）
        time_full: 当前时间
    
    Returns:
        dict: {
            'strongest_code': str, 'strongest_name': str, 
            'strongest_change_pct': float, 'strongest_delta': float,  # 环比上一tick
            'weakest_code': str, 'weakest_name': str,
            'weakest_change_pct': float, 'weakest_delta': float
        }
    """
    global _prev_industry_avg
    result = {
        'strongest_code': '', 'strongest_name': '', 
        'strongest_change_pct': 0.0, 'strongest_delta': 0.0,
        'weakest_code': '', 'weakest_name': '',
        'weakest_change_pct': 0.0, 'weakest_delta': 0.0
    }
    
    if industry_stats is None or industry_stats.empty:
        return result
    
    try:
        # 需要至少有效样本（过滤股票数太少的板块，避免噪声）
        MIN_TOTAL = 3  # 板块至少3只股票才纳入（可配置）
        valid = industry_stats[industry_stats['total'] >= MIN_TOTAL].copy()
        if valid.empty:
            valid = industry_stats.copy()
        
        # 最强：avg_change_pct 最大
        strongest = valid.loc[valid['avg_change_pct'].idxmax()]
        # 最弱：avg_change_pct 最小
        weakest = valid.loc[valid['avg_change_pct'].idxmin()]
        
        s_code = str(strongest['industry_code'])
        s_name = str(strongest['industry_name'])
        s_pct = float(strongest['avg_change_pct'])
        w_code = str(weakest['industry_code'])
        w_name = str(weakest['industry_name'])
        w_pct = float(weakest['avg_change_pct'])
        
        # 环比上一tick（同板块涨幅变化量）
        s_delta = s_pct - _prev_industry_avg.get(s_code, s_pct)
        w_delta = w_pct - _prev_industry_avg.get(w_code, w_pct)
        
        result.update({
            'strongest_code': s_code, 'strongest_name': s_name,
            'strongest_change_pct': round(s_pct, 4), 'strongest_delta': round(s_delta, 4),
            'weakest_code': w_code, 'weakest_name': w_name,
            'weakest_change_pct': round(w_pct, 4), 'weakest_delta': round(w_delta, 4)
        })
        
        # 更新缓存（供下一tick环比）
        _prev_industry_avg = dict(zip(
            valid['industry_code'].astype(str), 
            valid['avg_change_pct'].astype(float)
        ))
        
    except Exception as e:
        logger.warning(f"[{time_full}] 计算最强/最弱板块失败: {e}")
    
    return result
```

## 六、性能与风险

### 6.1 性能影响

| 环节 | 影响 | 说明 |
|------|------|------|
| tick计算 | **极小** | 最强/最弱只是max/min，行业数~100个，微秒级 |
| APQD存储 | 极小 | 每tick多存8个字段 |
| 区间查询 | 中 | 区间越大查询越多，需索引优化 |

### 6.2 风险

| 风险 | 解决 |
|------|------|
| tick计算增加耗时 | max/min开销极小，可忽略（已优化过monitor_stock）|
| APQD表加字段影响建表 | 沿用建表完整性机制，主动补齐字段 |
| 区间查询慢 | monitor_gp_apqd按time加索引，区间聚合在SQL层 |
| 板块噪声（股票太少）| MIN_TOTAL过滤（至少3只股票才纳入）|

### 6.3 建表完整性（关键）

**沿用之前修复的经验**：APQD表加新字段后，必须在写MySQL前主动补齐，避免"启动时机导致建表缺列"问题（参考 `consecutive_attacks` 事故）。
