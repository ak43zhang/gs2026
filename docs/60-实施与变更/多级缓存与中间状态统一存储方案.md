## 一、核心问题与方案对比

### 1.1 最开始的问题

| 问题 | 现象 | 根本原因 |
|------|------|----------|
| VWAP计算错误 | 重启后为0% | `_mkt_trend_vwap_sum_pv/v`未恢复，从零开始 |
| 形态识别错误 | 重启后为"横盘" | `_mkt_shape_history`未恢复，数据不足 |
| 斜率计算错误 | 重启后为0 | `_slope_buf_short/long`未恢复，无法计算 |

**根本原因**：只存结果不存中间累积状态，数学上不可逆
```python
# VWAP = sum_pv / sum_v
# 知道VWAP=-0.3，无法反推sum_pv和sum_v
```

### 1.2 方案演进对比

| 方案 | 核心设计 | 存储结构 | 获取方式 | 扩展性 | 数据量 | 综合评分 |
|------|----------|----------|----------|--------|--------|----------|
| v9.0 | 分类型存储 | 每数据点1行 | 区间查询 | 中 | 384万行/天 | ⭐⭐⭐ |
| v9.1 | 分层存储 | Redis详细+MySQL稀疏 | 逐个恢复 | 中 | Redis:2GB, MySQL:32MB | ⭐⭐⭐⭐ |
| **v10.0/v11.0** | **Snapshot快照** | **每tick完整快照** | **一次性获取** | **优** | **Redis:1GB, MySQL:64MB** | **⭐⭐⭐⭐⭐** |

**v10.0/v11.0优势**：
- ✅ 一次性获取全部中间状态（1次HGETALL）
- ✅ 横向扩展（新增指标加字段即可）
- ✅ 覆盖更新（最新tick直接覆盖）
- ✅ 高效（1次Redis操作存取）
- ✅ 完整解决原问题（重启后从快照恢复）

## 二、最终方案：Snapshot快照模式（v11.0）

### 2.1 核心设计

```
每tick = 一个完整状态快照（覆盖更新）

┌─────────────────────────────────────────────────────────────┐
│                    Snapshot快照架构                          │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  每tick生成一个完整状态快照：                                  │
│  {                                                            │
│    "timestamp": 37803,          # 当前时间戳                  │
│    "mkt": {                    # 大盘中间状态                │
│      "vwap_pv": 12345678.9,    # VWAP分子                    │
│      "vwap_v": 987654321.0,    # VWAP分母                   │
│      "shape_h": [...],         # 形态历史（截断500点）       │
│      "high": 1.52,                                            │
│      "low": -0.85                                             │
│    },                                                         │
│    "bonds": {                  # 400只债券中间状态           │
│      "123456": {                                              │
│        "ss": [1.0, 1.1, ...],  # short斜率缓存（60点）      │
│        "sl": [0.9, 1.0, ...],  # long斜率缓存（300点）      │
│        "pamt": 1000000,         # 放量状态                  │
│        "pprc": 105.5                                           │
│      },                                                       │
│      "123457": { ... },                                       │
│      ... 400只债券                                            │
│    }                                                          │
│  }                                                            │
│                                                               │
│  存储：                                                       │
│    - Redis: snapshot:mkt:{date} → 大盘快照（Hash覆盖）       │
│    - Redis: snapshot:bonds:{date} → 个券快照（Hash覆盖）      │
│    - MySQL: 每30秒存1次备份                                   │
│                                                               │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 Redis设计（主存储）

```python
# 大盘快照（1个key）
Key: snapshot:mkt:{date}           # 如: snapshot:mkt:20260726
Type: Hash
Field: {timestamp} → Value: {mkt_snapshot_json}

# 示例:
# field: "37803" → value: '{
#   "vwap_pv": 12345678.9,
#   "vwap_v": 987654321.0,
#   "shape_h": [{"t":32400,"p":-0.5}, ...],  # 最近500点
#   "high": 1.52,
#   "low": -0.85,
#   ...
# }'

# 个券快照（1个key存400只）
Key: snapshot:bonds:{date}        # 如: snapshot:bonds:20260726
Type: Hash
Field: {timestamp} → Value: {all_bonds_snapshot_json}

# 示例:
# field: "37803" → value: '{
#   "123456": {"ss":[...60个...], "sl":[...300个...], "pamt":1000000},
#   "123457": {"ss":[...], "sl":[...], "pamt":2000000},
#   ... 400只
# }'

# 过期: 12小时（43200秒）
```

### 2.3 MySQL设计（备份）

```sql
-- 稀疏存储：每30秒存1次
CREATE TABLE snapshot_backup (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    snapshot_type VARCHAR(16) NOT NULL,   -- 'mkt' 或 'bonds'
    trading_date VARCHAR(8) NOT NULL,
    snapshot_time INT NOT NULL,             -- 时间戳（每30秒）
    snapshot_json JSON NOT NULL,            -- 完整快照
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_type_date_time (snapshot_type, trading_date, snapshot_time),
    KEY idx_date (trading_date)
);

-- 数据示例：
-- | type  | date     | time  | snapshot_json |
-- |-------|----------|-------|---------------|
-- | mkt   | 20260726 | 32400 | '{vwap_pv:..., shape_h:..., ...}' |
-- | bonds | 20260726 | 32400 | '{123456:{ss:[...], ...}, ...}' |
-- | mkt   | 20260726 | 32430 | '{vwap_pv:..., ...}' |  -- 30秒后
-- | bonds | 20260726 | 32430 | '{...}' |
-- ... 160行/天（每30秒存1次）
```

### 2.4 存储流程

```python
def generate_snapshot(df_now, current_date, time_sec):
    """
    生成完整状态快照并存储
    
    每tick调用，覆盖更新
    """
    # 1. 大盘中间状态
    mkt_snapshot = {
        "vwap_pv": _mkt_trend_vwap_sum_pv,
        "vwap_v": _mkt_trend_vwap_sum_v,
        "shape_h": _mkt_shape_history[-500:],  # 截断到最近500点
        "high": _mkt_trend_day_high,
        "low": _mkt_trend_day_low,
        # ... 其他大盘指标
    }
    
    # 2. 个券中间状态（400只）
    bonds_snapshot = {}
    for code in all_400_bonds:
        bonds_snapshot[code] = {
            "ss": list(_slope_buf_short.get(code, [])),  # 60点
            "sl": list(_slope_buf_long.get(code, [])),   # 300点
            "pamt": _peak_vol_state.get(code, {}).get('max_amount', 0),
            "pprc": _peak_vol_state.get(code, {}).get('price_at_max', 0),
            # ... 其他个券指标
        }
    
    # 3. 存储到Redis（覆盖更新）
    r = redis_util._get_redis_client()
    
    # 大盘快照（1个key，field为时间戳，覆盖）
    r.hset(f"snapshot:mkt:{current_date}", str(time_sec), json.dumps(mkt_snapshot))
    r.expire(f"snapshot:mkt:{current_date}", 43200)
    
    # 个券快照（1个key，field为时间戳，覆盖）
    r.hset(f"snapshot:bonds:{current_date}", str(time_sec), json.dumps(bonds_snapshot))
    r.expire(f"snapshot:bonds:{current_date}", 43200)
    
    # 4. 稀疏存储到MySQL（每30秒）
    if time_sec % 30 == 0:
        sql = """
            INSERT INTO snapshot_backup (snapshot_type, trading_date, snapshot_time, snapshot_json)
            VALUES (%s, %s, %s, %s)
            ON DUPLICATE KEY UPDATE snapshot_json = VALUES(snapshot_json)
        """
        execute(sql, ('mkt', current_date, time_sec, json.dumps(mkt_snapshot)))
        execute(sql, ('bonds', current_date, time_sec, json.dumps(bonds_snapshot)))
    
    return mkt_snapshot, bonds_snapshot
```

### 2.5 恢复流程

```python
def recover_from_snapshot(date: str, time_sec: int = None):
    """
    从快照恢复全部中间状态
    
    重启时调用
    """
    r = redis_util._get_redis_client()
    
    # L2: Redis（主存储）
    mkt_key = f"snapshot:mkt:{date}"
    bonds_key = f"snapshot:bonds:{date}"
    
    if time_sec is None:
        # 获取最新时间戳
        all_timestamps = r.hkeys(mkt_key)
        if all_timestamps:
            time_sec = max(int(t.decode()) for t in all_timestamps)
    
    mkt_data = r.hget(mkt_key, str(time_sec))
    bonds_data = r.hget(bonds_key, str(time_sec))
    
    if mkt_data and bonds_data:
        # 解析并恢复
        mkt_snapshot = json.loads(mkt_data.decode())
        bonds_snapshot = json.loads(bonds_data.decode())
        
        # 恢复大盘状态
        _mkt_trend_vwap_sum_pv = mkt_snapshot['vwap_pv']
        _mkt_trend_vwap_sum_v = mkt_snapshot['vwap_v']
        _mkt_shape_history = mkt_snapshot['shape_h']
        ...
        
        # 恢复个券状态
        for code, data in bonds_snapshot.items():
            _slope_buf_short[code] = deque(data['ss'], maxlen=60)
            _slope_buf_long[code] = deque(data['sl'], maxlen=300)
            _peak_vol_state[code] = {'max_amount': data['pamt'], 'price_at_max': data['pprc']}
        
        logger.info(f"[恢复] 从Redis快照 {time_sec} 成功")
        return True
    
    # L3: MySQL（备份）
    sql = """
        SELECT snapshot_json FROM snapshot_backup
        WHERE snapshot_type = %s AND trading_date = %s
        ORDER BY ABS(snapshot_time - %s) LIMIT 1
    """
    # 查询最近时间点的快照
    
    # L4: 都无
    logger.warning("[降级] 无快照，从0开始")
    return False
```

### 2.6 一次性获取全部中间状态

```python
def get_all_intermediate_state(date: str, time_sec: int = None):
    """
    一次性获取全部中间状态（大盘+400只债券）
    
    用于实时计算分析
    """
    r = redis_util._get_redis_client()
    
    # 1次HGETALL获取大盘全部历史快照
    mkt_all = r.hgetall(f"snapshot:mkt:{date}")
    
    # 1次HGETALL获取个券全部历史快照
    bonds_all = r.hgetall(f"snapshot:bonds:{date}")
    
    # 解析指定时间点（或最新）
    if time_sec is None:
        time_sec = max(int(t.decode()) for t in mkt_all.keys())
    
    return {
        "mkt": json.loads(mkt_all[str(time_sec).encode()].decode()),
        "bonds": json.loads(bonds_all[str(time_sec).encode()].decode())
    }
```

## 八、逐字段修改方案（保证流程正确+高效）

### 8.1 修改原则

| 原则 | 说明 |
|------|------|
| **不改计算逻辑** | 原有`+=`、`.append`、计算代码完全不变 |
| **只加持久化** | 在tick末尾统一收集快照并存储（1次） |
| **只加恢复** | 在日期切换/启动时从快照恢复（1次） |
| **异步存储** | 快照存储走异步，不阻塞主tick |
| **降级兜底** | 快照缺失时从0开始（原行为，兼容） |

### 8.2 新增模块：snapshot_cache.py

```python
# src/gs2026/monitor/snapshot_cache.py（新建）
import json
from gs2026.utils import redis_util, mysql_util

_SNAPSHOT_RECOVERED = False  # 启动恢复标志

def save_snapshot(date, time_sec, mkt_snapshot, bonds_snapshot):
    """存储快照（异步调用）"""
    try:
        r = redis_util._get_redis_client()
        pipe = r.pipeline()
        # 大盘快照（覆盖最新时间戳）
        pipe.hset(f"snapshot:mkt:{date}", str(time_sec), 
                  json.dumps(mkt_snapshot, ensure_ascii=False))
        pipe.expire(f"snapshot:mkt:{date}", 43200)
        # 个券快照（覆盖）
        pipe.hset(f"snapshot:bonds:{date}", str(time_sec),
                  json.dumps(bonds_snapshot, ensure_ascii=False))
        pipe.expire(f"snapshot:bonds:{date}", 43200)
        pipe.execute()  # 1次网络往返

        # MySQL稀疏备份（每30秒）
        if time_sec % 30 == 0:
            _save_mysql_backup(date, time_sec, mkt_snapshot, bonds_snapshot)
    except Exception as e:
        logger.warning(f"[快照] 存储失败(不影响主流程): {e}")

def recover_snapshot(date):
    """启动恢复快照（返回mkt_snapshot, bonds_snapshot）"""
    global _SNAPSHOT_RECOVERED
    if _SNAPSHOT_RECOVERED:
        return None, None
    try:
        r = redis_util._get_redis_client()
        mkt_key = f"snapshot:mkt:{date}"
        # 取最新时间戳
        timestamps = r.hkeys(mkt_key)
        if not timestamps:
            # L3 MySQL兜底
            return _recover_mysql_backup(date)
        latest = max(int(t.decode()) for t in timestamps)
        mkt_data = r.hget(mkt_key, str(latest))
        bonds_data = r.hget(f"snapshot:bonds:{date}", str(latest))
        _SNAPSHOT_RECOVERED = True
        return (json.loads(mkt_data.decode()) if mkt_data else None,
                json.loads(bonds_data.decode()) if bonds_data else None)
    except Exception as e:
        logger.warning(f"[快照] 恢复失败(从0开始): {e}")
        return None, None
```

### 9.1 性能影响分析

| 操作 | 位置 | 耗时 | 是否阻塞 |
|------|------|------|----------|
| 计算逻辑 | 原有 | 不变 | - |
| 收集快照 | tick末尾 | <3ms | 否（内存操作） |

| 恢复快照 | 日期切换/启动 | <20ms | 仅1次 |

**关键**：正常运行时，主tick只多了"收集快照+提交线程池"（<3ms），存储在后台异步完成。

|------|------|------|
