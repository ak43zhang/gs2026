# 债券攻排行自动刷新问题分析与修复方案

## 一、问题现象

- 用户选择 09:45:24 时间，债券数据开始展示正确
- 过了一会儿（自动刷新后），数据就不对了
- 股票攻排行固定时间后不会刷新，保持正确

## 二、根因分析

### 自动刷新机制

**`_autoRefreshTimer` 定时器**（行1513-1525）：
```javascript
_autoRefreshTimer = setInterval(() => {
    if (_isLive && !document.hidden) {
        if (!shouldStartAutoRefresh()) {
            stopAutoRefresh();
            return;
        }
        loadTimestamps();
        loadAllData();  // 【问题】没有传参数！
    }
}, REFRESH_INTERVAL);
```

### `loadAllData` 的行为

```javascript
async function loadAllData(timeStr) {
    if (timeStr || getSelectedDate()) {
        // 历史回放模式 - 使用固定时间
        await loadBondRanking(timeStr);
    } else {
        // 实时模式 - 使用最新时间
        await loadBondRanking();  // 没传timeStr！
    }
}
```

### 问题流程

1. 用户选择 09:45:24 → `_userFixedTime = '09:45:24'`
2. 调用 `loadAllData('09:45:24')` → 债券数据正确
3. 自动刷新触发 → 调用 `loadAllData()` **没传参数**
4. 走实时模式分支 → `loadBondRanking()` 没传timeStr
5. `buildRankUrl('bond', undefined)` → URL没有time参数
6. 后端返回**最新时间**的数据 → **数据不对了**

### 为什么股票没问题？

股票也有同样的问题！但用户说股票"固定时间后就不刷新了"，可能是因为：
1. 股票有某种机制阻止了自动刷新
2. 或者用户没有注意到股票也有问题

实际上，**自动刷新定时器没有检查 `_userFixedTime`**，这是根本问题。

## 三、解决方案

### 方案：修改 `_autoRefreshTimer` 检查 `_userFixedTime`

**修改位置**：`monitor.html` 行1513-1525

```javascript
_autoRefreshTimer = setInterval(() => {
    // 实时模式且页面可见时才刷新
    if (_isLive && !document.hidden) {
        // 【v3.0】二次检查：防止刷新中途进入非交易时段
        if (!shouldStartAutoRefresh()) {
            console.log('[AutoRefresh] 进入非交易时段，停止自动刷新');
            stopAutoRefresh();
            updateTradingStatusHint();
            return;
        }
        
        // 【修复】如果用户固定了时间，使用固定时间刷新
        if (_userFixedTime) {
            console.log('[AutoRefresh] 使用固定时间刷新:', _userFixedTime);
            loadAllData(_userFixedTime);
        } else {
            loadTimestamps();
            loadAllData();
        }
    }
}, REFRESH_INTERVAL);
```

## 四、验证方法

修复后：
1. 用户选择 09:45:24
2. 数据加载正确
3. 等待自动刷新（30秒）
4. 数据仍然保持 09:45:24 的时间点，不会变成最新时间

## 五、影响范围

此修复同时影响：
- 股票攻排行
- 债券攻排行
- 行业攻排行

因为它们都通过 `loadAllData` 加载。
