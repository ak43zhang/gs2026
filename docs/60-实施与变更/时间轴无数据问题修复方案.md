# 时间轴无数据问题排查与修复方案

> **版本**: v1.0  
> **日期**: 2026-07-28  
> **状态**: 待审核  
> **问题**: Redis清除后刷新今天数据，时间轴未展示最后一条且拖不动

---

## 一、问题现象

1. 清除Redis数据后刷新页面
2. 时间轴**未直接展示最后一条**数据
3. 时间轴**拖不动**，像没数据

---

## 二、根因分析

### 问题定位

在 `initTradingDate().then()` 中（行~4728）：

```javascript
initTradingDate().then(() => {
    // 【v2.1补漏】非交易时段(实时)不查今日timestamps表
    const _liveMode = !getSelectedDate();
    if (!(_liveMode && isNonTradingHours())) {
        loadTimestamps();  // <-- 15:00后被跳过！
    }
    // ...
});
```

**关键问题**：
- 15:00后 `isNonTradingHours()` 返回 `true`
- 条件 `!(_liveMode && isNonTradingHours())` = `!(true && true)` = `false`
- `loadTimestamps()` **被跳过**，`_timestamps` 保持为 `[]`
- `shouldEnableTimeline()` 返回 `_timestamps.length > 0` = `false`
- 时间轴被禁用（`pointerEvents='none'`）

### 影响范围

| 时段 | 当前行为 | 期望行为 |
|------|----------|----------|
| 15:00后首次加载 | 不加载时间戳，时间轴禁用 | **应该加载时间戳，时间轴可用** |
| 15:00后已加载数据 | 正常（时间戳已缓存） | 正常 |

---

## 三、修复方案

### 方案：修正初始化逻辑，确保时间戳始终加载

**核心原则**：时间戳加载与"是否自动刷新"分离，时间轴数据是**基础数据**，不应被时段控制。

#### 修改点1：initTradingDate().then() 中的条件

```javascript
// 修改前（有问题）
initTradingDate().then(() => {
    const _liveMode = !getSelectedDate();
    if (!(_liveMode && isNonTradingHours())) {
        loadTimestamps();  // 15:00后被跳过
    }
    loadAllData();
});

// 修改后（修复）
initTradingDate().then(() => {
    // 【v3.0修复】时间戳始终加载，与时段无关
    // 时间轴数据是基础数据，15:00后也需要显示历史
    loadTimestamps().then(() => {
        // 时间戳加载完成后再加载数据
        loadAllData();
    });
});
```

#### 修改点2：确保15:00后时间戳加载后时间轴可用

```javascript
// 在 loadTimestamps() 成功后，主动更新时间轴可用性
async function loadTimestamps() {
    try {
        const url = buildUrl('/api/monitor/timestamps');
        const r = await (await fetch(url)).json();
        if (r.success && r.data && r.data.length > 0) {
            _timestamps = r.data;
            const slider = document.getElementById('timeline-slider');
            slider.max = _timestamps.length - 1;
            if (!_userFixedTime) {
                slider.value = _timestamps.length - 1;
                document.getElementById('timeline-time').textContent = _timestamps[_timestamps.length - 1];
            }
            
            // 【v3.0修复】加载成功后立即更新时间轴可用性
            updateTimelineAvailability();
            
            console.log('[时间戳] 加载成功，共', _timestamps.length, '个时间点');
        } else {
            console.warn('[时间戳] 无数据:', r);
            _timestamps = [];
        }
    } catch(e) {
        console.error('[时间戳] 请求失败:', e);
        _timestamps = [];
    }
}
```

#### 修改点3：15:00后首次加载时显示最后一个时间点

```javascript
// 在 loadAllData() 的 'closed' case 中，使用时间戳最后一个时间点
async function loadAllData(timeStr) {
    // ...
    case 'closed':
        // 15:00后：只加载一次
        if (!_closedPhaseDataLoaded) {
            console.log('[loadAllData] 收盘后，加载最后一次数据');
            
            // 【v3.0修复】确保使用最后一个时间戳
            let lastTimeStr = timeStr;
            if (!lastTimeStr && _timestamps.length > 0) {
                lastTimeStr = _timestamps[_timestamps.length - 1];
                console.log('[loadAllData] 使用最后一个时间戳:', lastTimeStr);
            }
            
            await loadMarketStats(lastTimeStr);
            await loadStockRanking(lastTimeStr);
            await loadBondRanking(lastTimeStr);
            await loadIndustryRanking(lastTimeStr);
            await loadCombineSignal(lastTimeStr);
            updateLastUpdateTime();
            _closedPhaseDataLoaded = true;
        }
        return;
}
```
