# 债券上攻排行区间次数问题 - 根因分析与解决方案

## 一、问题现象

- 09:40:00 时应该是新的区间，区间次数应该从0开始计算
- 但债券显示的是上一个区间（09:30-09:39）的次数
- 股票攻排行没有这个问题

## 二、根因分析（实打实）

### 2.1 代码对比

**股票 `get_stock_ranking`**（行1709）：
```python
# 获取原始股票数据（实时模式）
data = data_service.get_stock_ranking(...)
# 补充债券和行业信息，以及window_count
actual_date = date or datetime.now().strftime('%Y%m%d')  # 【注意】可能带横线
data = _enrich_stock_data(data, actual_date, datetime.now().strftime("%H:%M:%S"))
```

**债券 `get_bond_ranking`**（行1982）：
```python
actual_date = date or datetime.now().strftime('%Y%m%d')  # 【关键】可能带横线

if time_str:
    data = _get_ranking_fast('bond', actual_date, time_str, limit)
# ...
data = _enrich_bond_data(data, actual_date, time_str)
```

### 2.2 关键差异

**`_get_ranking_fast`**（行510）：
```python
table = f"monitor_{prefix}_top30_{date.replace('-', '')}"
# 使用 replace('-', '')，所以 '2026-07-31' → '20260731'（正确）
```

**`_enrich_bond_data`**（行1075）：
```python
table_name = f"monitor_zq_sssj_{date}"
# 【BUG】没有 replace('-', '')，所以 '2026-07-31' → 'monitor_zq_sssj_2026-07-31'（错误！）
```

### 2.3 问题确认

**表名对比**：
| 函数 | 传入 date | 生成的表名 | 是否正确 |
|------|----------|-----------|---------|
| `_get_ranking_fast` | '2026-07-31' | `monitor_zq_top30_20260731` | ✅ 正确 |
| `_enrich_bond_data` | '2026-07-31' | `monitor_zq_sssj_2026-07-31` | ❌ 错误！ |

**实际数据库表名**：
- `monitor_zq_top30_20260731`（正确表，有数据）
- `monitor_zq_sssj_20260731`（正确表，有数据）
- `monitor_zq_sssj_2026-07-31`（错误表名，不存在或为空）

**结果**：
- `_get_ranking_fast` 从正确表读取数据
- `_enrich_bond_data` 尝试从错误表读取 `window_count`，失败或读到旧数据

## 四、解决方案

### 方案：统一 date 格式（无横线）

**修改 `get_bond_ranking`**（行1985）：
```python
# 原代码
actual_date = date or datetime.now().strftime('%Y%m%d')

# 修改为
actual_date = (date or datetime.now().strftime('%Y%m%d')).replace('-', '')
```

**同样修改 `get_stock_ranking`**（行1712）：
```python
# 原代码
actual_date = date or datetime.now().strftime('%Y%m%d')

# 修改为
actual_date = (date or datetime.now().strftime('%Y%m%d')).replace('-', '')
```

### 备选方案：在 `_enrich_bond_data` 中处理

如果担心影响其他调用点，可以在 `_enrich_bond_data` 中处理：
```python
date_clean = date.replace('-', '')
table_name = f"monitor_zq_sssj_{date_clean}"
```

但统一在入口处理更彻底。
