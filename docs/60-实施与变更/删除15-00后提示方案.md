# 删除15:00后提示方案

> **版本**: v1.0  
> **日期**: 2026-07-28  
> **状态**: 待审核  
> **需求**: 删除"已收盘（15:00后），点击时间轴查看历史"提示

---

## 当前提示

在 `updateTradingStatusHint()` 函数的 `case 'closed':` 中：

```javascript
case 'closed':
    // 15:00后
    if (_closedPhaseDataLoaded) {
        text = '⏸️ 已收盘（15:00后），点击时间轴查看历史';
    } else {
        text = '📡 收盘数据加载中...';
    }
    show = true;
    break;
```

---

## 修改方案

### 方案：15:00后不显示任何提示

将 `case 'closed':` 的 `show` 设为 `false`，与 `case 'trading':` 一致：

```javascript
case 'closed':
    // 15:00后：不显示提示
    show = false;
    break;
```

或完全删除 `case 'closed':` 分支（让 `switch` 默认行为不显示）。

---

## 修改后完整 switch

```javascript
switch (phase) {
    case 'night':
        text = '⏸️ 非交易时段（00:00-09:25），09:30自动恢复刷新';
        show = true;
        break;
    case 'auction':
        if (_auctionDataLoaded) {
            text = '✅ 集合竞价大盘概览已加载，09:30自动恢复刷新';
        } else {
            text = '📡 集合竞价加载大盘概览中...';
        }
        show = true;
        break;
    case 'trading':
        show = false;
        break;
    case 'closed':
        // 【修改】15:00后不显示提示
        show = false;
        break;
}
```

---

## 影响

| 时段 | 修改前 | 修改后 |
|------|--------|--------|
| 00:00-09:25 | 显示提示 | 显示提示 |
| 09:25-09:30 | 显示提示 | 显示提示 |
| 09:30-15:00 | 不显示 | 不显示 |
| **15:00后** | **显示"已收盘..."** | **不显示** |
