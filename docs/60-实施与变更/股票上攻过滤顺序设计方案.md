# 股票/债券上攻过滤管道 - 最终设计方案 v2（交集模型 + 前端可配类型）

## 一、过滤模型（核心）

```
┌────────────────────────────────────────────────┐
│  Phase 1: 谓词型（串行执行）                       │
│    转债模式 → 行业联动 → 前N行业 → 绿名单 ...       │
│    逐个缩小 → 得到候选池 S                          │
├────────────────────────────────────────────────┤
│  Phase 2: 排名型（各自基于 S 独立算，结果取交集）    │
│    前N金额(基于S)   → 结果集 R1                     │
│    前N区间次数(基于S) → 结果集 R2                    │
│    最终 = R1 ∩ R2 ∩ ...                            │
└────────────────────────────────────────────────┘
```

### 为什么排名型取交集而非串行？
- **串行**：R1 → R2（R2基于R1输出）→ 顺序敏感、结果随顺序变
- **交集**：R1、R2 都基于同一个 S 算 → **顺序无关**（交集可交换），干净无歧义 ✅

这正是你要的："排名型都从谓词型数据来，排名型之间取交集"。

## 二、举例验证

谓词后候选池 S：
```
A(金额100, 次数2)  B(金额90, 次数10)  C(金额80, 次数8)  D(金额70, 次数4)
```
选「前2金额」+「前2区间次数」：
- 前2金额（基于S）= {A, B}
- 前2区间次数（基于S）= {B, C}
- **交集 = {B}** —— 同时满足两个排名条件的标的

无论先算哪个排名，交集恒为 {B}，**顺序无关**。

## 三、数据结构

### 过滤器注册表
```javascript
const STOCK_PIPELINE = {
    industry:     { label:'行业联动',      kind:'predicate', fixed:true,  apply: filterByIndustry },
    topn_sectors: { label:'仅前N行业',     kind:'predicate', fixed:true,  apply: filterStockByTopNSectors },
    bond:         { label:'转债模式',      kind:'predicate', fixed:true,  apply: filterStockByBond },
    topn_window:  { label:'仅前N区间次数', kind:'ranking',   fixed:false, sortField:'window_count' },
    // 未来扩展排名型：
    // topn_amount:  { label:'仅前N金额',   kind:'ranking',  fixed:false, sortField:'amount' },
};
```

字段说明：
- `kind`：`predicate`（谓词）/ `ranking`（排名）—— **前端可改（fixed:false 的才可改）**
- `fixed:true`：类型锁定（如转债模式天然是谓词，无排序字段，不可改为排名）
- `sortField`：排名型的排序字段（排名型必须有）

### 前端可配置的状态（存 localStorage）
```javascript
// 用户在前端调整的类型覆盖（仅 fixed:false 的生效）
let _stockKindOverride = {};  // { topn_window: 'ranking' | 'predicate' }
```

## 四、管道执行

```javascript
function runStockPipeline(data) {
    // 解析每个过滤器的实际类型（用户覆盖优先）
    const getKind = (id) => {
        const f = STOCK_PIPELINE[id];
        if (f.fixed) return f.kind;
        return _stockKindOverride[id] || f.kind;
    };

    // Phase 1: 谓词型串行 → 候选池 S
    let S = data;
    for (const id in STOCK_PIPELINE) {
        if (getKind(id) === 'predicate') {
            S = applyFilter(id, S);
        }
    }

    // Phase 2: 排名型各自基于 S 算，取交集
    const rankingIds = Object.keys(STOCK_PIPELINE).filter(id => getKind(id) === 'ranking');
    const activeRanking = rankingIds.filter(id => isRankingActive(id)); // 值>0才算激活

    if (activeRanking.length === 0) return S;

    let resultCodes = null;
    for (const id of activeRanking) {
        const subset = applyFilter(id, S);           // 基于 S 算前N
        const codes = new Set(subset.map(it => it.code));
        resultCodes = (resultCodes === null)
            ? codes
            : new Set([...resultCodes].filter(c => codes.has(c)));  // 交集
    }
    return S.filter(it => resultCodes.has(it.code));
}
```

### 排名型统一函数（基于传入 data，通用化）
```javascript
// 通用排名过滤：按 sortField 取前N，排除 <=0，不足N则有多少展示多少
function applyRankingFilter(id, data) {
    const f = STOCK_PIPELINE[id];
    const el = document.getElementById(f.selectId);
    if (!el) return data;
    const n = parseInt(el.value) || 0;
    if (n <= 0) return data;
    const field = f.sortField;
    const sorted = data.slice()
        .filter(it => (parseFloat(it[field]) || 0) > 0)
        .sort((a, b) => (parseFloat(b[field]) || 0) - (parseFloat(a[field]) || 0));
    const codes = {};
    for (let i = 0; i < Math.min(n, sorted.length); i++) codes[sorted[i].code] = true;
    return data.filter(it => codes[it.code]);
}
```

## 五、前端"类型配置"界面

在过滤面板底部增加一个"⚙ 过滤器类型"折叠区：

```
过滤器类型配置
─────────────────────
行业联动       [谓词] (锁定)
仅前N行业      [谓词] (锁定)
转债模式       [谓词] (锁定)
仅前N区间次数  [谓词▼/排名] ← 可切换
```

- `fixed:true` 的显示类型但灰化不可改
- `fixed:false` 的显示下拉，可选 谓词/排名
- 改动存 localStorage，`rerenderStockRanking()` 立即重算

### 类型切换的语义
- 设为**排名型**：按 sortField 取前N（当前"仅前N区间次数"的行为）
- 设为**谓词型**：退化为"该字段 > 0 即保留"（即"有区间次数就显示"）

> 说明：`sortField` 存在的过滤器才能在两种类型间切换；无 sortField 的（如转债模式）锁定为谓词。
