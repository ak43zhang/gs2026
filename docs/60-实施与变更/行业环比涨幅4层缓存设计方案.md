# 行业环比涨幅4层缓存设计方案

## 需求确认
1. 保留绝对涨幅排行字段（rank_by_change_pct）
2. 新增环比涨幅排行字段（rank_by_delta_pct）
3. 4层缓存架构：内存 → Redis → MySQL → 自身
4. 应用于区间测算功能

## 4层缓存架构详解

### L1-内存缓存（进程内）
```python
# 全局变量，tick间保持
_INDUSTRY_PREV_CHANGE_CACHE = {
    'date': None,           # 日期，跨日清空
    'time': None,           # 上一tick时间
    'data': {},             # {industry_code: avg_change_pct}
    'delta_data': {},       # {industry_code: delta_change_pct}  # 新增
}
```

**作用**：当前tick计算环比时，直接从内存取上一tick数据，最快。

**生命周期**：
- 进程启动：空
- 每tick更新：保存当前tick的avg_change_pct供下一tick使用
- 跨日检测：date变化时清空

### L2-Redis缓存（跨进程/重启恢复）
```
Key: monitor_hy_top30_{date}:prev_change
Type: Hash
Field: industry_code
Value: avg_change_pct（序列化字符串）

Key: monitor_hy_top30_{date}:delta  # 新增
Type: Hash
Field: industry_code  
Value: delta_change_pct（环比涨幅）
```

**作用**：
- monitor_stock.py重启后，从Redis恢复上一tick数据，继续计算环比
- 区间测算服务可从Redis读取历史环比数据（比查MySQL快）

### L3-MySQL持久化
```sql
-- monitor_hy_top30_{date} 表新增字段
ALTER TABLE monitor_hy_top30_{date} 
ADD COLUMN delta_change_pct DOUBLE COMMENT '环比涨幅（与上一tick相比）',
ADD COLUMN rank_by_delta_pct INT COMMENT '环比涨幅排名（1=最大）';
```

**作用**：
- 历史数据回溯
- 区间测算服务查询数据源

### L4-自身兜底（首tick/异常）
**策略**：
- 首tick（9:30:03）：无上一tick，delta_change_pct = 0，rank_by_delta_pct = 中间值
- 数据缺失：若Redis/MySQL都无上一tick数据，用当前绝对涨幅作为基准（delta=0）

## 数据流（tick级）

```
tick N-1 (09:30:00)
  ↓
计算行业avg_change_pct → 存L1内存(_INDUSTRY_PREV_CHANGE_CACHE)
                       → 存L2 Redis (monitor_hy_top30_{date}:prev_change)
                       → 存L3 MySQL (avg_change_pct字段)
  ↓
tick N (09:30:03)
  ↓
从L1内存取tick N-1数据 → 计算delta = tickN.avg - tickN-1.avg
                       → 存L1内存(_INDUSTRY_PREV_CHANGE_CACHE['delta_data'])
                       → 存L2 Redis (monitor_hy_top30_{date}:delta)
                       → 存L3 MySQL (delta_change_pct, rank_by_delta_pct字段)
```

### 2. calculate_industry_topn 改造
```python
def calculate_industry_topn(top30_df, df_now, date_str, time_full):
    # ... 现有计算 ...
    
    # 第8步后：计算环比涨幅
    global _INDUSTRY_PREV_CHANGE_CACHE
    
    # 跨日清空
    if _INDUSTRY_PREV_CHANGE_CACHE['date'] != date_str:
        _INDUSTRY_PREV_CHANGE_CACHE = {'date': date_str, 'time': None, 'data': {}, 'delta_data': {}}
    
    # 计算环比Δ
    if _INDUSTRY_PREV_CHANGE_CACHE['time'] is not None:
        # 有上一tick数据，计算Δ
        result_df['delta_change_pct'] = result_df['avg_change_pct'] - result_df['code'].map(
            _INDUSTRY_PREV_CHANGE_CACHE['data']
        ).fillna(result_df['avg_change_pct'])  # 无上一tick的用当前值（Δ=0）
    else:
        # 首tick，Δ=0
        result_df['delta_change_pct'] = 0.0
    
    # 环比排名
    result_df['rank_by_delta_pct'] = result_df['delta_change_pct'].rank(
        method='min', ascending=False
    ).astype(int)
    
    # 保存当前tick到L1内存（供下一tick使用）
    _INDUSTRY_PREV_CHANGE_CACHE['time'] = time_full
    _INDUSTRY_PREV_CHANGE_CACHE['data'] = dict(zip(
        result_df['code'].astype(str), 
        result_df['avg_change_pct'].astype(float)
    ))
    _INDUSTRY_PREV_CHANGE_CACHE['delta_data'] = dict(zip(
        result_df['code'].astype(str),
        result_df['delta_change_pct'].astype(float)
    ))
    
    return result_df
```

### 4. 新增Redis存储函数
```python
def _save_industry_delta_to_redis(df: pd.DataFrame, date_str: str, time_full: str):
    """L2缓存：存环比涨幅到Redis hash"""
    try:
        client = redis_util._get_redis_client()
        # 存当前绝对涨幅（供下一tick计算Δ）
        hash_key_prev = f"monitor_hy_top30_{date_str}:prev_change"
        mapping_prev = dict(zip(
            df['code'].astype(str).str.strip(),
            df['avg_change_pct'].astype(float).astype(str)
        ))
        if mapping_prev:
            client.hset(hash_key_prev, mapping=mapping_prev)
            client.expire(hash_key_prev, 86400)
        
        # 存当前环比涨幅（供区间测算服务查询）
        hash_key_delta = f"monitor_hy_top30_{date_str}:delta"
        mapping_delta = dict(zip(
            df['code'].astype(str).str.strip(),
            df['delta_change_pct'].astype(float).astype(str)
        ))
        if mapping_delta:
            client.hset(hash_key_delta, mapping=mapping_delta)
            client.expire(hash_key_delta, 86400)
            
        # 存时间戳列表（供区间测算服务知道有哪些tick）
        ts_key = f"monitor_hy_top30_{date_str}:delta_timestamps"
        client.rpush(ts_key, time_full)
        client.expire(ts_key, 86400)
    except Exception as e:
        logger.warning(f"行业环比Redis缓存失败: {e}")
```

### 5. 重启恢复函数（L2 → L1）
```python
def _recover_industry_prev_from_redis(date_str: str, time_full: str) -> bool:
    """重启后从Redis恢复上一tick数据到L1内存"""
    try:
        client = redis_util._get_redis_client()
        hash_key = f"monitor_hy_top30_{date_str}:prev_change"
        raw = client.hgetall(hash_key)
        if not raw:
            return False
        
        data = {}
        for code_b, val_b in raw.items():
            code = code_b.decode() if isinstance(code_b, bytes) else code_b
            val = val_b.decode() if isinstance(val_b, bytes) else val_b
            data[code] = float(val)
        
        global _INDUSTRY_PREV_CHANGE_CACHE
        _INDUSTRY_PREV_CHANGE_CACHE['date'] = date_str
        _INDUSTRY_PREV_CHANGE_CACHE['time'] = time_full  # 用当前time作为"上一tick"
        _INDUSTRY_PREV_CHANGE_CACHE['data'] = data
        logger.info(f"从Redis恢复行业上一tick数据: {len(data)}个行业")
        return True
    except Exception as e:
        logger.warning(f"Redis恢复行业数据失败: {e}")
        return False
```
