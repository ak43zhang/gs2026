## 三、方案设计（v2.0）

### 核心逻辑
```
00:00-09:25  → 完全不加载
09:25-09:30  → 每隔N秒尝试加载"大盘概览"，
               成功一次后就不再加载（数据保持显示到09:30）
09:30后      → 正常加载（大盘概览+其他数据，3秒刷新）
```

### 3.1 集合竞价加载函数（只加载大盘概览，带成功判断）

```javascript
// ===== 09:25 大盘概览专用加载（重试到成功即停） =====
async function loadAuctionMarketOverview() {
    // 若已加载成功，直接跳过（保证只加载一次）
    if (_auctionDataLoaded) return true;
    
    try {
        const url = buildUrl('/api/monitor/market-overview');
        const r = await (await fetch(url)).json();
        
        if (r.success && r.data) {
            // 判断是否真的有数据（大盘概览有效）
            const hasData = _isMarketOverviewValid(r.data);
            if (hasData) {
                // 加载成功：渲染 + 标记
                _bpMktData = r.data || {};
                renderMarketData('stock', r.data?.stock);
                renderMarketData('bond', r.data?.bond);
                syncTopHeight();
                updateWeather(r.data?.stock, r.data?.bond, _bpMktData);
                updateMiniCharts();
                
                _auctionDataLoaded = true;  // ✅ 成功才标记，之后不再加载
                console.log('[Auction] 大盘概览加载成功，保持显示到09:30');
                return true;
            } else {
                console.log('[Auction] 大盘概览数据暂为空，等待下次重试');
            }
        }
    } catch (e) {
        console.log('[Auction] 大盘概览加载失败，等待下次重试:', e.message);
    }
    return false;  // 未成功，下次继续重试
}

// 判断大盘概览数据是否有效
function _isMarketOverviewValid(data) {
    // 大盘有股票或转债数据即算有效
    const hasStock = data.stock && Object.keys(data.stock).length > 0;
    const hasBond = data.bond && Object.keys(data.bond).length > 0;
    const hasMarketAvg = data.market_avg && data.market_avg.length > 0;
    return hasStock || hasBond || hasMarketAvg;
}
```

### 3.3 重试驱动（复用 startTradingCheckTimer）

```javascript
function startTradingCheckTimer() {
    if (_tradingCheckTimer) clearInterval(_tradingCheckTimer);
    
    _tradingCheckTimer = setInterval(() => {
        const nowTimeVal = getCurrentTimeVal();
        
        // 集合竞价时段(09:25-09:30) 且未加载成功 → 重试
        if (nowTimeVal >= 925 && nowTimeVal < 930 && !_auctionDataLoaded) {
            console.log('[Monitor] 集合竞价重试加载大盘概览');
            if (!document.hidden) {
                loadAuctionMarketOverview();  // 重试，成功后函数内部会标记
            }
            updateTradingStatusHint();
            return;
        }
        
        // 进入交易时段(09:30, 13:00) → 恢复正常刷新
        if (isTradingHours() && !_pollingTimer) {
            console.log('[Monitor] 进入交易时段，恢复刷新');
            adjustPollingInterval(3000);
            return;
        }
        
        updateTradingStatusHint();
    }, _auctionRetryInterval);  // 重试间隔（见下方参数）
}
```

**重试间隔说明**：
- 当前检查定时器是 30 秒。集合竞价只有 5 分钟（09:25-09:30），30秒重试太慢（最多10次）。
- **建议集合竞价期间用更短间隔**，如 **10 秒**（5分钟内最多30次重试，足够覆盖数据延迟）。

## 四、关键保证点

| 保证点 | 实现方式 |
|--------|----------|
| **只加载大盘概览** | 集合竞价只调 `loadAuctionMarketOverview()`，不调 `loadCombineSignals()` |
| **只加载一次（成功后）** | `_auctionDataLoaded` 标记，**成功才置true**，之后跳过 |
| **重试到成功** | 未成功时 `_auctionDataLoaded` 保持false，定时器持续重试 |
| **数据保持显示到09:30** | 加载成功后不清空 `_bpMktData`，页面持续显示；09:30才恢复刷新 |
| **日期正确** | 复用 `getSelectedDate()` → 今天自动用今天日期 |
| **其他数据不加载** | 删除集合竞价中的 `loadCombineSignals()` 调用 |

## 七、我的倾向

| 决策 | 倾向 | 理由 |
|------|------|------|
| 加载内容 | **只加载大盘概览** | 严格按用户期望，其他数据09:30再加载 |
| 重试间隔 | **10秒** | 集合竞价仅5分钟，10秒重试足够（最多30次），不过密 |
| 成功判断 | **有股票/转债/大盘均值任一即成功** | 大盘概览有数据即可 |
| 数据保持 | **成功后不清空，显示到09:30** | 严格按用户期望 |
| 无限重试到09:30 | **是（若一直失败）** | 用户说"重试直到能加载到"，失败就一直试到09:30 |

**一句话**：09:25起每10秒尝试加载**仅大盘概览**，成功一次即停并保持显示，失败则重试到09:30，09:30恢复正常刷新。
