- 更新设计文档：删除分层设计，改为渐进式计算说明

**渐进式计算逻辑**:
```
数据点 >= 要求点数（如20点）:
    → 基于完整窗口计算（如15分钟）
数据点 < 要求点数 但 >= 最小点数（如8点）:
    → 基于现有全部数据计算
数据点 < 最小点数:
    → 返回None
```

**最小点数设置**:
- 5分钟斜率：5个点（约15秒）
- 15分钟斜率：8个点（约24秒）

**实际效果**:

| 时间 | 数据点 | 15分钟斜率 | 计算窗口 |
|------|--------|------------|----------|
| 09:30:09 | 3点 | None | 数据不足 |
| 09:30:24 | 8点 | ✅ 有值 | 基于24秒 |
| 09:35:00 | 100点 | ✅ 有值 | 基于5分钟 |
| 09:45:00 | 300点 | ✅ 有值 | 完整15分钟 |
