## 二、滞后性问题分析

### 2.1 根因

`_calc_slope()` 使用**等权线性回归**：

```python
def _calc_slope(buf):
    """60/300个数据点全部等权参与回归"""
    # y = kx + b 的最小二乘解
    # 第1个点和第60个点的权重完全相同
```

**后果**：当市场在 t=50 时突然反转（从涨→跌），前 50 个"涨"的数据点仍然拉着回归线向上。需要等到 t>80（超过一半数据被替换）斜率才会翻负。

### 2.2 量化滞后程度

| 指标 | 窗口 | 理论最大滞后 | 实际感知滞后 |
|------|------|-------------|-------------|
| `mkt_slope_short` (60点) | 3min | ~1.5min | 约30-60秒才反映方向变化 |
| `mkt_slope_long` (300点) | 15min | ~7.5min | 约3-5分钟才反映趋势拐点 |

### 2.3 解决原理：指数加权回归

```
等权回归：  w_i = 1/N（所有点权重相同）
指数加权：  w_i = e^(-λ * (t_now - t_i))

λ = ln(2) / half_life

half_life = 30s 时：
  - 30秒前的数据权重 = 50%
  - 60秒前的数据权重 = 25%
  - 90秒前的数据权重 = 12.5%
```

**效果**：近期数据对回归线影响远大于远期，市场反转时斜率能在 10-15秒 内响应。

### 2.4 个券已解决的对比

| 算法 | 市场急跌5秒后的斜率反应 | 市场急跌30秒后的斜率反应 |
|------|------------------------|------------------------|
| 等权 `slope_short` | 几乎不变（5/60=8%新数据） | 变化微小（30/60=50%新数据） |
| 加权 `weighted_slope_2m` | 明显下降（最近5秒权重占~40%） | 完全翻转 |

## 三、修改方案

### 3.1 新增大盘级加权指标

在 `compute_market_indicators()` 末尾新增 3 个指标，写入已有的 `ext_indicators` JSON 列：

| 新字段 | 含义 | 算法 | 存储 |
|--------|------|------|------|
| `mkt_weighted_slope_2m` | 大盘2分钟加权斜率 | 指数加权回归, half_life=30s | `ext_indicators` JSON |
| `mkt_change_1m_pct` | 大盘1分钟变化率 | 1分钟前avg_pct vs 当前 | `ext_indicators` JSON |
| `mkt_price_acceleration` | 大盘动量加速度 | 当前mkt_weighted_slope - 上一tick | `ext_indicators` JSON |

### 3.2 数据结构设计

修改后 `ext_indicators` JSON 结构：

```json
{
    "weighted_slope_2m": 0.000123,
    "change_1m_pct": 0.05,
    "price_acceleration": 0.000008,
    "mkt_weighted_slope_2m": 0.000045,
    "mkt_change_1m_pct": 0.03,
    "mkt_price_acceleration": 0.000003
}
```

**设计考量**：
- 大盘字段广播到所有行（同tick值相同），与现有 `mkt_slope_short` 等字段模式一致
- 放入已有 `ext_indicators` JSON 列，不新增独立列，减少存储/IO开销
- 大盘计算每tick只执行一次（O(1)计算 + O(N)写入），不影响性能

### 3.3 实现细节

#### 缓存结构（新增全局变量）

```python
# 大盘加权斜率缓存
_mkt_ext_price_cache = []            # [(timestamp_seconds, avg_pct), ...] 保留2.5分钟
_mkt_ext_prev_slope = 0.0            # 上一tick大盘加权斜率
_mkt_ext_date = None                 # 日期切换检测
```

#### 计算流程

```python
def compute_mkt_ext_indicators(df_now, time_full, current_date):
    """
    计算大盘级扩展指标（每tick一次，O(1)计算 + O(N)广播写入）
    复用 _calc_weighted_slope() 函数
    """
    global _mkt_ext_price_cache, _mkt_ext_prev_slope, _mkt_ext_date
    
    # 日期切换 → 清空
    if _mkt_ext_date != current_date:
        _mkt_ext_price_cache = []
        _mkt_ext_prev_slope = 0.0
        _mkt_ext_date = current_date
    
    # 大盘平均涨跌幅
    avg_pct = float(df_now['change_pct'].mean())
    current_seconds = _time_to_seconds(time_full)
    
    # 追加 + 清理过期（保留150秒）
    _mkt_ext_price_cache.append((current_seconds, avg_pct))
    cutoff = current_seconds - 150
    _mkt_ext_price_cache = [(ts, p) for ts, p in _mkt_ext_price_cache if ts >= cutoff]
    
    # 1. 加权斜率
    if len(_mkt_ext_price_cache) >= 2:
        prices = [p for _, p in _mkt_ext_price_cache]
        times = [t for t, _ in _mkt_ext_price_cache]
        mkt_ws = round(_calc_weighted_slope(prices, times, half_life=30), 6)
    else:
        mkt_ws = 0.0
    
    # 2. 1分钟变化率
    target_ts = current_seconds - 60
    pct_1m_ago = None
    for ts, p in reversed(_mkt_ext_price_cache):
        if ts <= target_ts:
            pct_1m_ago = p
            break
    mkt_c1p = round(avg_pct - pct_1m_ago, 4) if pct_1m_ago is not None else 0.0
    
    # 3. 加速度
    mkt_pa = round(mkt_ws - _mkt_ext_prev_slope, 6)
    _mkt_ext_prev_slope = mkt_ws
    
    return mkt_ws, mkt_c1p, mkt_pa
```

#### 集成到 `compute_ext_indicators()`

在现有 `compute_ext_indicators()` 末尾，将大盘指标合并到每行的 `ext_indicators` JSON 中：

```python
# 计算大盘扩展指标（每tick一次）
mkt_ws, mkt_c1p, mkt_pa = compute_mkt_ext_indicators(df_now, time_full, current_date)

# 合并到 ext_indicators JSON
for i in range(len(df_now)):
    ext_indicators_list.append(json.dumps({
        'weighted_slope_2m': weighted_slopes[i],
        'change_1m_pct': change_1m[i],
        'price_acceleration': accelerations[i],
        'mkt_weighted_slope_2m': mkt_ws,        # 新增
        'mkt_change_1m_pct': mkt_c1p,           # 新增
        'mkt_price_acceleration': mkt_pa,       # 新增
    }, ensure_ascii=False))
```

### 3.4 性能分析

| 操作 | 复杂度 | 耗时预估(400+债券) |
|------|--------|-------------------|
| 大盘avg_pct计算 | O(N) | <0.1ms（pandas向量化） |
| 加权斜率(市场级) | O(K) K≈50点 | <0.05ms |
| 变化率+加速度 | O(K) | <0.02ms |
| JSON序列化(含新字段) | O(N) | 已在现有循环中，增加3个key约+0.5ms |
| **总计新增耗时** | — | **<1ms/tick** |

**结论**：不影响现有3秒tick循环的性能预算。

## 四、参数调优手段

### 4.1 half_life 调优

| half_life | 响应速度 | 噪声敏感度 | 适用场景 |
|-----------|----------|------------|----------|
| 15s | 极快(~5秒翻转) | 高（易误判） | 超短线/打板 |
| **30s（当前默认）** | **快(~10-15秒翻转)** | **中** | **日内波段** |
| 60s | 中等(~25秒翻转) | 低 | 趋势跟踪 |
| 120s | 慢(~50秒翻转) | 极低 | 大趋势判断 |

**调优建议**：
- 当前 `half_life=30` 适合日内转债交易（3-15分钟持仓）
- 如需更快响应（如做T），可降到 15-20
- 如需更稳定（如趋势过滤），可升到 45-60
- 大盘和个券可使用不同 half_life（大盘建议略大，因为市场级噪声更大）

### 4.2 窗口长度调优

| 参数 | 当前值 | 可调范围 | 影响 |
|------|--------|----------|------|
| 缓存保留时间 | 150s (2.5min) | 90-300s | 数据点数量，影响回归精度 |
| 1分钟变化率窗口 | 60s | 30-120s | 变化率灵敏度 |
| WINDOW_SHORT(等权) | 60点 | 30-120点 | slope_short 响应速度 |
| WINDOW_LONG(等权) | 300点 | 150-600点 | slope_long 趋势平滑度 |

### 4.3 多时间尺度策略

利用不同指标的响应速度差异构建信号：

```
快指标 → 中指标 → 慢指标
change_1m_pct → weighted_slope_2m → slope_short → slope_long
(零滞后)        (10-15秒)          (30-60秒)     (3-5分钟)
```

**典型用法**：
- 快指标翻正 + 慢指标为正 → 趋势加速（强做多信号）
- 快指标翻负 + 慢指标仍正 → 可能是回调，观察
- 快指标翻负 + 慢指标开始下降 → 趋势拐点确认

## 五、各指标具体使用场景

### 5.1 个券级

| 指标 | 使用场景 | 信号示例 |
|------|----------|----------|
| `weighted_slope_2m` | 判断个券短期走势方向 | >0 且递增 → 上攻中 |
| `change_1m_pct` | 判断个券瞬时动量 | >0.5% → 强势拉升 |
| `price_acceleration` | 检测个券拐点 | 从正转负 → 上攻减速/见顶 |
| `slope_short` | 中等时间尺度趋势 | 用于排行/排序的稳定指标 |
| `slope_long` | 日内大趋势 | 用于判断个券今日整体方向 |
| `peak_vol_bias` | 放量后回落程度 | 大幅负值 → 放量见顶已回落 |
| `high_distance` | 距日内高点距离 | 接近0 → 在高位/创新高 |

### 5.2 大盘级

| 指标 | 使用场景 | 信号示例 |
|------|----------|----------|
| `mkt_weighted_slope_2m`（新） | 判断市场短期走势方向 | >0 → 市场在走强 |
| `mkt_change_1m_pct`（新） | 判断市场瞬时动量 | 突然大幅变负 → 市场急跌 |
| `mkt_price_acceleration`（新） | 检测市场拐点 | 从负转正 → 市场止跌企稳 |
| `mkt_slope_short` | 市场中等趋势（略滞后） | 用于确认趋势方向 |
| `mkt_slope_long` | 市场大趋势（滞后） | 用于日内整体环境判断 |
| `mkt_peak_vol_bias` | 市场放量后回落程度 | 判断是否缩量调整 |
| `mkt_high_distance` | 市场距日内高点距离 | 判断是否在阶段性顶部 |

### 5.3 组合使用

| 策略 | 快指标条件 | 慢指标条件 | 含义 |
|------|-----------|-----------|------|
| **大盘加速上攻** | `mkt_price_acceleration > 0` | `mkt_slope_short > 0` | 大盘趋势向上且在加速 |
| **大盘拐点预警** | `mkt_price_acceleration < 0` | `mkt_slope_short > 0` | 趋势仍向上但已减速 |
| **个券强于大盘** | `weighted_slope_2m > mkt_weighted_slope_2m * 2` | — | 个券上攻力度显著强于市场 |
| **顺势加仓** | `change_1m_pct > 0.3%` | `mkt_weighted_slope_2m > 0` | 个券拉升 + 市场配合 |
| **逆势警惕** | `change_1m_pct > 0.3%` | `mkt_weighted_slope_2m < 0` | 个券拉升但市场走弱 |
