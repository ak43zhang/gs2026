# 量化选债历史数据回放测试方案设计

## 一、方案概述

### 1.1 目标

在无实时数据流入的环境下，使用历史数据验证量化选债实时信号跟踪功能的正确性。

### 1.2 核心要求

- ✅ 走完整真实流程（筛选逻辑、状态流转、保存逻辑一致）
- ✅ 执行效率快（全天4000+tick在可接受时间内完成）
- ✅ 内存安全（流式处理，不OOM）
- ✅ 幂等性（多次执行结果一致，不受Redis已有数据影响）
- ✅ 双模式可切换（运行时替换 / Redis回放）

---

## 二、双模式架构

### 2.1 模式一：运行时替换（默认）

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  MySQL历史数据   │────→│  流式读取tick   │────→│  内存虚拟Redis  │
│  (只读)         │     │  (一次一tick)   │     │  (dict模拟)     │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                        ↓
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  MySQL          │←────│  保存命中记录   │←────│  系统处理       │
│  (quant_screen   │     │  (批量插入)     │     │  (Monkey Patch) │
│   _hits)        │     │                 │     │                 │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

**原理**：
- 运行时替换 `_get_current_sssj()` 函数
- 原函数：从Redis读取 → 替换后：从内存dict读取
- 系统其他代码完全无感知

**优势**：
- 零Redis IO，速度最快
- 天然幂等，不受Redis已有数据影响
- 内存占用低（单tick ~250KB）

---

### 2.2 模式二：Redis回放（可选）

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  MySQL历史数据   │────→│  流式读取tick   │────→│  Redis Pipeline │
│  (只读)         │     │  (一次一tick)   │     │  批量写入       │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                        ↓
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  MySQL          │←────│  保存命中记录   │←────│  系统正常处理   │
│  (quant_screen   │     │  (批量插入)     │     │  (读取Redis)    │
│   _hits)        │     │                 │     │                 │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

**原理**：
- 使用Redis Pipeline批量写入tick数据
- 系统正常从Redis读取处理
- 更接近真实生产流程

**优势**：
- 验证Redis层是否正常
- 可测试Redis性能瓶颈

## 三、实施设计

### 3.1 脚本结构

```python
# test/replay_quant_screen_hits.py

import asyncio
import argparse
from datetime import datetime, timedelta

# 导入系统模块
import sys
sys.path.insert(0, 'F:\\pyworkspace2026\\gs2026\\src')

from gs2026.dashboard2.routes import monitor
from gs2026.dashboard.services.data_service import DataService

class QuantScreenReplayer:
    """量化选债历史数据回放器"""
    
    MODES = ['mock', 'redis']  # mock=运行时替换, redis=Redis回放
    
    def __init__(self, mode='mock'):
        self.mode = mode
        self._original_func = None
        self._mock_data = None
        self.data_service = DataService()
        
    async def __aenter__(self):
        """上下文管理器：初始化模式"""
        if self.mode == 'mock':
            # 模式一：运行时替换
            self._original_func = monitor._get_current_sssj
            monitor._get_current_sssj = self._mock_get_current_sssj
        return self
        
    async def __aexit__(self, exc_type, exc_val, exc_tb):
        """上下文管理器：恢复原函数"""
        if self.mode == 'mock' and self._original_func:
            monitor._get_current_sssj = self._original_func
            
    def _mock_get_current_sssj(self, date):
        """Mock函数：返回内存中的当前tick数据"""
        return self._mock_data
        
    async def replay(self, trade_date, time_start='093000', time_end='150000', 
                     speed='1x', schemes=None):
        """
        执行回放
        
        Args:
            trade_date: 交易日期 '20260708'
            time_start: 开始时间 '093000'
            time_end: 结束时间 '150000'
            speed: 播放速度 '1x'=实时, '10x'=10倍速, '0'=立即完成
            schemes: 测试用的方案列表
        """
        # 1. 从MySQL流式读取tick分组
        tick_groups = await self._fetch_tick_groups(trade_date, time_start, time_end)
        
        results = []
        total_ticks = 0
        
        async with self:  # 进入上下文（模式初始化）
            for tick_time, df_tick in tick_groups:
                total_ticks += 1
                
                # 2. 设置当前tick数据
                if self.mode == 'mock':
                    self._mock_data = df_tick
                else:
                    # 模式二：写入Redis
                    await self._write_to_redis(df_tick)
                
                # 3. 调用系统API
                result = await self._call_quant_screen(trade_date, schemes)
                
                # 4. 记录结果
                results.append({
                    'tick_time': tick_time,
                    'match_count': len(result.get('matches', [])),
                    'stats': result.get('stats', {})
                })
                
                # 5. 速度控制
                if speed != '0':
                    await self._sleep_by_speed(speed)
                    
        return {
            'total_ticks': total_ticks,
            'results': results,
            'summary': self._calc_summary(results)
        }
        
    async def _fetch_tick_groups(self, trade_date, time_start, time_end):
        """流式读取tick分组（generator）"""
        # 使用aiomysql流式查询
        pool = await self.data_service._get_mysql_pool()
        async with pool.acquire() as conn:
            async with conn.cursor() as cur:
                sql = """
                    SELECT * FROM monitor_zq_sssj_%s 
                    WHERE time BETWEEN %s AND %s
                    ORDER BY time
                """ % (trade_date, time_start, time_end)
                await cur.execute(sql)
                
                # 按time分组yield
                current_time = None
                current_rows = []
                
                async for row in cur:
                    if row['time'] != current_time:
                        if current_rows:
                            yield current_time, pd.DataFrame(current_rows)
                        current_time = row['time']
                        current_rows = []
                    current_rows.append(row)
                    
                if current_rows:
                    yield current_time, pd.DataFrame(current_rows)
                    
    async def _write_to_redis(self, df_tick):
        """模式二：批量写入Redis"""
        redis = await self.data_service._get_redis()
        pipe = redis.pipeline()
        
        for _, row in df_tick.iterrows():
            bond_code = row['bond_code']
            data = row.to_dict()
            pipe.hset('bond:latest', bond_code, json.dumps(data, default=str))
            
        await pipe.execute()
        
    async def _call_quant_screen(self, trade_date, schemes):
        """调用系统量化筛选API"""
        # 构造请求
        request_data = {
            'date': trade_date,
            'schemes': schemes or []
        }
        
        # 直接调用内部函数（绕过HTTP）
        from flask import Flask
        app = Flask(__name__)
        
        with app.test_request_context(json=request_data):
            # 模拟异步请求
            result = await monitor.quant_screen()
            return result.get_json()
            
    async def _sleep_by_speed(self, speed):
        """根据速度控制间隔"""
        # 真实tick间隔约3秒
        base_interval = 3.0
        
        if speed.endswith('x'):
            factor = float(speed[:-1])
            await asyncio.sleep(base_interval / factor)
        else:
            await asyncio.sleep(float(speed))
            
    def _calc_summary(self, results):
        """计算汇总统计"""
        total_matches = sum(r['match_count'] for r in results)
        tick_with_matches = sum(1 for r in results if r['match_count'] > 0)
        
        return {
            'total_ticks': len(results),
            'ticks_with_matches': tick_with_matches,
            'total_matches': total_matches,
            'avg_matches_per_tick': total_matches / len(results) if results else 0
        }


# CLI入口
async def main():
    parser = argparse.ArgumentParser(description='量化选债历史数据回放测试')
    parser.add_argument('--date', required=True, help='交易日期 20260708')
    parser.add_argument('--mode', default='mock', choices=['mock', 'redis'],
                       help='回放模式：mock=运行时替换(默认), redis=Redis回放')
    parser.add_argument('--time-start', default='093000', help='开始时间')
    parser.add_argument('--time-end', default='150000', help='结束时间')
    parser.add_argument('--speed', default='10x', help='播放速度：1x/10x/100x/0')
    parser.add_argument('--schemes', help='方案JSON文件路径')
    
    args = parser.parse_args()
    
    # 加载方案
    schemes = []
    if args.schemes:
        with open(args.schemes, 'r', encoding='utf-8') as f:
            schemes = json.load(f)
    else:
        # 默认测试方案
        schemes = [
            {
                'name': '强势反弹',
                'conditions': [
                    {'field': 'change_pct', 'op': '>', 'value': 2.0, 'logic': 'AND'},
                    {'field': 'amount', 'op': '>', 'value': 1000000, 'logic': 'AND'}
                ],
                'stop_loss': 3.0,
                'take_profit': 5.0,
                'max_hold_time': 30
            }
        ]
    
    # 执行回放
    replayer = QuantScreenReplayer(mode=args.mode)
    result = await replayer.replay(
        trade_date=args.date,
        time_start=args.time_start,
        time_end=args.time_end,
        speed=args.speed,
        schemes=schemes
    )
    
    # 输出结果
    print(f"\n{'='*60}")
    print(f"回放完成: {args.date}")
    print(f"模式: {args.mode}")
    print(f"速度: {args.speed}")
    print(f"{'='*60}")
    print(f"总tick数: {result['total_ticks']}")
    print(f"有命中的tick: {result['summary']['ticks_with_matches']}")
    print(f"总命中次数: {result['summary']['total_matches']}")
    print(f"平均每tick命中: {result['summary']['avg_matches_per_tick']:.2f}")
    print(f"{'='*60}\n")
    
    # 保存详细结果
    output_file = f"test/replay_result_{args.date}_{args.mode}.json"
    with open(output_file, 'w', encoding='utf-8') as f:
        json.dump(result, f, ensure_ascii=False, indent=2)
    print(f"详细结果已保存: {output_file}")

if __name__ == '__main__':
    asyncio.run(main())
```

## 四、使用示例

### 4.1 默认模式（运行时替换，10倍速）

```bash
# 回放全天，10倍速
python test/replay_quant_screen_hits.py --date 20260708 --speed 10x

# 回放上午开盘1小时，100倍速
python test/replay_quant_screen_hits.py --date 20260708 \
    --time-start 093000 --time-end 100000 --speed 100x

python test/replay_quant_screen_hits.py --date 20260708 --speed 0
```

## 五、验证检查点

| 检查项 | 验证方法 |
|--------|---------|
| 命中记录是否正确生成 | `SELECT COUNT(*) FROM quant_screen_hits WHERE trade_date='20260708'` |
| 状态流转是否正确 | 对比同一债券不同时间点的 `signal_status` |
| 止盈止损是否正确触发 | 构造价格触及阈值的数据，检查 `is_locked` 和 `lock_reason` |
| 时长计算是否正确 | 检查 `created_at` 和 `updated_at` 差值 |
| max_hold_time锁定 | 设置短max_hold_time，验证超时锁定 |
| 多方案命中 | 同一债券被多个方案命中，验证分别记录 |
