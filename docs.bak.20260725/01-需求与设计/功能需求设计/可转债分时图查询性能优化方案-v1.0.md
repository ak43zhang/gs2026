# 可转债分时图查询性能优化方案设计文档 v1.1

## 一、需求概述

### 1.1 目标效果
鼠标悬停到任意债券代码上，**即时**（<200ms）展示该债券的分时图。图表持续显示时，**每个tick（3秒）实时推送**新数据点，分时线实时延伸。

### 1.2 分时图内容
- **价格折线**：每个tick（3秒级）的价格变化，实时延伸
- **涨跌幅**：相对昨收的百分比变化，正红负绿
- **成交量柱**：每分钟成交量（底部柱状图）
- **均价线**：日内均价参考（黄色）
- **昨收基准线**：虚线标记0%位置
- **十字光标**：随鼠标移动显示精确时间/价格/涨幅

### 1.3 适用场景
- 数据监控 > 量化选债页面（monitor.html）
- 分析中心页面的转债列表
- 任何展示 `bond_code` 的表格/列表

## 二、性能指标

| 指标 | 目标 |
|------|------|
| 悬停到首次显示 | < 200ms |
| tick推送延迟 | < 100ms（WebSocket） |
| 图表渲染帧率 | ≥ 30fps |
| 内存占用（单债全天tick） | < 100KB |
| 同时缓存数量 | 最近20只 |
| 数据推送频率 | 每tick（3秒） |

## 三、架构设计

### 3.1 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    monitor_bond.py 主循环（每3秒）               │
│                                                                  │
│  数据源(jsl/adata/akshare/tdx) → get_bond() → df_now           │
│       │                                                          │
│       ▼                                                          │
│  tick_buffer.append(code, time, price, volume, amount)          │
│       │                                                          │
│       ▼                                                          │
│  WebSocket广播: 推送当前被订阅的债券最新tick                     │
└──────────────────────────────┬──────────────────────────────────┘
                               │ WebSocket
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│                       前端（Browser）                            │
│                                                                  │
│  hover → 订阅该债券 → 拉取历史tick → 渲染                       │
│                         ↓                                        │
│  WebSocket onmessage → 追加新tick → Canvas实时延伸              │
│                                                                  │
│  leave → 取消订阅 → 隐藏图表                                    │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 数据流（与数据源无关）

```
任意数据源 get_bond() → df_now (统一结构)
    ↓
tick_buffer 按 bond_code 积累每次 df_now 的快照
    ↓
WebSocket 通道推送给前端订阅者
```

**关键设计**：分时图数据来自 `get_bond()` 每次返回的统一结构，不绑定任何特定数据源。无论底层是 jsl、adata、akshare 还是 tdx，只要 `get_bond()` 每3秒返回一次 `df_now`，分时图就能工作。

### 3.3 数据流时序

```
[首次hover]
  0ms    mouseenter事件
  150ms  防抖结束 → WebSocket发送 subscribe:{code}
  160ms  后端返回历史tick数组（当天已积累的所有tick）
  180ms  前端Canvas渲染完整分时图
  200ms  图表显示 ✓

[持续显示中]
  每3秒  后端推送新tick → 前端追加一个点 → 线条平滑延伸

[hover离开]
  0ms    mouseleave → WebSocket发送 unsubscribe:{code}
         图表淡出隐藏
```

## 四、后端设计

### 4.1 tick_buffer（内存缓冲）

```python
class TickBuffer:
    """
    积累每次get_bond()返回的tick数据
    每只债一天最多4800个点（4小时/3秒=4800）
    全市场480只 × 4800点 × 20字节/点 ≈ 45MB内存
    """
    
    def __init__(self):
        self._data = {}  # {bond_code: [(time, price, volume, amount), ...]}
        self._today = None
    
    def on_tick(self, df_now: pd.DataFrame, timestamp: str):
        """monitor_bond每次轮询后调用"""
        # 日期切换时清空
        today = timestamp[:10]
        if today != self._today:
            self._data.clear()
            self._today = today
        
        for _, row in df_now.iterrows():
            code = row['bond_code']
            if row['price'] <= 0:
                continue
            self._data.setdefault(code, []).append({
                't': timestamp[11:19],  # HH:MM:SS
                'p': row['price'],
                'v': row['volume'],
                'a': row['amount'],
            })
    
    def get_history(self, code: str) -> list:
        """获取某只债当天全部tick"""
        return self._data.get(code, [])
    
    def get_latest(self, code: str) -> dict:
        """获取最新一个tick"""
        ticks = self._data.get(code, [])
        return ticks[-1] if ticks else None
```

### 4.2 WebSocket服务

```python
# 使用 flask-socketio 或原生 websocket

class IntradayWS:
    def __init__(self, tick_buffer):
        self.buffer = tick_buffer
        self.subscribers = {}  # {code: set(client_ids)}
    
    def on_subscribe(self, client_id, code):
        """客户端订阅某债券"""
        self.subscribers.setdefault(code, set()).add(client_id)
        # 立即返回历史tick
        return self.buffer.get_history(code)
    
    def on_unsubscribe(self, client_id, code):
        """取消订阅"""
        if code in self.subscribers:
            self.subscribers[code].discard(client_id)
    
    def broadcast_tick(self, df_now, timestamp):
        """每次tick后广播给订阅者"""
        for code, clients in self.subscribers.items():
            if not clients:
                continue
            tick = self.buffer.get_latest(code)
            if tick:
                for client in clients:
                    send_to_client(client, {'type': 'tick', 'code': code, 'data': tick})
```

## 五、前端设计

### 5.1 组件结构

```javascript
class BondIntradayChart {
    constructor() {
        this.container = null;       // 浮动容器
        this.canvas = null;          // Canvas元素
        this.ws = null;              // WebSocket连接
        this.currentCode = null;     // 当前展示的债券
        this.tickData = [];          // 当前债的tick数组
        this.preClose = 0;           // 昨收价
        this.debounceTimer = null;
    }
    
    // 绑定hover事件
    bindAll(selector) { ... }
    
    // hover进入
    onEnter(code, element) {
        // 防抖150ms
        this.debounceTimer = setTimeout(() => {
            this.subscribe(code);
            this.show(element);
        }, 150);
    }
    
    // hover离开
    onLeave() {
        clearTimeout(this.debounceTimer);
        this.unsubscribe();
        this.hide();
    }
    
    // 订阅：发送subscribe + 接收历史数据
    subscribe(code) {
        this.ws.send(JSON.stringify({action: 'subscribe', code: code}));
    }
    
    // 收到新tick
    onTick(tick) {
        this.tickData.push(tick);
        this.renderIncremental(tick);  // 只画新增的一段
    }
    
    // Canvas渲染
    render() { ... }
    renderIncremental(newTick) { ... }  // 增量渲染
}
```

## 六、性能优化

### 6.1 前端

| 策略 | 说明 |
|------|------|
| 防抖150ms | 快速划过不触发 |
| WebSocket复用 | 单连接，多债券切换只换订阅 |
| Canvas离屏渲染 | 双缓冲避免闪烁 |
| 增量绘制 | 新tick只画最后一段，不重绘全图 |
| 历史tick本地缓存 | 再次hover同一只立即显示 |

### 6.2 后端

| 策略 | 说明 |
|------|------|
| 内存tick_buffer | 零IO，直接读内存 |
| 只推送被订阅的 | 不是每次广播全市场 |
| 数据压缩 | tick用短key(t/p/v/a)减小传输体积 |
| 按需计算 | pre_close等只在subscribe时返回一次 |

### 6.3 内存估算

| 项目 | 估算 |
|------|------|
| 单tick数据 | ~20字节 (time+price+vol+amt) |
| 单债全天 | 4800 ticks × 20B = 96KB |
| 全市场480只 | 480 × 96KB = ~45MB |
| 实际（多数债成交少） | ~20-30MB |

## 九、与数据源的关系

```
本方案与数据源完全解耦：

get_bond_jsl()  ─┐
get_bond_adata() ─┤→ df_now (统一结构) → tick_buffer → WebSocket → 分时图
get_bond_akshare()┤
get_bond_tdx()  ─┘

无论切换哪个数据源，分时图功能不受影响。
只要 get_bond() 每3秒返回包含 bond_code/price/volume/amount 的 DataFrame，
分时图就能正常工作。
```
