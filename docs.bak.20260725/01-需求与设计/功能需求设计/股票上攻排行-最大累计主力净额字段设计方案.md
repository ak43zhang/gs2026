# 股票上攻排行 - 最大累计主力净额字段设计方案

## 一、字段定义

| 属性 | 值 |
|------|-----|
| 字段名 | `max_cumulative_main_net` |
| 含义 | 当日累计主力净额的历史最大值（实时峰值） |
| 默认值 | 0 |
| 类型 | float |
| 计算 | 每tick: `max(prev_max, current_cumulative)` |

## 二、业务意义

### 2.1 核心用途
用于判断主力是否开始流出，通过比较当前累计值与历史峰值。

### 2.2 场景示例

```
时间线示例：
  09:35 累计净额 = +500万  → max = 500万
  10:20 累计净额 = +800万  → max = 800万（新高）
  11:30 累计净额 = +600万  → max = 800万（维持峰值，主力开始流出）
  14:00 累计净额 = +200万  → max = 800万（持续流出）
  
判断逻辑：
  if current_cumulative < max_cumulative * 0.8:
      提示"主力已开始流出，峰值回落超过20%"
```

### 2.3 使用场景

| 场景 | 判断条件 | 提示 |
|------|---------|------|
| 主力持续流入 | current ≈ peak | "资金持续流入，维持高位" |
| 主力开始流出 | current < peak * 0.8 | "⚠️ 主力开始流出，峰值回落" |
| 主力大幅撤离 | current < peak * 0.5 | "🔴 主力大幅撤离，谨慎操作" |

## 三、计算逻辑设计

### 3.1 初始化位置

**文件**: `src/gs2026/monitor/monitor_stock.py`  
**位置**: L560附近（与cumulative_main_net一起初始化）


### 3.2 计算位置

**文件**: `src/gs2026/monitor/monitor_stock.py`  
**位置**: L693-720（cumulative_main_net计算之后）

```python
# 1. 计算累计主力净额（已存在）
df_now['cumulative_main_net'] = df_now['cumulative_main_net_prev'] + df_now['main_net_amount']

# 2. 计算最大累计主力净额（与历史峰值比较）
if 'max_cumulative_main_net' in df_prev_main.columns:
    # 当前累计值 vs 历史峰值，取大者
    df_now['max_cumulative_main_net'] = df_prev_main['max_cumulative_main_net'].combine(
        df_now['cumulative_main_net'], 
        max
    )
else:
    # 首次，直接取当前累计值
    df_now['max_cumulative_main_net'] = df_now['cumulative_main_net']
```

### 3.3 计算顺序

```
┌─────────────────────────────────────────────────────────┐
│  每tick计算顺序（派生字段引擎）                              │
├─────────────────────────────────────────────────────────┤
│  1. main_net_amount      ← 当前tick主力净额               │
│  2. cumulative_main_net  ← 累计值（必须第2算）            │
│  3. main_net_count       ← 非零次数                       │
│  4. max_cumulative_main_net ← 峰值（依赖cumulative）      │
└─────────────────────────────────────────────────────────┘
```

## 四、关键决策

| 决策 | 说明 |
|------|------|
| **与cumulative一起计算** | 必须先算完cumulative，再算max |
| **用combine而不是max()** | 逐元素比较两个Series |
| **不取绝对值** | 关注净流入峰值（正值），流出是负值但峰值关心最高点 |
| **首次初始化** | 直接等于当前cumulative |

## 七、前端渲染方案

```javascript
case 'max_cumulative_main_net': {
    const current = item.cumulative_main_net || 0;
    const peak = item.max_cumulative_main_net || 0;
    
    if (peak === 0) return '<td>-</td>';
    
    // 计算回落百分比
    const dropPct = ((peak - current) / Math.abs(peak) * 100).toFixed(1);
    const isDropping = current < peak * 0.8; // 回落超过20%
    
    let colorClass = '';
    let indicator = '';
    
    if (isDropping) {
        colorClass = 'warning';  // 黄色警告
        indicator = '↓';
    } else if (current >= peak * 0.95) {
        colorClass = 'strong';   // 接近峰值，绿色
        indicator = '→';
    }
    
    const peakStr = formatMoney(peak);
    const currentStr = formatMoney(current);
    
    return `<td class="${colorClass}">
        <div class="peak-value">${peakStr} ${indicator}</div>
        <div class="current-value small">${currentStr} (${dropPct}%)</div>
    </td>`;
}
```

## 八、数据流

```
每tick → calculate_main_force_and_cumulative()
  Step 1: main_net_amount 计算完毕
  Step 2: cumulative_main_net = prev_cumulative + current
  Step 3: main_net_count = prev_count + (abs(current) > 1e-6 ? 1 : 0)
  Step 4: max_cumulative_main_net = max(prev_max, cumulative_main_net)
  → save to sssj表 → Redis → 前端
```
