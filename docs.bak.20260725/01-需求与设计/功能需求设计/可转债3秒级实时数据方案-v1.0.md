# 可转债实时数据3秒级更新方案设计文档 v1.0

## 一、问题分析

### 1.1 当前状况
`get_bond_tdx()` 使用 `get_security_bars(8, ...)` 获取1分钟K线：
- 每根K线代表1分钟内的 OHLC（开盘/最高/最低/收盘）
- 1分钟内只有一个收盘价，无法反映3秒级的价格波动
- 分时图显示为阶梯状，不够精细

### 1.2 目标
实现3秒级价格更新，使分时图能显示实时价格变化。

---

## 二、方案对比

| 方案 | 原理 | 优点 | 缺点 | 推荐 |
|------|------|------|------|------|
| **A: get_security_quotes 实时快照** | 每次获取全市场最新报价 | 真正的实时价格，3秒可更新 | 无历史tick序列，需自己积累 | ✅ 首选 |
| B: 本地积累 + 插值 | 分钟K线内线性插值 | 数据连续 | 假数据，不真实 | ❌ 不推荐 |
| C: 混合方案 | quotes取实时 + bars取历史 | 既有精细实时，又有完整历史 | 实现稍复杂 | ✅ 推荐（最终） |

---

## 三、推荐方案：实时快照 + 本地积累

### 3.1 核心思路

```
每3秒执行一次：
    ├─ get_security_quotes() 获取全市场最新价格（实时）
    ├─ 将每只债的最新价格写入 tick_buffer
    └─ tick_buffer 按时间顺序积累，形成分时序列

分时图查询时：
    └─ 从 tick_buffer 读取当天已积累的所有 tick
```

### 3.2 数据流

```
monitor_bond 主循环（每3秒）
    │
    ├─ get_bond_tdx() ──→ get_security_quotes() ──→ 全市场最新报价
    │                           ↓
    │                      {code: {price, volume, amount, ...}}
    │                           ↓
    └─ tick_buffer.on_tick(df_now) ──→ 按 code 积累 tick 序列
                                              ↓
                                    {code: [(09:30:03, 105.20), (09:30:06, 105.25), ...]}
                                              ↓
                                    分时图查询 ──→ 返回完整序列渲染
```

### 3.3 关键设计

#### tick_buffer 结构

```python
class TickBuffer:
    """
    内存中积累每只债的实时tick序列
    每只债一天最多 4800 个点（4小时 × 60分钟 × 20 ticks/分钟）
    """
    
    def __init__(self):
        self._ticks = {}  # {bond_code: [{'t': '09:30:03', 'p': 105.20, 'v': 1000, 'a': 105200}, ...]}
        self._today = None
    
    def on_tick(self, df_now: pd.DataFrame, timestamp: str):
        """
        每次 get_bond() 返回后调用
        df_now 包含全市场当前最新报价
        """
        today = timestamp[:10]
        if today != self._today:
            self._ticks.clear()  # 日期切换清空
            self._today = today
        
        time_str = timestamp[11:19]  # HH:MM:SS
        
        for _, row in df_now.iterrows():
            code = row['bond_code']
            price = row['price']
            
            if price <= 0:
                continue
            
            tick = {
                't': time_str,
                'p': price,
                'v': row.get('volume', 0),      # 本tick成交量（需计算增量）
                'a': row.get('amount', 0),        # 本tick成交额（需计算增量）
            }
            
            self._ticks.setdefault(code, []).append(tick)
    
    def get_intraday(self, code: str) -> list:
        """获取某只债当天全部tick序列"""
        return self._ticks.get(code, [])
    
    def get_latest(self, code: str) -> dict:
        """获取最新一个tick"""
        ticks = self._ticks.get(code, [])
        return ticks[-1] if ticks else None
```

#### 成交量/成交额计算

```python
def calculate_incremental(tick_buffer, code, current_volume, current_amount):
    """
    quotes返回的是累计成交量/成交额
    需要计算本tick的增量
    """
    ticks = tick_buffer.get_intraday(code)
    if not ticks:
        return current_volume, current_amount  # 第一个tick，直接用累计值
    
    last_tick = ticks[-1]
    last_vol = sum(t['v'] for t in ticks)  # 或维护累计值
    last_amt = sum(t['a'] for t in ticks)
    
    return (
        current_volume - last_vol,  # 本tick成交量
        current_amount - last_amt   # 本tick成交额
    )
```

### 3.4 get_bond_tdx 修改

```python
def get_bond_tdx(max_retries=3, retry_delay=2):
    """
    通过 pytdx 获取可转债实时行情
    每次返回全市场最新快照（3秒级）
    """
    from pytdx.hq import TdxHq_API
    
    # 连接服务器（复用连接池更佳）
    api = TdxHq_API()
    connected = False
    for host, port in TDX_SERVERS:
        try:
            api.connect(host, port, time_out=3)
            connected = True
            break
        except:
            continue
    
    if not connected:
        return pd.DataFrame()
    
    try:
        # 1. 获取可转债代码列表（只需一次，可缓存）
        bond_codes = _get_all_bond_codes(api)  # [(market, code, name), ...]
        
        # 2. 批量获取实时报价（每次最多80只）
        all_quotes = []
        for i in range(0, len(bond_codes), 80):
            batch = bond_codes[i:i+80]
            params = [(m, c) for m, c, n in batch]
            quotes = api.get_security_quotes(params)
            if quotes:
                all_quotes.extend(quotes)
        
        # 3. 转换为 DataFrame（统一结构）
        rows = []
        name_map = {c: n for m, c, n in bond_codes}
        
        for q in all_quotes:
            code = q.get('code', '')
            price = q.get('price', 0)
            pre_close = q.get('last_close', 0)
            
            rows.append({
                'bond_code': code,
                'bond_name': name_map.get(code, ''),
                'price': price,
                'open': q.get('open', 0),
                'high': q.get('high', 0),
                'low': q.get('low', 0),
                'pre_close': pre_close,
                'volume': q.get('vol', 0),      # 累计成交量
                'amount': q.get('amount', 0),   # 累计成交额
                'change_pct': _calc_change_pct(price, pre_close),
            })
        
        return pd.DataFrame(rows)
        
    finally:
        api.disconnect()
```

### 3.6 分时图查询

```python
@app.route('/api/bond/intraday/<code>')
def get_intraday_data(code):
    """获取某只债的分时图数据"""
    
    # 1. 从 tick_buffer 获取当天已积累的所有 tick
    ticks = tick_buffer.get_intraday(code)
    
    # 2. 获取昨收价（用于计算涨跌幅）
    pre_close = _get_pre_close(code)  # 从缓存或数据库
    
    # 3. 计算每个 tick 的涨跌幅
    for tick in ticks:
        tick['c'] = _calc_change_pct(tick['p'], pre_close)
    
    return jsonify({
        'success': True,
        'data': {
            'code': code,
            'pre_close': pre_close,
            'ticks': ticks,  # 3秒级序列
            'count': len(ticks),
        }
    })
```

## 四、内存估算

| 项目 | 计算 |
|------|------|
| 单tick数据 | time(8B) + price(8B) + vol(4B) + amt(8B) ≈ 28B |
| 单债全天 | 4800 ticks × 28B ≈ 134KB |
| 全市场480只 | 480 × 134KB ≈ 64MB |
| 实际（成交稀疏的债tick少） | ~30-40MB |

**结论**：内存占用可控，约30-40MB。

## 六、风险与应对

| 风险 | 应对 |
|------|------|
| 盘中数据源断开 | tick_buffer 保留上次数据，重连后继续积累 |
| 非交易时段无数据 | tick_buffer 为空，分时图显示"无数据" |
| 内存溢出 | 设置单债最大tick数（如5000），超限则丢弃最早的 |
| 数据不一致 | tick_buffer 以最新 tick 为准，覆盖旧值 |
