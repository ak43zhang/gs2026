# 盘中异动潜在最强标的挖掘系统设计方案

## 一、需求背景

当前系统已具备：
- 市场主线识别（基于已涨停股票）
- 市场最强标的排名（基于主线参与度）

新增需求：
- 基于已识别主线，挖掘**尚未涨停但可能即将涨停**的潜在标的
- 提供介入点建议，辅助短线交易决策

## 二、核心功能

### 2.1 功能概述

| 功能模块 | 说明 |
|---------|------|
| 自动挖掘 | 每新增1个`done`股票，自动触发潜在标的挖掘 |
| 手动挖掘 | 用户点击按钮，实时触发挖掘 |
| 双模式展示 | 实时模式显示最新，复盘模式跟随时间轴 |
| 可切换面板 | 市场最强标的 / 潜在最强标的 标签切换 |

### 2.2 展示内容

每只潜在标的包含：
- 股票代码/名称
- 排名（1-10）
- 涉及主线数量
- 涉及主线详情（名称、原因、证据）
- 综合评分（0-100）
- 建议介入点
- 风险等级
- 选股逻辑总结

## 三、数据表设计

```sql
-- 潜在标的挖掘记录表
CREATE TABLE stock_anomaly_potential (
    id INT AUTO_INCREMENT PRIMARY KEY,
    trading_date DATE NOT NULL,
    trigger_time TIME NOT NULL,        -- 触发时间（用于复盘定位）
    trigger_type VARCHAR(20),          -- 'auto' | 'manual'
    stock_code VARCHAR(10) NOT NULL,
    stock_name VARCHAR(50),
    rank_num INT,                      -- 排名 1-10
    mainline_count INT,
    mainlines JSON,                    -- [{name, reason, evidence}]
    total_score INT,
    suggested_entry VARCHAR(100),
    risk_level VARCHAR(10),
    logic TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_date_time_code (trading_date, trigger_time, stock_code)
);

-- 索引
CREATE INDEX idx_date_time ON stock_anomaly_potential(trading_date, trigger_time);
CREATE INDEX idx_rank ON stock_anomaly_potential(trading_date, trigger_time, rank_num);
```

# anomaly_correlator.py

_done_count_since_last_trigger = 0

def _mark_done(engine, anomaly_id, mainline_names, ai_analysis_merged):
    """标记完成，并触发潜在标的挖掘"""

    _done_count_since_last_trigger += 1
    
    if _done_count_since_last_trigger >= DONE_TRIGGER_THRESHOLD:

### 5.3 JavaScript逻辑

```javascript
// 切换标签
function switchStrengthTab(tab) {
    _activeStrengthTab = tab;
    
    // 更新标签样式
    document.querySelectorAll('.panel-tabs .tab').forEach(function(t) {
        t.classList.remove('active');
    });
    document.getElementById('tab-' + tab).classList.add('active');
    
    // 更新内容显示
    document.querySelectorAll('.tab-content').forEach(function(c) {
        c.classList.remove('active');
    });
    document.getElementById('strength-' + tab + '-content').classList.add('active');
    
    // 如果切换到潜在标的，自动加载
    if (tab === 'potential') {
        if (_isRealTimeMode) {
            loadPotentialLatest();
        } else {
            loadPotentialByTime(minutesToTimeStr(_currentTimeMinutes));
        }
    }
}

// 实时模式：加载最新
function loadPotentialLatest() {
    fetch('/api/anomaly/potential/latest?date=' + _currentDate)
        .then(function(r) { return r.json(); })
        .then(function(res) {
            if (res.success && res.data) {
                renderPotentialList(res.data);
            }
        });
}

// 复盘模式：加载特定时间点
function loadPotentialByTime(targetTime) {
    fetch('/api/anomaly/potential?date=' + _currentDate + '&time=' + targetTime)
        .then(function(r) { return r.json(); })
        .then(function(res) {
            if (res.success && res.data) {
                renderPotentialList(res.data);
            } else {
                // 该时间点无数据
                showEmptyState(targetTime + ' 无挖掘记录');
            }
        });
}

// 手动刷新
function refreshPotential() {
    fetch('/api/anomaly/potential?date=' + _currentDate, {method: 'POST'})
        .then(function(r) { return r.json(); })
        .then(function(res) {
            if (res.success) {
                renderPotentialList(res.data);
            }
        });
}
```

## 七、关键设计决策

| 决策点 | 方案 | 说明 |
|--------|------|------|
| 候选股票池 | AI自行选择 | 不依赖特定数据库表，Prompt中说明范围 |
| 触发机制 | 每1个done+手动 | 实时性强，后期可调阈值 |
| 复盘模式 | 跟随时间轴 | 潜在标的也随时间变化 |
| 展示数量 | 固定10只 | 排名1-10 |
| 面板设计 | 标签切换 | 市场最强/潜在最强 共用面板区域 |
