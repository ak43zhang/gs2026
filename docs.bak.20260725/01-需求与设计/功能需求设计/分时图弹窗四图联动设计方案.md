# 分时图弹窗优化：四图联动设计方案

## 展示内容

点击股票/债券后，弹窗同时展示4个分时图：

1. **大盘分时图**（上证指数/中小盘指数）
2. **行业分时图**（该股票所属行业板块）
3. **正股分时图**
4. **转债分时图**（无转债时显示"无可转债"）

- 总高度：约450px

## API 修改

### 扩展 `/api/monitor/chart-data/<bond_code>/<stock_code>` 返回值

```json
{
  "success": true,
  "data": {
    "stock": [...],         // 正股分时数据
    "bond": [...],          // 转债分时数据
    "market": [...],        // 大盘分时数据（新增）
    "industry": [...],      // 行业分时数据（新增）
    "industry_name": "半导体"  // 行业名称（新增）
  }
}
```

### 大盘数据来源

从 `monitor_gp_sssj_{date}` 表中查询指数代码（如 `000001` 上证指数或使用配置的基准指数）。

### 行业数据来源

1. 通过股票代码从 `cache_stock_industry_concept_bond` 获取行业名称
2. 从 `monitor_zs_sssj_{date}`（指数实时表）或行业指数表查询行业分时数据
