## 一、方案概述

一句话: **前端展示命中列表 → 你选择买谁 → 系统接管全部后续 → 交易结束 → 新一轮。**

## 三、状态机

```
IDLE ──→ TRADING ──→ MONITORING ──→ IDLE
              │                        ↑
              │ 30秒无弹窗              │ 止盈/止损/强平
              ↓                        │
          撤单 → IDLE                  │
                                       │
              MONITORING:              │
                价格>=止盈价 ───────────┘
                价格<=止损价 ───────────┘
                持仓>=max_hold_time ────┘(强平)
```

| 状态 | 含义 | 进入条件 | 退出条件 |
|------|------|---------|---------|
| IDLE | 等待,收集命中,展示列表 | 交易结束/初始 | 你点[买] |
| TRADING | 买入执行中 | 你点[买] | 成交/超时撤单 |
| MONITORING | 持仓中,监控价格 | 成交且TP/SL已设 | TP/SL触发/强平 |

## 四、各阶段详细设计

### 4.1 阶段①: 命中收集(IDLE状态)

```python
def on_hit(self, code, name, price, scheme, lots):
    """monitor_bond每tick调用, 非阻塞(<1ms)"""
    if self.state != "IDLE":
        return  # 交易中不收新命中
    
    self.hit_list.append({
        'code': code,
        'name': name,
        'buy_price': calc_buy_price(price, scheme),
        'tp_pct': scheme['take_profit'],
        'sl_pct': scheme['stop_loss'],
        'max_hold_minutes': scheme.get('max_hold_time', 30),
        'quantity': lots * 10,
        'hit_time': time.time(),
    })
    
    # 移除30秒前过期的
    self.hit_list = [h for h in self.hit_list if time.time() - h['hit_time'] < 30]
```

### 4.2 阶段②: 你选择买入

```python
def on_buy_click(self, code):
    """前端点[买]触发(API调用)"""
    if self.state != "IDLE":
        return {'success': False, 'message': '交易进行中'}
    
    # 从列表找到这条命中
    hit = next((h for h in self.hit_list if h['code'] == code), None)
    if not hit:
        return {'success': False, 'message': '信号已过期'}
    
    # 进入交易状态
    self.state = "TRADING"
    self.current = hit
    self.hit_list = []  # 清空列表(本轮结束)
    
    # 启动交易线程(不阻塞)
    Thread(target=self._trade_thread, daemon=True).start()
    
    return {'success': True, 'message': f'开始交易 {code}'}
```

### 4.3 阶段③路径A: 买到了 → 设TP/SL → 监控

```python
def _trade_thread(self):
    """独立线程: 填表→等弹窗→设TP/SL或撤单"""
    
    # 1. 填充买入表单
    fill_buy_form(self.current['code'], self.current['buy_price'], 
                  self.current['quantity'] // 10)
    play_sound("hit")
    
    # 2. 等待成交弹窗(30秒)
    filled = False
    start = time.time()
    while time.time() - start < 30:
        popup_code = detect_fill_popup()
        if popup_code == self.current['code']:
            filled = True
            break
        time.sleep(0.1)
    
    if filled:
        # === 路径A: 买到了 ===
        play_sound("filled")
        
        # 设止盈止损
        result = tp_sl_placer.place(
            code=self.current['code'],
            base_price=self.current['buy_price'],
            tp_pct=self.current['tp_pct'],
            sl_pct=self.current['sl_pct'],
            quantity=self.current['quantity'],
        )
        
        if result['success']:
            play_sound("tp_sl_set")
        else:
            play_sound("error")
            # TP/SL设失败,仍进入监控(靠价格监控+强平保护)
        
        # 进入持仓监控
        self.fill_time = time.time()
        self.tp_level = self.current['buy_price'] * (1 + self.current['tp_pct'] / 100)
        self.sl_level = self.current['buy_price'] * (1 - self.current['sl_pct'] / 100)
        self.max_hold_seconds = self.current['max_hold_minutes'] * 60
        self.state = "MONITORING"
    
    else:
        # === 路径B: 没买到 ===
        self._handle_not_filled()
```

### 4.4 阶段③路径B: 没买到 → 撤单

```python
def _handle_not_filled(self):
    """30秒未检测到成交弹窗 → 撤单 → 结束"""
    cancelled = try_cancel_order(self.current['code'])
    
    if cancelled:
        # 撤成功 → 确实没成交
        play_sound("timeout")
        self._end_trade("timeout_cancelled")
    else:
        # 撤不掉(可能已成交但弹窗漏了)
        # 告警,让你手动检查
        play_sound("alert")
        self._end_trade("alert_check_manually")
```

### 4.5 阶段③持仓监控(MONITORING)

```python
def on_tick(self, df_now):
    """monitor_bond每tick调用,传入当前行情"""
    if self.state != "MONITORING":
        return
    
    price = get_price(df_now, self.current['code'])
    if not price:
        return
    
    # 止盈触发
    if price >= self.tp_level:
        play_sound("tp_triggered")
        self._end_trade("take_profit", price)
        return
    
    # 止损触发
    if price <= self.sl_level:
        play_sound("sl_triggered")
        self._end_trade("stop_loss", price)
        return
    
    # 持仓超时 → 强平
    if time.time() - self.fill_time >= self.max_hold_seconds:
        self._force_sell(price)
```

### 4.6 强制卖出

```python
def _force_sell(self, price):
    """持仓超时强平: 填充卖出表单"""
    def _do_sell():
        fill_sell_form(self.current['code'], price, self.current['quantity'])
        play_sound("force_sell")
        self._end_trade("force_sell", price)
    
    Thread(target=_do_sell, daemon=True).start()
```

### 4.7 交易结束(统一出口)

```python
def _end_trade(self, reason, price=None):
    """所有路径的统一结束点"""
    # 记录日志
    log_trade(reason, self.current, price)
    
    # 记录到历史(面板展示)
    self.trade_history.append({
        'code': self.current['code'],
        'name': self.current['name'],
        'reason': reason,
        'time': datetime.now().isoformat(),
    })
    
    # 清空状态
    self.current = None
    self.hit_list = []     # 确保旧命中清空
    self.state = "IDLE"    # 回到IDLE, 开始新一轮
    
    # 提醒
    play_sound("trade_end")
```

## 七、线程模型

```
主线程 (monitor_bond.py, 每3秒tick)
    │
    ├── on_hit(): 往hit_list追加1条 (<1ms, 不阻塞)
    ├── on_tick(df): 价格比较3个数字 (<1ms, 不阻塞)
    │
    └── (采集+ETL正常运行, 完全不受影响)

交易线程 (daemon, 按需启动)
    │
    ├── 你点[买]时启动
    ├── 填表(2-3秒) → 等弹窗(最多30秒) → 设TP/SL(5-7秒)
    ├── 完成后: state=MONITORING (交给tick监控)
    └── 线程结束
    
强平线程 (daemon, 按需启动)
    │
    ├── on_tick检测到超时时启动
    ├── 填卖出表单(2-3秒)
    ├── _end_trade()
    └── 线程结束

Flask线程 (daemon, 常驻)
    │
    └── 提供面板和API (独立于主线程)
```

**并发安全:**
- 主线程: 只读/追加hit_list + 数字比较(无UI操作)
- 交易线程: 独占UI操作(state=TRADING时启动,完成前不会有第二个)
- 强平线程: 独占UI操作(state=MONITORING时才可能启动,启动后state立刻变IDLE)
- 任何时刻最多1个线程在操作UI → 零冲突

# trade_hook.py (接口层, 所有异常内部消化):
class TradeHook:
    def on_hit(self, code, name, price, scheme, lots):
        if not self.enabled: return
        try: self._trader.on_hit(code, name, price, scheme, lots)
        except: pass
    
    def on_tick(self, df_now):
        if not self.enabled: return
        try: self._trader.on_tick(df_now)
        except: pass
