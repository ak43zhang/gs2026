# 盘中异动两项优化设计方案

## 需求1：非交易日默认显示上一个交易日

### 当前逻辑
```javascript
var _currentDate = getLocalDateStr();  // 直接用今天日期
```

### 修改方案

**后端**：新增 API `/api/anomaly/latest-trading-date`

```python
@anomaly_bp.route('/latest-trading-date', methods=['GET'])
def get_latest_trading_date():
    """获取最近的交易日（如果今天不是交易日则返回上一个交易日）"""
    today = date.today().strftime('%Y-%m-%d')
    sql = text("""
        SELECT trade_date FROM data_jyrl 
        WHERE trade_date <= :today AND trade_status = '1'
        ORDER BY trade_date DESC LIMIT 1
    """)
    with engine.connect() as conn:
        result = conn.execute(sql, {'today': today})
        row = result.fetchone()
    
    trading_date = row[0] if row else today
    return jsonify({'success': True, 'date': trading_date})
```

**前端**：页面加载时先获取交易日再加载数据

```javascript
// 修改初始化流程
async function initPage() {
    // 1. 获取最近交易日
    try {
        var r = await fetch('/api/anomaly/latest-trading-date').then(r => r.json());
        if (r.success) {
            _currentDate = r.date;
        }
    } catch(e) {
        // 失败则用今天
        _currentDate = getLocalDateStr();
    }
    
    // 2. 更新日期选择器显示
    document.getElementById('date-picker').value = _currentDate;
    
    // 3. 加载数据
    loadData();
}

// 替换原来的直接调用
// loadData();  ← 删除
initPage();    // ← 改为
```

## 需求2："最相关"标记

### 逻辑

定位股票后，如果某个最强标的属于该股票的**所有**主线，标记"最相关"。

```
定位: 节能风电 → 所属主线: [绿色电力, 储能, 风电]

最强标的列表:
  - 阳光电源  主线: [绿色电力, 储能]     → 2/3 命中，不标记
  - 金风科技  主线: [绿色电力, 储能, 风电] → 3/3 命中，标记"最相关"
  - 宁德时代  主线: [储能]               → 1/3 命中，不标记
```

### 修改位置

`renderLocatedData()` 函数中过滤最强标的部分：

```javascript
// 4. 过滤最强标的 - 只显示该股票所在主线的标的
var locatedStrongest = _allStrongest.filter(function(s) {
    if (s.mainlines && s.mainlines.length > 0) {
        for (var i = 0; i < s.mainlines.length; i++) {
            if (relatedMainlineNames.includes(s.mainlines[i].name)) {
                return true;
            }
        }
    }
    return false;
});

// 【新增】标记"最相关"：属于该股票所有主线的标的
locatedStrongest.forEach(function(s) {
    if (s.mainlines && relatedMainlineNames.length > 0) {
        var matchCount = 0;
        s.mainlines.forEach(function(ml) {
            if (relatedMainlineNames.includes(ml.name)) {
                matchCount++;
            }
        });
        s._isMostRelated = (matchCount >= relatedMainlineNames.length);
    }
});

renderStrengthRanking(locatedStrongest);
```

然后在 `renderStrengthRanking` 渲染函数中，检查 `_isMostRelated` 标记：

```javascript
// 在股票名称后面添加标记
if (item._isMostRelated) {
    html += '<span style="background:#ff4d4f;color:#fff;padding:1px 4px;border-radius:3px;font-size:10px;margin-left:4px;">最相关</span>';
}
```
