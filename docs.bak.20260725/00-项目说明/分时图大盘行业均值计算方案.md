# 分时图四图联动：大盘均值和行业均值计算方案

## 现状分析

### `monitor_gp_sssj_{date}` 表已有字段
- `change_pct`：每只股票每个tick的涨跌幅
- `bk_name`：每只股票所属行业名称
- `time`：时间字段

### 当前处理流程（`deal_gp_works`）
```
获取实时行情 → normalize → enrich(添加bk_name等) → 计算主力/累计 → 保存Redis+MySQL
```

### 缺少的字段
- `market_avg`：该时间点大盘均值
- `industry_avg`：该时间点行业均值

---

## 设计方案

### 思路

在 `deal_gp_works` 流程中，保存数据**之前**计算大盘均值和行业均值，作为新字段写入每条记录。

### 计算逻辑

```python
# 在 deal_gp_works 保存数据前，计算均值
# 1. 大盘均值：当前tick所有股票的 change_pct 平均值
market_avg = df_now['change_pct'].mean()
df_now['market_avg'] = round(market_avg, 3)

# 2. 行业均值：按 bk_name 分组取平均，再 merge 回原表
industry_avg = df_now.groupby('bk_name')['change_pct'].transform('mean')
df_now['industry_avg'] = industry_avg.round(3)
```

### 优势
- **O(n) 复杂度**：`transform('mean')` 是向量化操作，极快
- **不影响原有逻辑**：只在保存前增加2列
- **前端直接读取**：不需要实时 GROUP BY 90万行

### 修改位置

在 `monitor_stock.py` 的 `deal_gp_works` 函数中，保存到 Redis/MySQL **之前**添加：

```python
# ===== 保存前：计算大盘均值和行业均值 =====
# 大盘均值（所有股票的 change_pct 平均值）
market_avg_val = df_now['change_pct'].mean()
df_now['market_avg'] = round(market_avg_val, 3) if pd.notna(market_avg_val) else 0.0

# 行业均值（同行业股票的 change_pct 平均值）
if 'bk_name' in df_now.columns:
    df_now['industry_avg'] = df_now.groupby('bk_name')['change_pct'].transform('mean').round(3)
else:
    df_now['industry_avg'] = 0.0
# ===== 计算完毕 =====
```

### 前端获取方式

API `/api/monitor/chart-data` 查询时：

```python
# 大盘均值分时 = 任选一只股票的 market_avg 按时间排列（每个时间点值相同）
market_sql = f"""
    SELECT time, market_avg as change_pct
    FROM {stock_table}
    WHERE stock_code = '{stock_code}'
    ORDER BY time ASC
"""

# 行业均值分时 = 该股票的 industry_avg 按时间排列
industry_sql = f"""
    SELECT time, industry_avg as change_pct
    FROM {stock_table}
    WHERE stock_code = '{stock_code}'
    ORDER BY time ASC
"""
```

**注意**：这里直接取该股票的 `market_avg` 和 `industry_avg`，因为每个时间点这两个值对同一行业的股票是相同的。不需要 GROUP BY！

## 性能评估

| 操作 | 耗时 |
|------|------|
| `df_now['change_pct'].mean()` | <1ms（5000条向量化） |
| `groupby().transform('mean')` | ~5ms（5000条分组计算） |
| 前端查询 `market_avg` | 同查正股数据，无额外开销 |

**总结：零性能影响，不需要额外 GROUP BY 查询。**
