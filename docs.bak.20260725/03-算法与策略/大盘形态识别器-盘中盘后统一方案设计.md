# 大盘日内走势形态识别器 - 盘中/盘后统一方案设计

## 一、当前实现分析

### 1.1 盘后模式 (`classify_shape_eod`)

**输入**：全天完整数据（09:30 - 收盘）

**判定逻辑**：
1. 计算全天结构指标（高低点位置、振幅、回升/回落幅度）
2. 基于全天振幅的**自适应阈值**判定7种形态：
   - 横盘震荡（振幅<0.5%）
   - 单边下行（高点≈开盘，收盘≈日低，低点靠后）
   - 单边上行（低点≈开盘，收盘≈日高，高点靠后）
   - V型反转（低点在中段，两侧都显著）
   - 倒V型（高点在中段，两侧都显著）
   - 低开高走（低点在前半段，之后显著回升）
   - 高开低走（真高开，高点在前半段，之后显著回落）

**特点**：
- 使用**全天振幅**作为基准计算阈值
- 高低点位置用**全天时间比例**（0-1）
- 需要完整数据才能判定

### 1.2 盘中模式 (`classify_stage_realtime`)

**输入**：开盘到指定时刻的部分数据

**判定逻辑**：
1. 截取到cutoff_time的数据
2. 计算**当前为止**的结构指标
3. 基于**当前振幅**的自适应阈值判定阶段：
   - 横盘（当前振幅<0.5%）
   - 下行中（刚创日内新低）
   - 上行中（刚创日内新高）
   - 反转向上确认（脱离最低点N分钟，回升显著）
   - 反转向下确认（脱离最高点N分钟，回落显著）
   - 下行后反弹初期（脱离最低点，回升未达确认阈值）
   - 上行后回落初期（脱离最高点，回落未达确认阈值）

**特点**：
- 使用**当前为止的振幅**作为基准
- 极值时间用**距当前分钟数**（绝对时间）
- 可以实时更新

## 二、核心差异对比

| 维度 | 盘后模式 | 盘中模式 | 差异影响 |
|------|---------|---------|---------|
| **数据范围** | 全天完整 | 开盘到当前 | 盘中无法预知未来高低点 |
| **振幅基准** | 全天振幅 R_full | 当前振幅 R_cur | 盘中阈值会随时间变化 |
| **极值位置** | 相对位置 (0-1) | 绝对分钟数 | 不同度量方式 |
| **阈值计算** | R_full × ratio | R_cur × ratio | 盘中阈值不稳定 |
| **判定目标** | 7种完整形态 | 7种实时阶段 | 语义不同 |

### 关键问题

1. **阈值漂移**：盘中当前振幅 ≠ 最终全天振幅
   - 例：10:00时振幅1%，可能最终全天振幅3%
   - 导致盘中"显著回升"阈值 0.5% vs 盘后 1.5%

2. **极值位置度量不一致**：
   - 盘后：高点在0.3（全天30%位置）
   - 盘中：高点在30分钟前（距当前）

3. **形态 vs 阶段语义差异**：
   - 盘后"V型反转" = 低点在中段 + 两侧显著
   - 盘中"反转向上确认" = 脱离低点N分钟 + 回升显著

## 三、统一方案设计

### 方案A：完全统一（推荐）

**核心思想**：盘中也使用"相对位置"思维，但基于"当前为止"

#### 3.1 统一数据结构

```python
@dataclass
class MarketStructure:
    """统一的市场结构指标（盘中/盘后通用）"""
    # 基础数据
    n_points: int              # 数据点数
    open_pct: float          # 开盘相对涨跌幅
    close_pct: float         # 收盘/当前相对涨跌幅
    high_pct: float          # 最高点
    low_pct: float           # 最低点
    
    # 时间位置（统一用相对位置 0-1）
    high_pos: float            # 高点相对位置（0=开盘，1=当前/收盘）
    low_pos: float             # 低点相对位置
    high_time: str             # 高点时间
    low_time: str              # 低点时间
    
    # 幅度指标
    total_range: float         # 当前/全天振幅
    recovery: float            # 从低点回升幅度
    drawdown: float            # 从高点回落幅度
    down_leg: float            # 开盘到最低点幅度
    up_leg: float              # 开盘到最高点幅度
    
    # 盘中特有：距极值时间（分钟）
    mins_since_high: float = None  # 距高点分钟数（仅盘中）
    mins_since_low: float = None   # 距低点分钟数（仅盘中）
    cur_time: str = None           # 当前时间（仅盘中）
```

#### 3.2 统一判定逻辑

**7种形态/阶段统一映射**：

| 盘后形态 | 盘中阶段 | 统一判定条件 |
|---------|---------|-------------|
| 横盘震荡 | 横盘 | `total_range < flat_range` |
| 单边下行 | 下行中/确认 | `high_pos < 0.3` AND `low_pos > 0.7` AND `recovery < significant` |
| 单边上行 | 上行中/确认 | `low_pos < 0.3` AND `high_pos > 0.7` AND `drawdown < significant` |
| V型反转 | 反转向上确认 | `0.25 < low_pos < 0.75` AND `down_leg > significant` AND `recovery > significant` |
| 倒V型 | 反转向下确认 | `0.25 < high_pos < 0.75` AND `up_leg > significant` AND `drawdown > significant` |
| 低开高走 | 下行后反弹初期 | `low_pos < 0.5` AND `recovery > 0` AND `recovery < significant` |
| 高开低走 | 上行后回落初期 | `high_pos < 0.5` AND `drawdown > 0` AND `drawdown < significant` |

**新增盘中特有阶段**（无法对应盘后形态）：
- "刚创日内新低"（mins_since_low < 3）
- "刚创日内新高"（mins_since_high < 3）

#### 3.3 统一阈值策略

```python
# 自适应阈值（盘中/盘后通用）
def calc_thresholds(total_range: float, config: dict) -> dict:
    return {
        'flat': config['flat_range'],                    # 固定值 0.5%
        'significant': total_range * config['significant_ratio'],  # 振幅×0.5
        'breakout': total_range * config['breakout_ratio'],        # 振幅×0.3
        'edge': total_range * config['edge_ratio'],                # 振幅×0.2
    }
```

**关键**：盘中使用`当前为止的振幅`，盘后使用`全天振幅`

#### 3.4 统一函数接口

```python
def classify_market_shape(
    df: pd.DataFrame,
    mode: str = 'eod',           # 'eod' | 'realtime'
    cutoff_time: str = None,     # realtime模式需要
    config: dict = None
) -> dict:
    """
    统一的大盘形态/阶段识别
    
    Returns:
        {
            'shape': str,           # 形态名（盘后）或阶段名（盘中）
            'category': str,        # 分类：'横盘'|'单边'|'反转'|'过渡'
            'confidence': float,    # 置信度（0-1）
            'detail': str,          # 详细说明
            'structure': MarketStructure,  # 结构指标
            'thresholds': dict,     # 使用的阈值
            # 盘中特有
            'mins_since_extreme': float,  # 距极值分钟
            'is_confirmed': bool,         # 是否已确认
        }
    """
```

## 四、延迟分析

### 4.1 数据源延迟

| 指标 | 来源 | 更新频率 | 延迟 |
|------|------|---------|------|
| `mkt_vs_open_pct` | `ext_indicators` JSON列 | 每tick（3秒） | **3秒** |

### 4.2 计算延迟

当前实现：
```python
df = load_mkt_curve(date_str)  # 查询单只债券全天数据
st = calc_structure(df)        # pandas计算（<1ms）
shape = classify_shape(st)     # 逻辑判断（<1ms）
```

**总延迟：3秒（数据源）+ <10ms（计算）≈ 3秒**

### 4.3 阈值滞后问题

**核心问题**：盘中使用"当前为止振幅"作为阈值基准，会导致：

| 时间 | 当前振幅 | 阈值(significant=0.5×) | 实际全天振幅 | 误差 |
|------|---------|----------------------|------------|------|
| 10:00 | 1.0% | 0.5% | 3.0% | -67% |
| 11:00 | 2.0% | 1.0% | 3.0% | -33% |
| 14:00 | 2.8% | 1.4% | 3.0% | -7% |

**影响**：
- 早盘容易"过度敏感"（阈值过低，容易触发"确认"）
- 尾盘趋于稳定（阈值接近最终值）

### 4.4 延迟优化建议

**方案1：使用历史平均振幅预估**（推荐）
```python
# 基于历史同期平均振幅预估全天振幅
expected_range = get_historical_avg_range(date)  # 例如最近20日同类型日平均
thresholds = calc_thresholds(expected_range, config)
```

**方案2：动态加权（当前+预估）**
```python
# 随着时间推移，逐步从预估转向实际
if trading_minutes < 60:
    # 早盘：主要用预估
    effective_range = 0.7 * expected_range + 0.3 * current_range
else:
    # 午盘：主要用实际
    effective_range = 0.3 * expected_range + 0.7 * current_range
```

**方案3：固定阈值（最简单）**
```python
# 不使用自适应，直接用固定值
CONFIG = {
    'flat_range': 0.5,          # 固定
    'significant': 1.5,         # 固定（不用振幅×0.5）
    'breakout': 0.8,            # 固定
}
```

## 八、总结

### 核心改进
1. **统一数据结构**：`MarketStructure` 支持盘中/盘后
2. **统一判定逻辑**：7种形态/阶段用同一套规则
3. **统一阈值计算**：自适应但可配置
4. **向后兼容**：旧接口继续可用

### 延迟现状
- **数据源延迟**：3秒（每tick更新）
- **计算延迟**：<10ms（可忽略）
- **阈值滞后**：早盘当前振幅≠全天振幅（可用历史预估优化）

### 建议
1. **基础方案**：实施统一结构（不解决阈值滞后）
2. **进阶方案**：增加历史预估优化阈值
