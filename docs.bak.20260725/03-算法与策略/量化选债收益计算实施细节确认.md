只修改 `_track_pending_exits()` 函数，**不添加任何打印/日志**。

核心逻辑：
1. 每tick查询全部命中记录
2. 分类处理：已结算跳过，未结算判断触发条件

4. 统计指标计算（供前端查询）

## 数据库操作详解

### 2.1 查询语句（每tick执行一次）

```sql
SELECT 
    id,
    bond_code,
    tick_time,           -- 入场时间 HHMMSS
    entry_price,
    take_profit_price,   -- 预计算：entry * (1 + tp_pct/100)
    stop_loss_price,     -- 预计算：entry * (1 - sl_pct/100)
    max_hold_time,       -- 分钟
    is_locked,
    signal_status,
    exit_price,
    final_return_pct,
    lock_reason
FROM quant_screen_hits
WHERE trade_date = :today
-- 查询全部，包括已结算和未结算
```

### 2.2 UPDATE语句（分类处理）

#### A. 持仓中记录（未触发任何条件）

**每tick都UPDATE**（实时更新浮动收益）：

```sql
UPDATE quant_screen_hits
SET 
    current_price = :current_price,
    current_return_pct = :current_return_pct,  -- (current - entry) / entry * 100
    signal_status = 'holding',
    updated_at = NOW()
WHERE id = :id
```

#### B. 新触发止盈（首次触发）

**一次性UPDATE**（确定后不再变更）：

```sql
UPDATE quant_screen_hits
SET 
    current_price = :current_price,
    current_return_pct = :current_return_pct,
    
    -- 平仓信息（确定）
    exit_price = :take_profit_price,      -- 触发价，非current_price
    exit_time = :exit_time,               -- 当前tick时间 HHMMSS
    final_return_pct = :final_return_pct, -- (tp_price - entry) / entry * 100
    
    -- 锁定信息
    signal_status = 'profited',
    is_locked = 1,
    locked_at = NOW(),
    lock_reason = 'take_profit',
    
    updated_at = NOW()
WHERE id = :id
```

#### C. 新触发止损（首次触发）

```sql
UPDATE quant_screen_hits
SET 
    current_price = :current_price,
    current_return_pct = :current_return_pct,
    
    exit_price = :stop_loss_price,        -- 触发价
    exit_time = :exit_time,
    final_return_pct = :final_return_pct,  -- (sl_price - entry) / entry * 100
    
    signal_status = 'stopped',
    is_locked = 1,
    locked_at = NOW(),
    lock_reason = 'stop_loss',
    
    updated_at = NOW()
WHERE id = :id
```

#### D. 新触发超时（首次触发）

```sql
UPDATE quant_screen_hits
SET 
    current_price = :current_price,
    current_return_pct = :current_return_pct,
    
    exit_price = :current_price,          -- 超时用实际价格
    exit_time = :deadline_time,           -- entry_time + max_hold_time
    final_return_pct = :final_return_pct, -- (current - entry) / entry * 100
    
    signal_status = 'timeout',
    is_locked = 1,
    locked_at = NOW(),
    lock_reason = 'max_time',
    
    updated_at = NOW()
WHERE id = :id
```

#### E. 已结算记录（is_locked=1）

**不UPDATE**，直接跳过。

## 统计指标SQL（供前端查询）

### 3.1 实时统计（每tick计算，不入库）

```sql
-- 持仓数（浮动未结算）
SELECT COUNT(*) as holding_count
FROM quant_screen_hits
WHERE trade_date = :today
  AND is_locked = 0

-- 盈数（止盈 + 超时盈利）
SELECT COUNT(*) as profit_count
FROM quant_screen_hits
WHERE trade_date = :today
  AND is_locked = 1
  AND (
      lock_reason = 'take_profit'
      OR (lock_reason = 'max_time' AND final_return_pct >= 0)
  )

-- 损数（止损 + 超时亏损）
SELECT COUNT(*) as loss_count
FROM quant_screen_hits
WHERE trade_date = :today
  AND is_locked = 1
  AND (
      lock_reason = 'stop_loss'
      OR (lock_reason = 'max_time' AND final_return_pct < 0)
  )
```

### 3.2 单条记录时长计算（前端展示用）

```sql
-- 已结算记录时长（秒）
CASE 
    WHEN lock_reason IN ('take_profit', 'stop_loss') THEN
        -- 触发时刻 - 入场时刻
        TIME_TO_SEC(exit_time) - TIME_TO_SEC(tick_time)
    WHEN lock_reason = 'max_time' THEN
        -- 固定时长
        max_hold_time * 60
    ELSE 0
END as hold_seconds

-- 持仓中记录时长（秒，实时变化）
CASE 
    WHEN is_locked = 0 THEN
        TIME_TO_SEC(CURRENT_TIME) - TIME_TO_SEC(tick_time)
    ELSE 0
END as floating_hold_seconds
```

## 核心计算逻辑代码（Python）

```python
def _track_pending_exits(df_now, date_str, time_full, engine):
    """
    每tick跟踪所有命中记录的收益状态
    无打印，只UPDATE数据库
    """
    import time
    from sqlalchemy import text
    
    # 1. 查询全部命中记录
    with engine.connect() as conn:
        result = conn.execute(text("""
            SELECT id, bond_code, tick_time, entry_price,
                   take_profit_price, stop_loss_price, max_hold_time,
                   is_locked, signal_status
            FROM quant_screen_hits
            WHERE trade_date = :date
        """), {'date': date_str})
        all_hits = result.fetchall()
    
    if not all_hits:
        return
    
    # 2. 构建当前价格字典
    price_map = {row['bond_code']: float(row['price']) 
                 for _, row in df_now.iterrows()}
    
    # 3. 时间转换
    current_seconds = _time_to_seconds(time_full)
    
    # 4. 分类处理
    updates_holding = []      # 持仓中：更新浮动收益
    updates_profited = []     # 新触发止盈
    updates_stopped = []      # 新触发止损  
    updates_timeout = []      # 新触发超时
    
    for row in all_hits:
        # 【已结算】跳过
        if row.is_locked:
            continue
        
        bond_code = row.bond_code
        entry_price = float(row.entry_price)
        current_price = price_map.get(bond_code)
        
        if not current_price or current_price <= 0:
            continue
        
        # 计算浮动收益
        current_return = (current_price - entry_price) / entry_price * 100
        
        tp_price = float(row.take_profit_price) if row.take_profit_price else None
        sl_price = float(row.stop_loss_price) if row.stop_loss_price else None
        max_hold = int(row.max_hold_time) if row.max_hold_time else 30
        
        entry_seconds = _time_to_seconds(row.tick_time)
        deadline_seconds = entry_seconds + max_hold * 60
        
        # 【判断触发条件】（按优先级）
        
        # ① 止盈触发
        if tp_price and current_price >= tp_price:
            final_return = (tp_price - entry_price) / entry_price * 100
            updates_profited.append({
                'id': row.id,
                'current_price': current_price,
                'current_return': current_return,
                'exit_price': tp_price,           # 触发价
                'exit_time': time_full.replace(':', ''),
                'final_return': final_return,
                'hold_seconds': current_seconds - entry_seconds
            })
        
        # ② 止损触发
        elif sl_price and current_price <= sl_price:
            final_return = (sl_price - entry_price) / entry_price * 100
            updates_stopped.append({
                'id': row.id,
                'current_price': current_price,
                'current_return': current_return,
                'exit_price': sl_price,           # 触发价
                'exit_time': time_full.replace(':', ''),
                'final_return': final_return,
                'hold_seconds': current_seconds - entry_seconds
            })
        
        # ③ 超时触发
        elif current_seconds >= deadline_seconds:
            final_return = (current_price - entry_price) / entry_price * 100
            updates_timeout.append({
                'id': row.id,
                'current_price': current_price,
                'current_return': current_return,
                'exit_price': current_price,       # 超时用实际价
                'exit_time': time_full.replace(':', ''),  # 或 deadline_time
                'final_return': final_return,
                'hold_seconds': max_hold * 60     # 固定时长
            })
        
        # ④ 未触发：持仓中
        else:
            updates_holding.append({
                'id': row.id,
                'current_price': current_price,
                'current_return': current_return
            })
    
    # 5. 批量UPDATE（无打印）
    with engine.connect() as conn:
        # A. 持仓中（浮动收益）
        for u in updates_holding:
            conn.execute(text("""
                UPDATE quant_screen_hits
                SET current_price = :cp,
                    current_return_pct = :cr,
                    signal_status = 'holding',
                    updated_at = NOW()
                WHERE id = :id
            """), {'id': u['id'], 'cp': u['current_price'], 'cr': u['current_return']})
        
        # B. 止盈
        for u in updates_profited:
            conn.execute(text("""
                UPDATE quant_screen_hits
                SET current_price = :cp,
                    current_return_pct = :cr,
                    exit_price = :ep,
                    exit_time = :et,
                    final_return_pct = :fr,
                    signal_status = 'profited',
                    is_locked = 1,
                    locked_at = NOW(),
                    lock_reason = 'take_profit',
                    updated_at = NOW()
                WHERE id = :id
            """), {**u, 'ep': u['exit_price'], 'et': u['exit_time'], 
                   'fr': u['final_return'], 'cp': u['current_price'], 'cr': u['current_return']})
        
        # C. 止损（类似）...
        # D. 超时（类似）...
        
        conn.commit()
```
