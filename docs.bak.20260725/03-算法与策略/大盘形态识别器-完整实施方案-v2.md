# 大盘形态识别器 - 完整实施方案设计（v2，基于JSON字段快速回填方案）

## 一、当前字段状态

### monitor_bond.py 已有的大盘指标
| 字段 | 说明 | 来源 |
|------|------|------|
| `mkt_vs_open_pct` | 大盘相对开盘涨跌幅 | 所有债券change_pct均值 |
| `mkt_vwap_bias` | VWAP偏离 | 累计VWAP计算 |
| `mkt_weighted_slope_10m` | 10分钟加权斜率 | EWLR计算 |
| `mkt_day_position` | 日内位置(0-100) | (当前-最低)/(最高-最低) |
| `mkt_new_low_distance` | 距新低距离(分钟) | 时间差计算 |

### 缺失字段
- **大盘形态字段**：`mkt_shape`（单边上行/单边下行/低开高走/高开低走/横盘）
- **形态详情字段**：`mkt_shape_detail`

## 二、新增字段设计

### 2.1 新增字段清单

| 字段名 | 类型 | 说明 | 存储位置 |
|--------|------|------|---------|
| `mkt_shape` | VARCHAR(20) | 大盘形态 | `ext_indicators` JSON |
| `mkt_shape_detail` | VARCHAR(100) | 形态详细说明 | `ext_indicators` JSON |

### 2.2 5种形态定义

| 形态 | 判定条件 | 形状 | 交易含义 |
|------|---------|------|---------|
| **单边上行** | `low_pos < 0.2` AND `cur > 0` AND `drawdown < sig` | ↗ | 强势做多 |
| **单边下行** | `high_pos < 0.2` AND `cur < 0` AND `recovery < sig` | ↘ | 空仓观望 |
| **低开高走** | `low_pos > 0.2` AND `recovery > sig` AND `cur > 0` | ✓ | 洗盘完成，做多 |
| **高开低走** | `high_pos > 0.2` AND `drawdown > sig` AND `cur < 0` | ✗ | 诱多出货，观望 |
| **横盘** | `total_range < 0.5%` OR (其他条件都不满足) | — | 震荡观望 |

**阈值计算**：
```python
sig = total_range * 0.5  # 显著 = 振幅 × 0.5
```

**判定优先级**（高→低）：
1. 横盘（振幅<0.5%）
2. 单边上行/下行（极值在开头）
3. 低开高走/高开低走（极值在中后段）

## 三、实施方案（基于JSON字段快速回填方案v3）

### 3.1 核心设计原则

**遵循JSON字段快速回填方案v3的设计原则**：
1. **计算逻辑统一**：所有计算函数定义在 `monitor_bond.py`，实时和回填共用
2. **字段级独立更新**：使用 `JSON_SET()` 只修改指定key，不影响其他字段
3. **默认覆盖**：无条件覆盖指定key的value
4. **复用现有架构**：回填通过 `compute_engine.py` 调用相同的函数

| 文件 | 修改内容 | 必需 |

```python
def compute_mkt_shape(dependencies: dict, history: list) -> str:
    """
    计算大盘形态（实时+回填共用）
    
    5种形态：
        - 单边上行: 开盘即最低，当前>0，回落不显著
        - 单边下行: 开盘即最高，当前<0，回升不显著
        - 低开高走: 低点不在开头，回升显著，当前>0
        - 高开低走: 高点不在开头，回落显著，当前<0
        - 横盘: 振幅<0.5%或其他条件不满足
    
    Args:
        dependencies: {'mkt_vs_open_pct': float}
        history: [{'mkt_vs_open_pct': float, 'time_sec': int}, ...]
    
    Returns:
        形态名: '单边上行'/'单边下行'/'低开高走'/'高开低走'/'横盘'
    """
    if len(history) < 10:
        return '横盘'
    
    # 合并历史和当前
    vs_values = [h.get('mkt_vs_open_pct', 0) for h in history]
    cur_pct = dependencies.get('mkt_vs_open_pct', 0)
    vs_values.append(cur_pct)
    
    high_pct = max(vs_values)
    low_pct = min(vs_values)
    total_range = high_pct - low_pct
    
    # 横盘判定
    if total_range < 0.5:
        return '横盘'
    
    # 位置计算
    n = len(vs_values)
    high_idx = vs_values.index(high_pct)
    low_idx = vs_values.index(low_pct)
    high_pos = high_idx / (n - 1) if n > 1 else 0
    low_pos = low_idx / (n - 1) if n > 1 else 0
    
    # 阈值
    sig = total_range * 0.5 if total_range > 0 else 0.001
    recovery = cur_pct - low_pct
    drawdown = high_pct - cur_pct
    
    # 形态判定
    if low_pos < 0.2 and cur_pct > 0 and drawdown < sig:
        return '单边上行'
    if high_pos < 0.2 and cur_pct < 0 and recovery < sig:
        return '单边下行'
    if low_pos > 0.2 and recovery > sig and cur_pct > 0:
        return '低开高走'
    if high_pos > 0.2 and drawdown > sig and cur_pct < 0:
        return '高开低走'
    
    return '横盘'


def compute_mkt_shape_detail(dependencies: dict, history: list) -> str:
    """
    计算大盘形态详情（实时+回填共用）
    
    Args:
        dependencies: {'mkt_vs_open_pct': float}
        history: [{'mkt_vs_open_pct': float, 'time_sec': int}, ...]
    
    Returns:
        形态详细说明
    """
    if len(history) < 10:
        return '数据不足'
    
    vs_values = [h.get('mkt_vs_open_pct', 0) for h in history]
    cur_pct = dependencies.get('mkt_vs_open_pct', 0)
    vs_values.append(cur_pct)
    
    high_pct = max(vs_values)
    low_pct = min(vs_values)
    total_range = high_pct - low_pct
    
    n = len(vs_values)
    high_idx = vs_values.index(high_pct)
    low_idx = vs_values.index(low_pct)
    high_pos = high_idx / (n - 1) if n > 1 else 0
    low_pos = low_idx / (n - 1) if n > 1 else 0
    
    sig = total_range * 0.5 if total_range > 0 else 0.001
    recovery = cur_pct - low_pct
    drawdown = high_pct - cur_pct
    
    if total_range < 0.5:
        return f'振幅{total_range:.2f}%<0.5%'
    if low_pos < 0.2 and cur_pct > 0 and drawdown < sig:
        return f'开盘即最低，当前{cur_pct:+.2f}%'
    if high_pos < 0.2 and cur_pct < 0 and recovery < sig:
        return f'开盘即最高，当前{cur_pct:+.2f}%'
    if low_pos > 0.2 and recovery > sig and cur_pct > 0:
        return f'低点在{low_pos:.0%}，回升{recovery:.2f}%'
    if high_pos > 0.2 and drawdown > sig and cur_pct < 0:
        return f'高点在{high_pos:.0%}，回落{drawdown:.2f}%'
    
    return f'高{high_pct:+.2f}% 低{low_pct:+.2f}% 收{cur_pct:+.2f}%'
```

def _update_mkt_state(self, deps: dict):
    """
    更新大盘状态（供回填使用）
    
    用于 backfill_json_fields.py 在skip-existing模式下
    更新计算引擎的状态，但不计算新字段

            self.mkt_trend_day_high = deps['mkt_vs_open_pct']
        if deps['mkt_vs_open_pct'] < self.mkt_trend_day_low:
            self.mkt_trend_day_low = deps['mkt_vs_open_pct']
