## 一、后端实时计算逻辑

### 1.1 函数位置
`src/gs2026/monitor/monitor_bond.py::_track_pending_exits()`

### 1.2 执行时机
每个tick（约3秒）执行一次

### 1.3 计算流程

```
┌─────────────────────────────────────────────────────────────┐
│  1. 查询未结算记录 (is_locked=0)                              │
│     SELECT id, bond_code, entry_price, take_profit_price,     │
│            stop_loss_price, max_hold_time, tick_time          │
│     FROM quant_screen_hits WHERE trade_date=:date AND is_locked=0│
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  2. 获取当前tick价格                                         │
│     price_map = {bond_code: current_price, ...}              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  3. 遍历每个记录，判断触发条件                                │
│                                                              │
│     ┌──────────────────────────────────────────────────┐   │
│     │ ① 止盈触发？                                       │   │
│     │    current_price >= take_profit_price             │   │
│     │    ├─ exit_price = take_profit_price              │   │
│     │    ├─ final_return_pct = (tp - entry) / entry * 100│  │
│     │    ├─ hold_seconds = current_time - entry_time    │   │
│     │    └─ lock_reason = 'take_profit'               │   │
│     └──────────────────────────────────────────────────┘   │
│                         │ 否                                 │
│                         ▼                                    │
│     ┌──────────────────────────────────────────────────┐   │
│     │ ② 止损触发？                                       │   │
│     │    current_price <= stop_loss_price             │   │
│     │    ├─ exit_price = stop_loss_price              │   │
│     │    ├─ final_return_pct = (sl - entry) / entry * 100│  │
│     │    ├─ hold_seconds = current_time - entry_time    │   │
│     │    └─ lock_reason = 'stop_loss'                 │   │
│     └──────────────────────────────────────────────────┘   │
│                         │ 否                                 │
│                         ▼                                    │
│     ┌──────────────────────────────────────────────────┐   │
│     │ ③ 超时触发？                                       │   │
│     │    current_time >= entry_time + max_hold_time   │   │
│     │    ├─ exit_price = current_price                │   │
│     │    ├─ final_return_pct = (current - entry) / entry * 100│
│     │    ├─ hold_seconds = max_hold_time * 60         │   │
│     │    └─ lock_reason = 'max_time'                   │   │
│     └──────────────────────────────────────────────────┘   │
│                         │ 否                                 │
│                         ▼                                    │
│     ┌──────────────────────────────────────────────────┐   │
│     │ ④ 未触发：持仓中（不UPDATE，前端自己算）           │   │
│     └──────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  4. 批量UPDATE新触发的记录                                   │
│     UPDATE quant_screen_hits SET                             │
│         exit_price=:exit_price,                              │
│         exit_time=:exit_time,                                │
│         final_return_pct=:final_return_pct,                  │
│         hold_seconds=:hold_seconds,                            │
│         signal_status=:signal_status,                        │
│         is_locked=1,                                         │
│         locked_at=NOW(),                                     │
│         lock_reason=:lock_reason                             │
│     WHERE id=:id                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.4 关键计算确认

| 计算项 | 公式 | 状态 |
|--------|------|------|
| 止盈收益 | `(take_profit_price - entry_price) / entry_price * 100` | ✅ 正确 |
| 止损收益 | `(stop_loss_price - entry_price) / entry_price * 100` | ✅ 正确 |
| 超时收益 | `(current_price - entry_price) / entry_price * 100` | ✅ 正确 |
| 止盈时长 | `current_seconds - entry_seconds` | ✅ 正确 |
| 止损时长 | `current_seconds - entry_seconds` | ✅ 正确 |
| 超时时长 | `max_hold_time * 60` | ✅ 正确 |

### 1.5 触发优先级确认

```
优先级（从高到低）：
1. 止盈 (take_profit)
2. 止损 (stop_loss)
3. 超时 (max_time)

实现方式：if-elif-else，一旦触发一个，后续不再检查
```

### 1.6 出场价确认

|---------|---------------|------|
| 止盈 | `take_profit_price`（预设阈值） | ✅ 正确 |
| 止损 | `stop_loss_price`（预设阈值） | ✅ 正确 |

## 二、前端实时计算逻辑

### 2.1 函数位置
`docs/03-算法与策略/前端收益计算逻辑参考.js`

### 2.2 计算流程

```javascript
// 1. 获取静态数据（命中记录）
const hits = await fetch('/quant-screen/hits?date=today').then(r => r.json());

// 2. 获取实时价格
const prices = { bond_code: current_price, ... };

// 3. 实时计算
for each hit in hits:
    if hit.is_locked:
        // 已结算：直接显示最终收益
        display_return = hit.final_return_pct
        display_status = getStatusText(hit.lock_reason)
    else:
        // 持仓中：实时计算
        currentPrice = prices[hit.bond_code]
        display_return = (currentPrice - hit.entry_price) / hit.entry_price * 100
        
        // 触发预判（展示用）
        if currentPrice >= hit.take_profit_price:
            display_status = '止盈(待确认)'
        else if currentPrice <= hit.stop_loss_price:
            display_status = '止损(待确认)'
        else if 超时:
            display_status = '超时(待确认)'
        else:
            display_status = '持仓中'
```

### 2.3 统计逻辑确认
