# 大盘形态识别器 - 完全统一方案设计（用户思路版）

## 一、用户思路分析

### 1.1 核心诉求

**完全统一命名**：
- 盘中也用 "横盘"、"单边下行"、"V型反转"、"低开高走" 等盘后形态名称
- 不用 "下行中"、"反转向上确认" 等阶段性描述

**时间区间内自洽**：
- 10:00-10:10 下行再向上 → 这就是 "V型反转" 或 "低开高走"
- 基于**已发生的数据**判断，不预测未来，也不等"确认"

**早盘敏感不是问题**：
- 10:00的判断基于09:30-10:00的数据
- 如果这30分钟内完成了"下行+向上"，那就是V型
- 不需要考虑10:00之后会发生什么

### 1.2 思路正确性分析

| 用户思路 | 分析 | 结论 |
|---------|------|------|
| 统一命名 | 简化理解，盘中盘后同一套语言 | ✅ 正确 |
| 时间区间内自洽 | 基于已发生数据判断，不预测 | ✅ 正确 |
| 早盘敏感不是问题 | 每个时刻基于当前数据判断 | ✅ 正确 |

**关键洞察**：
- 盘中的"V型反转"是基于**当前为止**的数据说的
- 10:00说是V型，不代表14:00还是V型（可能变成横盘或单边）
- 每个tick重新计算，形态可以动态变化

## 二、新设计方案

### 2.1 核心改变

**删除"阶段"概念**：
- ❌ 删除：下行中、反转向上确认、下行后反弹初期...
- ✅ 统一用：横盘、单边上行、单边下行、V型反转、倒V型、低开高走、高开低走

**判定逻辑统一**：
- 盘后：基于全天数据判定7种形态
- 盘中：基于**当前为止**数据判定7种形态（同一套规则）

**动态更新**：
- 09:30 → 横盘（数据不足）
- 10:00 → V型反转（已发生下行+向上）
- 11:00 → 单边上行（继续上行，V型被打破）
- 每个tick重新计算，形态动态变化

### 2.2 统一判定规则（7种形态）

基于**当前为止**的数据结构：
```python
struct = {
    'open_pct': 0,           # 开盘相对涨跌幅（始终为0）
    'cur_pct': float,        # 当前相对涨跌幅
    'high_pct': float,       # 当前为止最高点
    'low_pct': float,        # 当前为止最低点
    'high_pos': float,       # 高点相对位置（0-1，当前为止）
    'low_pos': float,        # 低点相对位置（0-1，当前为止）
    'total_range': float,    # 当前为止振幅（high-low）
    'recovery': float,       # 从低点回升幅度（cur - low）
    'drawdown': float,       # 从高点回落幅度（high - cur）
}
```

**7种形态判定（统一规则）**：

| 形态 | 判定条件 | 说明 |
|------|---------|------|
| **横盘震荡** | `total_range < 0.5%` | 波动过小 |
| **单边下行** | `high_pct < breakout_thr` AND `cur_pct ≈ low_pct` AND `low_pos > 0.5` | 高点≈开盘，当前≈最低点，低点在后半段 |
| **单边上行** | `abs(low_pct) < breakout_thr` AND `cur_pct ≈ high_pct` AND `high_pos > 0.5` | 低点≈开盘，当前≈最高点，高点在后半段 |
| **V型反转** | `0.25 < low_pos < 0.75` AND `down_leg > sig_thr` AND `recovery > sig_thr` | 低点在中段，下行和回升都显著 |
| **倒V型** | `0.25 < high_pos < 0.75` AND `up_leg > sig_thr` AND `drawdown > sig_thr` | 高点在中段，上行和回落都显著 |
| **低开高走** | `low_pos < 0.5` AND `recovery > sig_thr` | 低点在前半段，之后显著回升 |
| **高开低走** | `high_pct > breakout_thr` AND `high_pos < 0.5` AND `drawdown > sig_thr` | 真高开，高点在前半段，之后显著回落 |

**阈值计算（自适应）**：
```python
sig_thr = total_range * 0.5      # 显著 = 当前振幅 × 0.5
breakout_thr = total_range * 0.3  # 突破 = 当前振幅 × 0.3
```

### 2.3 与旧方案的关键区别

| 维度 | 旧方案（阶段式） | 新方案（完全统一） |
|------|----------------|------------------|
| **盘中命名** | 下行中、反转向上确认... | 单边下行、V型反转、低开高走... |
| **判定时机** | 等N分钟确认 | 即时判定（基于当前数据） |
| **形态变化** | 阶段单向推进 | 形态动态变化（V型→单边→横盘） |
| **理解难度** | 需要理解"阶段"概念 | 直接对应K线形态 |

**修改 `calc_structure`**：
```python
def calc_structure(df: pd.DataFrame, mode: str = 'eod') -> dict:
    """
    计算结构指标（支持盘中/盘后）
    
    Args:
        df: 净值曲线数据
        mode: 'eod' 或 'realtime'
    """
    vs = df['vs_open'].values
    n = len(vs)
    
    # 基础指标（与之前相同）
    high_idx = int(np.argmax(vs))
    low_idx = int(np.argmin(vs))
    
    return {
        'n': n,
        'open_pct': float(vs[0]),
        'cur_pct': float(vs[-1]),        # 盘后=close，盘中=当前
        'high_pct': float(vs.max()),
        'low_pct': float(vs.min()),
        'high_idx': high_idx,
        'low_idx': low_idx,
        'high_pos': high_idx / (n - 1) if n > 1 else 0,  # 当前为止的相对位置
        'low_pos': low_idx / (n - 1) if n > 1 else 0,
        'high_time': df['time'].iloc[high_idx],
        'low_time': df['time'].iloc[low_idx],
        'total_range': float(vs.max() - vs.min()),
        'recovery': float(vs[-1] - vs.min()),    # 从低点回升
        'drawdown': float(vs.max() - vs[-1]),    # 从高点回落
        'down_leg': float(vs[0] - vs.min()),     # 开盘到最低
        'up_leg': float(vs.max() - vs[0]),       # 开盘到最高
    }
```

**修改 `main` 函数**：
```python
def main():
    parser = argparse.ArgumentParser(description='大盘日内走势形态识别器（盘中/盘后统一）')
    parser.add_argument('date', nargs='?', help='日期 YYYYMMDD')
    parser.add_argument('--mode', choices=['eod', 'realtime'], 
                       default='eod', help='eod=盘后(全天) | realtime=盘中(截至指定时间)')
    parser.add_argument('--time', help='realtime模式的截止时间 HH:MM')
    args = parser.parse_args()

    date_str = args.date or CONFIG['date']
    mode = args.mode
    cutoff_time = args.time

    df = load_mkt_curve(date_str)
    if df.empty:
        print(f"日期 {date_str} 无数据")
        return

    # 盘中模式：截取到指定时间
    if mode == 'realtime' and cutoff_time:
        cutoff_min = _time_to_minutes(cutoff_time + ':00')
        df = df[df['time'].apply(_time_to_minutes) <= cutoff_min]
        if df.empty:
            print(f"{cutoff_time}前无数据")
            return

    st = calc_structure(df, mode)
    shape, reason = classify_shape(st, mode)

    # 输出
    if mode == 'eod':
        print(f"日期 {date_str} 走势形态分析（盘后）")
        print("=" * 60)
        print(f"净值: 开盘0% → 最高{st['high_pct']:+.2f}%({st['high_time']}) "
              f"→ 最低{st['low_pct']:+.2f}%({st['low_time']}) → 收盘{st['cur_pct']:+.2f}%")
    else:
        print(f"日期 {date_str} 截至 {cutoff_time} 走势形态分析（盘中）")
        print("=" * 60)
        print(f"净值: 开盘0% → 最高{st['high_pct']:+.2f}%({st['high_time']}) "
              f"→ 最低{st['low_pct']:+.2f}%({st['low_time']}) → 当前{st['cur_pct']:+.2f}%")
    
    print(f"当前振幅: {st['total_range']:.2f}% | "
          f"高点位置{st['high_pos']:.0%} 低点位置{st['low_pos']:.0%}")
    print(f"从低点回升{st['recovery']:.2f}% | 从高点回落{st['drawdown']:.2f}%")
    print()
    print(f"【形态判定】{shape}")
    print(f"  理由: {reason}")
    
    if mode == 'realtime':
        print()
        print("⚠️ 盘中判断基于当前为止的数据，形态可能随时间变化")
```

## 六、总结

### 核心改变
1. **删除"阶段"概念**：不再有"下行中"、"反转向上确认"等
2. **统一7种形态**：盘中盘后都用横盘/单边/V型/倒V/低开高走/高开低走
3. **即时判定**：基于当前为止数据，不等待确认
4. **动态变化**：形态随时间变化（V型→单边→横盘）

### 用户思路正确性
✅ **完全正确**：
- 统一命名简化理解
- 时间区间内自洽（基于已发生数据）
- 早盘敏感不是问题（每个时刻独立判断）
