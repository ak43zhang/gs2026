# 盘中异动股票定位功能设计方案

## 功能需求

输入股票代码，全页面展示与该股票相关的内容：
1. **市场主线** → 该股票所在的主线
2. **最强标的** → 该股票相关的最强标的
3. **主线可转债** → 该股票相关的可转债（如有）
4. **异动列表** → 该股票的异动记录

## 页面布局

```
┌─────────────────────────────────────────┐
│  搜索框: [________] [定位] [清除]        │
├─────────────────────────────────────────┤
│  市场主线: [股票所属主线] 或 [空白]        │
├─────────────────────────────────────────┤
│  最强标的: [相关标的列表] 或 [空白]        │
├─────────────────────────────────────────┤
│  主线可转债: [相关可转债] 或 [空白]        │
├─────────────────────────────────────────┤
│  异动列表: [该股票的异动记录]             │
└─────────────────────────────────────────┘
```

## 数据关联逻辑

```
输入股票代码
    │
    ├─→ 查询股票所属行业/概念 → 市场主线
    │
    ├─→ 查询同行业/同概念最强标的 → 最强标的
    │
    ├─→ 查询股票对应的可转债 → 主线可转债
    │   (通过 stock_bond_mapping)
    │
    └─→ 查询该股票的异动记录 → 异动列表
        (从 anomaly 相关表查询)
```

### 2. 前端实现

```javascript
// 定位功能
async function locateStock(code) {
    if (!code || code.length !== 6) {
        alert('请输入6位股票代码');
        return;
    }
    
    const r = await fetch(`/api/anomaly/locate-stock?code=${code}`).then(r => r.json());
    if (!r.success) {
        alert('未找到该股票');
        return;
    }
    
    // 更新各区域
    renderMainline(r.data.mainline);
    renderStrongest(r.data.strongest);
    renderBond(r.data.bond);
    renderAnomalies(r.data.anomalies);
    
    // 标记定位状态
    document.body.classList.add('locate-mode');
}

// 清除定位
function clearLocate() {
    document.getElementById('locate-input').value = '';
    document.body.classList.remove('locate-mode');
    // 恢复默认显示
    loadDefaultData();
}
```

## 后端实现

```python
def get_stock_locate_data(stock_code: str, date: str = None) -> dict:
    """获取股票定位数据"""
    if date is None:
        date = datetime.now().strftime('%Y%m%d')
    
    # 1. 查询股票基本信息
    stock_info = get_stock_info(stock_code)
    if not stock_info:
        return None
    
    # 2. 查询所属主线（行业/概念）
    mainline = get_mainline_by_stock(stock_code, date)
    
    # 3. 查询最强标的（同行业/同概念）
    strongest = get_strongest_in_mainline(mainline, date, exclude=stock_code)
    
    # 4. 查询可转债
    bond = get_bond_by_stock(stock_code)
    
    # 5. 查询异动记录
    anomalies = get_stock_anomalies(stock_code, date)
    
    return {
        'stock': stock_info,
        'mainline': mainline,
        'strongest': strongest,
        'bond': bond,
        'anomalies': anomalies
    }

def get_mainline_by_stock(stock_code: str, date: str) -> dict:
    """根据股票查询所属主线"""
    # 从行业表查询
    sql = """
        SELECT industry as name, GROUP_CONCAT(stock_code) as stocks
        FROM analysis_industry_{date}
        WHERE stock_code = %s
        GROUP BY industry
    """.format(date=date)
    
    # 或从概念表查询
    # ...
    
    return {'name': '行业名称', 'stocks': ['code1', 'code2']}

def get_bond_by_stock(stock_code: str) -> dict:
    """根据股票查询可转债"""
    # 从映射表查询
    mapping = get_stock_bond_mapping(stock_code)
    if mapping and mapping.get('bond_code'):
        return {
            'code': mapping['bond_code'],
            'name': mapping['bond_name'],
            'price': get_bond_price(mapping['bond_code'])
        }
    return None

def get_stock_anomalies(stock_code: str, date: str) -> list:
    """查询股票异动记录"""
    # 从异动表查询
    table = f"anomaly_events_{date}"
    sql = f"""
        SELECT time, type, description
        FROM {table}
        WHERE stock_code = %s
        ORDER BY time DESC
        LIMIT 50
    """
    # ...
    return [{'time': '10:30:00', 'type': '拉升', 'desc': '快速上涨5%'}]
```
