# 龙头股体量维度细分方案（基于游资实战体系）

## 方案概述

**设计目标**：基于体量维度将龙头细分为三类，便于盘中快速识别和策略匹配

**适用场景**：`stock_anomaly` 盘中异动实时分析

**核心维度**：流通市值（最直观、最可量化）

---

## 一、三类龙头定义

### 1. 权重龙头（指数大盘型）

**定义**：
- 流通市值 > 500亿
- 对指数有显著影响（沪深300/中证500成分股）
- 机构资金主导，趋势性强

**特征**：
| 维度 | 特征 |
|------|------|
| 涨停时间 | 通常较晚（10:00后），需要大量资金封板 |
| 封单特点 | 封单金额巨大（>10亿），但封单比可能不高 |
| 连板能力 | 较弱，通常1-2板，以趋势为主 |
| 带动效应 | 带动指数和板块情绪，但非短线标杆 |
| 参与资金 | 机构、大游资、量化资金 |
| 操作策略 | 趋势跟随，不追高，回调低吸 |

**案例**：
- 宁德时代（新能源权重龙头）
- 贵州茅台（消费权重龙头）
- 比亚迪（汽车权重龙头）
- 中芯国际（半导体权重龙头）

**识别标准**：
```python
if 流通市值 > 500亿:
    类型 = "权重龙头"
    策略 = "趋势跟随，不追高"
```

---

### 2. 板块中军（容量中坚型）

**定义**：
- 流通市值 200-500亿
- 板块内市值最大或前列
- 机构与游资共同参与

**特征**：
| 维度 | 特征 |
|------|------|
| 涨停时间 | 中等（09:30-10:00），需要一定资金但可封住 |
| 封单特点 | 封单金额适中（1-5亿），封单比中等 |
| 连板能力 | 中等，通常2-3板，可趋势可短线 |
| 带动效应 | 板块核心标杆，后排跟风明显 |
| 参与资金 | 机构+游资合力 |
| 操作策略 | 可打板可低吸，板块核心 |

**案例**：
- 科大讯飞（AI中军，300亿+）
- 隆基绿能（光伏中军，曾300亿+）
- 海康威视（AI视觉中军）
- 北方华创（半导体设备中军）

**识别标准**：
```python
if 200亿 <= 流通市值 <= 500亿:
    类型 = "板块中军"
    策略 = "板块核心，可打板可低吸"
```

---

### 3. 小盘情绪龙（短线连板型）

**定义**：
- 流通市值 < 200亿
-  preferably 50-150亿最佳
- 游资主导，情绪标杆

**特征**：
| 维度 | 特征 |
|------|------|
| 涨停时间 | 最早（09:25-09:35），资金抢筹 |
| 封单特点 | 封单比高（>10%），封板坚决 |
| 连板能力 | 最强，可5板+，短线核心 |
| 带动效应 | 情绪标杆，激活整个板块 |
| 参与资金 | 游资、散户、量化 |
| 操作策略 | 打板为主，快进快出 |

**案例**：
- 各种3-5板连板妖股（通常<100亿）
- 题材启动期的先锋龙
- 板块情绪转折的日内龙

**识别标准**：
```python
if 流通市值 < 200亿:
    类型 = "小盘情绪龙"
    策略 = "打板为主，快进快出"
    if 50亿 <= 流通市值 <= 150亿:
        备注 = "最佳体量"
```

## 六、代码实现框架

```python
def classify_leader_by_size(stock: dict) -> dict:
    """
    基于体量维度分类龙头
    
    Args:
        stock: 包含市值、时间、连板数的股票数据
    
    Returns:
        分类结果
    """
    market_cap = stock['float_market_cap']  # 流通市值（亿）
    
    # 1. 按市值分类
    if market_cap > 500:
        size_type = "权重龙头"
        strategy = "趋势跟随，不追高，回调低吸"
        risk_level = "低"
        return_expect = "10-30%"
        fit_for = "稳健型"
    elif 200 <= market_cap <= 500:
        size_type = "板块中军"
        strategy = "板块核心，可打板可低吸"
        risk_level = "中"
        return_expect = "30-50%"
        fit_for = "平衡型"
    else:  # < 200亿
        size_type = "小盘情绪龙"
        strategy = "打板为主，快进快出"
        risk_level = "高"
        return_expect = "50-100%+"
        fit_for = "激进型"
    
    # 2. 细化特征
    time_feature = classify_time_feature(stock['anomaly_time'])
    seal_expect = classify_seal_expect(size_type)
    continuous_expect = classify_continuous_expect(stock['continuous_zt'], size_type)
    capital_type = classify_capital_type(size_type)
    
    return {
        'size_type': size_type,
        'strategy': strategy,
        'risk_level': risk_level,
        'return_expect': return_expect,
        'fit_for': fit_for,
        'time_feature': time_feature,
        'seal_expect': seal_expect,
        'continuous_expect': continuous_expect,
        'capital_type': capital_type
    }


def classify_time_feature(anomaly_time) -> str:
    """分类涨停时间特征"""
    time_str = str(anomaly_time)
    if '09:25' in time_str or '09:30' in time_str:
        return "早"
    elif '09:3' in time_str or '09:4' in time_str or '09:5' in time_str or '10:' in time_str:
        return "中"
    else:
        return "晚"


def classify_seal_expect(size_type: str) -> str:
    """分类封单预期"""
    mapping = {
        "权重龙头": "大",
        "板块中军": "中",
        "小盘情绪龙": "小"
    }
    return mapping.get(size_type, "中")


def classify_continuous_expect(continuous_zt: int, size_type: str) -> str:
    """分类连板预期"""
    if size_type == "权重龙头":
        return "1-2板"
    elif size_type == "板块中军":
        return "2-3板"
    else:  # 小盘情绪龙
        if continuous_zt >= 2:
            return "5板+"
        else:
            return "2-3板"


def classify_capital_type(size_type: str) -> str:
    """分类资金类型"""
    mapping = {
        "权重龙头": "机构主导",
        "板块中军": "机构游资合力",
        "小盘情绪龙": "游资主导"
    }
    return mapping.get(size_type, "未知")
```
