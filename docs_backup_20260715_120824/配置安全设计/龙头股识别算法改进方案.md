# 龙头股识别算法改进方案

## 当前问题

**现象**：32只首次涨停的AI应用与智能体股票，AI分析没有识别出龙头股

**根本原因**：
1. 当前prompt只要求分析单只股票的涨停原因，没有横向比较
2. 缺乏"板块内地位"判断维度
3. 没有涨停时间序列分析（谁先涨停谁后涨停）
4. 缺乏封单强度、换手率等盘口数据

---

## 龙头股识别的真实逻辑（历史经验）

### 1. 时间优先原则
```
同板块内，先涨停的是龙头，后涨停的是跟风
- 10:00:00 涨停 → 龙头候选
- 10:05:00 涨停 → 跟风（受龙头带动）
- 10:30:00 涨停 → 补涨（板块已确认强势）
```

### 2. 封单强度原则
```
封单金额 / 流通市值 比率越高，龙头地位越稳
- 封单比 > 10% → 绝对龙头
- 封单比 5-10% → 强势龙头
- 封单比 < 5% → 弱势或跟风
```

### 3. 连板基因原则
```
历史连板能力决定龙头气质：
- 近30日有过连板 → 龙头基因
- 股性活跃（常涨停）→ 受资金青睐
- 首次涨停且历史活跃 → 潜力龙头
```

### 4. 板块贡献度原则
```
对板块情绪带动的贡献：
- 涨停后板块内其他股票跟风上涨 → 龙头确认
- 涨停时板块尚无其他涨停 → 开拓者（高风险高回报）
- 涨停时板块已有多个涨停 → 跟风补涨
```

### 5. 市值与流通性原则
```
- 流通市值50-200亿：最佳龙头体量
- 太小（<30亿）：容易被控盘，持续性差
- 太大（>500亿）：拉升难度大，难成短线龙头
```

---

## 真实龙头vs补涨vs跟风的区别

| 维度 | 真龙头 | 补涨 | 跟风 |
|------|--------|------|------|
| **涨停时间** | 板块内最早 | 板块确认后 | 板块高潮时 |
| **封单强度** | 强（封单比>5%） | 中等 | 弱（反复开板）|
| **连板预期** | 高（2-3板） | 中（1-2板） | 低（首板） |
| **带动效应** | 带动板块 | 跟随板块 | 被动上涨 |
| **次日溢价** | 高开高走 | 高开低走/平开 | 低开低走 |
| **历史股性** | 活跃，常涨停 | 一般 | 冷门 |
| **消息纯度** | 核心受益 | 间接受益 | 沾边概念 |

## 改进方案设计

### 方案A：增强现有Prompt（推荐）

在现有涨停分析基础上，增加板块横向比较：

```python
# 新增字段
ENHANCED_ZTB_STRUCTURE = """{
    "股票名称": "",
    "股票代码": "",
    "涨停时间": "",
    "板块内地位": "龙头/补涨/跟风/独立",
    "地位判定依据": [
        "涨停时间排名：本板块第X只涨停",
        "封单强度：封单金额X万，占流通市值X%",
        "历史股性：近30日涨停X次，最高连板X板",
        "带动效应：涨停后板块内X只跟涨"
    ],
    "龙头潜力评分": 0-100,
    "连板预期": "高/中/低",
    "次日溢价预期": "大幅高开/小幅高开/平开/低开",
    ... 原有字段 ...
}"""
```

**Prompt增强要点**：
1. 提供同板块其他涨停股票列表（代码、名称、涨停时间）
2. 要求AI比较后判定地位
3. 增加"龙头潜力评分"维度

### 方案B：独立龙头股识别模块

```python
def identify_leaders(zt_stocks: list) -> dict:
    """
    从涨停股票中识别龙头股
    
    输入: [{
        'code': '300001',
        'name': '特变电工',
        'zt_time': '10:00:00',
        'block': 'AI应用',
        'seal_amount': 50000000,  # 封单金额
        'float_market_cap': 1000000000,  # 流通市值
        'history_zt_count': 5,  # 近30日涨停次数
        'max_continuous': 2,  # 历史最高连板
    }]
    
    输出: {
        'leaders': [...],  # 龙头股列表
        'supporters': [...],  # 补涨股列表
        'followers': [...],  # 跟风股列表
    }
    """
    # 1. 按板块分组
    blocks = group_by_block(zt_stocks)
    
    for block, stocks in blocks.items():
        # 2. 计算各项指标
        for stock in stocks:
            stock['score'] = calculate_leader_score(stock, stocks)
        
        # 3. 排序识别
        sorted_stocks = sorted(stocks, key=lambda x: x['score'], reverse=True)
        
        # 4. 分类
        leaders.append(sorted_stocks[0])  # 最高分是龙头
        supporters.extend(sorted_stocks[1:3])  # 2-3名是补涨
        followers.extend(sorted_stocks[3:])  # 其余是跟风
```

**评分算法**：
```python
def calculate_leader_score(stock, all_stocks_in_block):
    score = 0
    
    # 1. 涨停时间排名（权重40%）
    time_rank = get_time_rank(stock, all_stocks_in_block)
    score += (1 - time_rank / len(all_stocks_in_block)) * 40
    
    # 2. 封单强度（权重25%）
    seal_ratio = stock['seal_amount'] / stock['float_market_cap']
    score += min(seal_ratio * 100, 25)  # 封顶25分
    
    # 3. 历史股性（权重20%）
    history_score = min(stock['history_zt_count'] * 2 + stock['max_continuous'] * 3, 20)
    score += history_score
    
    # 4. 市值适中度（权重15%）
    cap = stock['float_market_cap'] / 1e8  # 转为亿
    if 50 <= cap <= 200:
        score += 15
    elif 30 <= cap < 50 or 200 < cap <= 500:
        score += 10
    else:
        score += 5
    
    return score
```

### 方案C：AI+规则混合识别

结合方案A和方案B的优点：
1. 先用规则算法计算初步评分
2. 将评分数据喂给AI，让AI做最终判定
3. AI可以结合消息面、板块纯度等难以量化的因素
