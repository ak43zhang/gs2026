# 龙头股识别优化方案v3 - 展示层优化（不修改数据）

## 核心需求

1. **AI已定义龙头** → 保留所有AI定义的role，不做任何修改
2. **AI未定义龙头** → 只在展示时按简化版规则显示，**不修改数据库中的role**
3. **市值阈值** → 放到AI提示词中，让AI去分析计算

---

## 一、方案概述

**本质**：这是一个**前端/展示层**优化，不是数据层优化

**影响范围**：
- ✅ 修改：前端展示逻辑、AI提示词
- ❌ 不修改：数据库role字段、后端计算逻辑

---

## 二、实施位置

### 方案A：前端展示时动态计算（推荐）

在 `monitor.html` 或数据查询API中，展示前动态计算显示用的role

```javascript
// 前端展示逻辑
function getDisplayRole(stock, mainlineStocks) {
    // 1. 检查AI是否已定义龙头
    const hasAiLeader = mainlineStocks.some(s => 
        s.role === '权重龙头' || s.role === '板块中军' || 
        s.role === '小盘情绪龙' || s.role === '龙头'
    );
    
    if (hasAiLeader) {
        // AI已定义龙头，直接显示数据库中的role
        return stock.role;
    }
    
    // 2. AI未定义龙头，按简化版规则计算展示role
    const sortedStocks = mainlineStocks.sort((a, b) => 
        a.anomaly_time.localeCompare(b.anomaly_time)
    );
    const rank = sortedStocks.findIndex(s => s.stock_code === stock.stock_code);
    
    if (rank === 0) {
        // 第1只：根据市值判断展示role
        const marketCap = stock.circulating_market_cap || 0;
        if (marketCap > 500) return '权重龙头(估算)';
        if (marketCap >= 200) return '板块中军(估算)';
        return '小盘情绪龙(估算)';
    } else if (rank <= 2) {
        return '补涨(估算)';
    } else {
        return '跟风(估算)';
    }
}
```

### 方案B：后端API返回时计算（备选）

在 `data_service.py` 的查询API中，返回数据前添加 `display_role` 字段

```python
def get_display_role(stock, mainline_stocks):
    """
    计算展示用的role（不修改数据库）
    """
    # 检查AI是否已定义龙头
    has_ai_leader = any(
        s.get('role') in ['权重龙头', '板块中军', '小盘情绪龙', '龙头']
        for s in mainline_stocks
    )
    
    if has_ai_leader:
        # AI已定义，直接返回原role
        return stock.get('role')
    
    # AI未定义，按简化版规则计算
    sorted_stocks = sorted(mainlineStocks, key=lambda x: x['anomaly_time'])
    rank = next((i for i, s in enumerate(sorted_stocks) 
                 if s['stock_code'] == stock['stock_code']), -1)
    
    if rank == 0:
        market_cap = stock.get('circulating_market_cap', 0)
        if market_cap > 500:
            return '权重龙头(估算)'
        elif market_cap >= 200:
            return '板块中军(估算)'
        else:
            return '小盘情绪龙(估算)'
    elif rank <= 2:
        return '补涨(估算)'
    else:
        return '跟风(估算)'
```

   - 业绩可验证性

   - 涨停时间：越早越好
   - 连板基因：continuous_zt越高越好

   - 特征：涨停较晚、封单大、趋势性强

   - 例：宁德时代、贵州茅台、中芯国际
   
   【板块中军】200亿 ≤ 流通市值 ≤ 500亿
   - 特征：涨停中等、机构游资合力、板块核心
   - 策略：可打板可低吸
   - 例：科大讯飞、北方华创
   
   【小盘情绪龙】流通市值 < 200亿
   - 特征：涨停最早、连板最强、情绪标杆
   - 策略：打板为主，快进快出
   - 例：各种3-5板连板妖股

4. 带动效应（权重25%）
   - 该股票涨停后是否激活板块
   - 后排补涨是否出现

    }

【重要规则】

1. 必须选出1只真龙头（权重龙头/板块中军/小盘情绪龙三选一）
2. 如果多只股票都很强，优先选择：
   - 逻辑最正宗的

## 四、数据需求

### 需要获取的字段

```sql
SELECT 
    a.id,
    a.stock_code,
    a.stock_name,
    a.anomaly_time,
    a.continuous_zt,
    a.circulating_market_cap,  -- 流通市值（亿）
    r.role,                     -- AI定义的role
    r.evidence,
    r.confidence_contribution
FROM stock_anomaly_mainline_rel r
JOIN stock_anomaly a ON r.anomaly_id = a.id
WHERE r.mainline_id = :mainline_id
ORDER BY a.anomaly_time
```
