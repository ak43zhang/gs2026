# 统一字段回填引擎设计方案 v1.0

## 1. 背景与问题

### 1.1 现状

由于系统迭代多次新增字段，历史数据表 `monitor_zq_sssj_YYYYMMDD` 存在字段不统一的问题：

| 日期 | 预估字段数 | 缺失字段 |
|------|-----------|----------|
| 20260706 | ~10 | amount_rank, min1_*, slope_*, mkt_*, ext_indicators, min1_amount_rank |
| 20260707 | ~12 | slope_*, mkt_*, ext_indicators, min1_amount_rank |
| 20260708 | ~14 | mkt_*, ext_indicators, min1_amount_rank |
| 20260709 | ~24 | min1_amount_rank, ext_indicators(部分) |
| 20260710 | 27 | min1_amount_rank（刚新增） |

### 1.2 目标

1. **统一回填**：一个脚本处理所有历史表，自动检测缺失字段并补全
2. **逻辑一致**：回填计算与 `monitor_bond.py` 实时计算**完全相同**
3. **高效执行**：利用 pandas 向量化操作，避免逐行迭代
4. **易于扩展**：新增字段只需在注册表添加一条，无需修改引擎逻辑

## 2. 实时计算逻辑参考（来源：monitor_bond.py）

### 2.1 计算顺序（每tick执行）

```
monitor_bond.py 主循环 deal_zq_works():
  │
  ├─ 1. 获取行情数据 df_now（~330只债券）
  ├─ 2. amount_rank = amount.rank(ascending=False, method='min')
  ├─ 3. compute_min1_fields(df_now, time_full)
  │     ├─ min1_change_pct = change_pct - base_change_pct
  │     ├─ min1_amount = amount - base_amount
  │     └─ min1_amount_rank = min1_amount.rank(ascending=False, method='min')
  ├─ 4. compute_indicators(df_now, date_str, engine)
  │     ├─ slope_short: 20点窗口线性回归斜率
  │     ├─ slope_long: 100点窗口线性回归斜率
  │     ├─ peak_vol_bias: (amount - rolling_mean) / rolling_mean
  │     └─ high_distance: (high - price) / high
  ├─ 5. compute_market_indicators()
  │     ├─ mkt_slope_short: 全市场平均change_pct的短期斜率
  │     ├─ mkt_slope_long: 全市场平均change_pct的长期斜率
  │     ├─ mkt_peak_vol_bias: 全市场平均成交额偏离
  │     └─ mkt_high_distance: 全市场平均高点距离
  ├─ 6. compute_ext_indicators(df_now, time_full, date_str)
  │     ├─ weighted_slope_2m: 指数加权2分钟斜率（半衰期30秒）
  │     ├─ change_1m_pct: (price - price_1m_ago) / price_1m_ago * 100
  │     └─ price_acceleration: 当前斜率 - 上一周期斜率
  └─ 7. save_dataframe_async(df_now, table, time)
```

### 2.2 各字段详细计算逻辑

#### A类：同tick排名字段

| 字段 | 公式 | 依赖 | 特点 |
|------|------|------|------|
| `amount_rank` | `amount.rank(ascending=False, method='min')` | amount | 无状态，同tick独立计算 |
| `min1_amount_rank` | `min1_amount.rank(ascending=False, method='min')` | min1_amount | 无状态，同tick独立计算 |

#### B类：1分钟差值字段

| 字段 | 公式 | 依赖 | 特点 |
|------|------|------|------|
| `min1_change_pct` | `change_pct - base_change_pct` | change_pct | 有状态：每分钟首tick设基准 |
| `min1_amount` | `amount - base_amount` | amount | 有状态：每分钟首tick设基准 |

**基准规则**：
- 每分钟第1个tick：`base = 当前值`，`min1 = 0`
- 同分钟后续tick：`min1 = 当前值 - base`
- 冷启动（首次出现的bond）：`base = 当前值`，`min1 = 0`

#### C类：趋势斜率字段

| 字段 | 公式 | 窗口 | 特点 |
|------|------|------|------|
| `slope_short` | 线性回归斜率 | 20点(~60秒) | 有状态：deque滑动窗口 |
| `slope_long` | 线性回归斜率 | 100点(~300秒) | 有状态：deque滑动窗口 |
| `peak_vol_bias` | `(amount - mean(amount_window)) / mean(amount_window)` | 20点 | 有状态 |
| `high_distance` | `(high - price) / high` | 无 | 无状态 |

**斜率计算方法**：
```python
from scipy.stats import linregress
x = np.arange(len(window))
slope, _, _, _, _ = linregress(x, window)
```

#### D类：市场级字段

| 字段 | 公式 | 特点 |
|------|------|------|
| `mkt_slope_short` | 全市场平均change_pct的20点窗口斜率 | 有状态：全市场级deque |
| `mkt_slope_long` | 全市场平均change_pct的100点窗口斜率 | 有状态 |
| `mkt_peak_vol_bias` | 全市场平均成交额偏离 | 有状态 |
| `mkt_high_distance` | `mean(所有债券的high_distance)` | 无状态（依赖C类） |

**市场级计算**：
```python
# 每tick一个值（所有债券共享）
avg_change = df_now['change_pct'].mean()
mkt_buf_short.append(avg_change)  # deque(maxlen=20)
mkt_slope_short = linregress(x, list(mkt_buf_short)).slope
```

#### E类：扩展JSON字段

| 字段 | 公式 | 特点 |
|------|------|------|
| `weighted_slope_2m` | 指数加权线性回归（半衰期30秒，窗口2分钟/40点） | 有状态：per-bond deque |
| `change_1m_pct` | `(price - price_1m_ago) / price_1m_ago * 100` | 有状态：per-bond 1分钟前价格 |
| `price_acceleration` | `当前weighted_slope - 上一tick的weighted_slope` | 有状态 |

## 3. 回填引擎设计

### 3.1 核心架构

```
backfill_unified.py
  │
  ├─ FieldRegistry（字段注册表）
  │     声明式配置所有字段的元数据和计算方法
  │
  ├─ SchemaManager（表结构管理）
  │     检测缺失字段 → ALTER TABLE ADD COLUMN
  │
  ├─ ComputeEngine（计算引擎）
  │     按类别分组计算，维护状态缓冲区
  │
  └─ BatchWriter（批量写入器）
        高效UPDATE回写，每批1000行
```

### 3.2 字段注册表

```python
FIELD_REGISTRY = [
    # === A类：同tick排名 ===
    FieldDef('amount_rank', 'INT', category='rank',
             depends=['amount'],
             compute=lambda df: df['amount'].rank(ascending=False, method='min').astype(int)),
    
    FieldDef('min1_amount_rank', 'INT', category='rank',
             depends=['min1_amount'],
             compute=lambda df: df['min1_amount'].rank(ascending=False, method='min').astype(int)),
    
    # === B类：1分钟差值 ===
    FieldDef('min1_change_pct', 'FLOAT', category='min1',
             depends=['change_pct'],
             base_field='change_pct'),
    
    FieldDef('min1_amount', 'FLOAT', category='min1',
             depends=['amount'],
             base_field='amount'),
    
    # === C类：趋势斜率 ===
    FieldDef('slope_short', 'FLOAT', category='slope',
             depends=['price'],
             window=20),
    
    FieldDef('slope_long', 'FLOAT', category='slope',
             depends=['price'],
             window=100),
    
    FieldDef('peak_vol_bias', 'FLOAT', category='slope',
             depends=['amount'],
             window=20),
    
    FieldDef('high_distance', 'FLOAT', category='stateless',
             depends=['high', 'price'],
             compute=lambda df: (df['high'] - df['price']) / df['high']),
    
    # === D类：市场级 ===
    FieldDef('mkt_slope_short', 'FLOAT', category='market',
             depends=['change_pct'],
             window=20),
    
    FieldDef('mkt_slope_long', 'FLOAT', category='market',
             depends=['change_pct'],
             window=100),
    
    FieldDef('mkt_peak_vol_bias', 'FLOAT', category='market',
             depends=['amount'],
             window=20),
    
    FieldDef('mkt_high_distance', 'FLOAT', category='market_derived',
             depends=['high_distance']),
    
    # === E类：扩展JSON ===
    FieldDef('ext_indicators', 'JSON', category='ext_json',
             depends=['price', 'slope_short']),
]
```

### 3.3 计算引擎（与实时逻辑一致性保证）

**关键设计**：回填必须按时间正序逐tick处理，模拟实时状态积累。

```python
class ComputeEngine:
    def __init__(self):
        # 模拟实时的模块级缓存
        self.min1_base = {}          # B类：{bond_code: {field: base_value}}
        self.min1_last_minute = ''
        self.slope_buf_short = {}    # C类：{bond_code: deque(maxlen=20)}
        self.slope_buf_long = {}     # C类：{bond_code: deque(maxlen=100)}
        self.amount_buf = {}         # C类：{bond_code: deque(maxlen=20)}
        self.mkt_buf_short = deque(maxlen=20)   # D类
        self.mkt_buf_long = deque(maxlen=100)   # D类
        self.mkt_amount_buf = deque(maxlen=20)  # D类
        self.ext_price_buf = {}      # E类：{bond_code: deque(maxlen=40)}
        self.ext_prev_slope = {}     # E类：{bond_code: float}

    def process_tick(self, df_tick, tick_time):
        """处理单个tick（与实时compute链完全对应）"""
        # 1. amount_rank
        df_tick['amount_rank'] = df_tick['amount'].rank(ascending=False, method='min').astype(int)
        
        # 2. min1类字段
        self._compute_min1(df_tick, tick_time)
        
        # 3. slope类字段
        self._compute_slopes(df_tick)
        
        # 4. market类字段
        self._compute_market(df_tick)
        
        # 5. ext_indicators
        self._compute_ext(df_tick, tick_time)
        
        return df_tick
```

### 3.4 高效执行策略

```
全量回填流程（单日）：
  │
  ├─ 1. 检测 & ALTER TABLE（~100ms）
  │
  ├─ 2. SELECT * FROM table ORDER BY time（全表读入内存）
  │     130万行 × 27列 ≈ 300-500MB，约10-15秒
  │
  ├─ 3. 按time分组，逐tick处理（向量化计算）
  │     4000 ticks × 330 bonds ≈ 2-3分钟
  │
  └─ 4. 批量UPDATE回写（每1000行一commit）
        UPDATE table SET f1=:v1, f2=:v2 WHERE bond_code=:code AND time=:t
        130万行 ÷ 1000 = 1300次commit ≈ 2-3分钟
        
  总计：单日全字段回填约 5-8分钟
```

**优化手段**：
- 仅回填缺失字段（非全字段），大幅减少计算和写入量
- `--fields` 参数支持指定回填字段
- `--skip-existing` 跳过已有非空值的字段

### 3.5 命令行接口

```bash
# 回填单日全部缺失字段
python scripts/backfill_unified.py --date 20260710

# 回填日期范围
python scripts/backfill_unified.py --start 20260706 --end 20260710

# 只回填指定字段
python scripts/backfill_unified.py --date 20260709 --fields min1_amount_rank

# 只补缺失字段（已有数据的跳过）
python scripts/backfill_unified.py --date 20260706 --skip-existing

# 强制全量重算
python scripts/backfill_unified.py --date 20260710 --force
```

## 4. 与实时计算的一致性对照

| 计算环节 | 实时（monitor_bond.py） | 回填（backfill_unified.py） |
|----------|------------------------|---------------------------|
| 处理顺序 | 每3秒一个tick，时间正序 | 从DB读取后按time正序处理 |
| amount_rank | `df_now['amount'].rank(...)` | 相同 |
| min1基准 | 模块级 `_min1_base` dict | Engine实例 `self.min1_base` dict |
| min1分钟切换 | 比较 `time_full[:4]` 变化 | 相同逻辑 |
| slope计算 | 模块级 `_slope_buf_short` deque | Engine实例 `self.slope_buf_short` dict |
| slope窗口 | short=20, long=100 | 相同常量 |
| slope算法 | `scipy.stats.linregress` | 相同 |
| market聚合 | `df_now['change_pct'].mean()` | 相同 |
| market斜率 | 模块级 `_mkt_buf_short` deque | Engine实例 `self.mkt_buf_short` deque |
| ext加权斜率 | `bond_indicators.py` 指数权重 | 相同算法（半衰期30秒） |
| ext change_1m | 1分钟前价格差 | 相同 |
| ext acceleration | 当前slope - 上tick slope | 相同 |

**一致性保证机制**：
1. 回填引擎的计算函数**直接复用**实时代码中的算法（不重写）
2. 状态缓冲区的初始化和更新逻辑**完全相同**
3. 窗口大小、参数常量**统一定义**，避免硬编码不一致
4. 单元测试：对同一段数据，实时处理结果 vs 回填结果应完全相等

## 7. 风险与注意事项

1. **内存占用**：单日130万行全量加载约300-500MB，服务器需有足够内存
2. **回填期间不宜采集**：回填UPDATE可能与实时INSERT冲突，建议非交易时段执行
3. **slope冷启动**：前20-100个tick的slope值不准确（窗口未满），与实时行为一致
4. **min1冷启动**：每日第一个tick的min1值为0，与实时行为一致
5. **幂等性**：重复执行会覆盖已有值（`--skip-existing` 可避免）
