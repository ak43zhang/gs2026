# GS2026 内网穿透脚本

本目录提供 ngrok 内网穿透的一键启停脚本，用于从外网访问 GS2026 Web 看板。

## 脚本说明

| 脚本 | 作用 | 何时用 |
|------|------|--------|
| `启动ngrok.bat` | 开启外网访问，生成外网网址 | 要在外网访问时 |
| `停止ngrok.bat` | 关闭外网访问，恢复纯局域网 | 用完关闭时 |
| `查看网址.bat` | 查看当前外网网址和运行状态 | 忘记网址时 |

## 快速使用

1. **开启**：双击 `启动ngrok.bat` → 复制显示的 https 网址 → 手机浏览器打开
2. **查看**：双击 `查看网址.bat` → 显示当前网址
3. **关闭**：双击 `停止ngrok.bat` → 外网访问关闭

## 重要提示

- ⚠️ **网址会变**：ngrok 免费版每次重启，外网网址都会变化，需重新查看
- 🔵 **首次访问**：手机首次打开会显示 ngrok 蓝色警告页，点 **"Visit Site"** 进入
- 🟢 **不影响局域网**：无论开关，局域网 `http://192.168.0.102:8080` 始终可访问
- 🔴 **安全**：只穿透 8080 Web 端口，切勿穿透 3306(MySQL)/6379(Redis)

## 依赖

- `C:\ngrok\ngrok.exe`（v3.39.10+，已配置 authtoken）
- GS2026 Web 服务运行在 8080 端口
- Windows Defender 已对 `C:\ngrok` 加白名单
