# GS2026 内网穿透脚本

本目录提供 ngrok 内网穿透的一键启停脚本，用于从外网访问 GS2026 Web 看板。

## 文件说明

| 文件 | 类型 | 作用 |
|------|------|------|
| `启动ngrok.bat` | 双击运行 | 开启外网访问，生成外网网址 |
| `停止ngrok.bat` | 双击运行 | 关闭外网访问，恢复纯局域网 |
| `查看网址.bat` | 双击运行 | 查看当前外网网址和运行状态 |
| `ngrok_start.ps1` | 逻辑文件 | 启动核心逻辑（勿单独运行） |
| `ngrok_stop.ps1` | 逻辑文件 | 停止核心逻辑（勿单独运行） |
| `ngrok_view.ps1` | 逻辑文件 | 查看核心逻辑（勿单独运行） |

> **架构说明**：为解决 Windows 中文乱码问题，采用 `.bat 调用器 + .ps1 逻辑` 分离设计。
> `.bat` 用 GBK 编码且几乎无中文；中文逻辑全在 `.ps1`（UTF-8 BOM），由 PowerShell 正确渲染。
> **双击 .bat 即可，不要单独运行 .ps1。**

## 快速使用

1. **开启**：双击 `启动ngrok.bat` → 复制显示的 https 网址 → 手机浏览器打开
2. **查看**：双击 `查看网址.bat` → 显示当前网址
3. **关闭**：双击 `停止ngrok.bat` → 外网访问关闭

## 重要提示

- ⚠️ **网址会变**：ngrok 免费版每次重启，外网网址都会变化，需重新查看
- 🔵 **首次访问**：手机首次打开会显示 ngrok 蓝色警告页，点 **"Visit Site"** 进入
- 🟢 **不影响局域网**：无论开关，局域网 `http://192.168.0.102:8080` 始终可访问
- 🔴 **安全**：只穿透 8080 Web 端口，切勿穿透 3306(MySQL)/6379(Redis)

## 依赖

- `C:\ngrok\ngrok.exe`（v3.39.10+，已配置 authtoken）
- GS2026 Web 服务运行在 8080 端口
- Windows Defender 已对 `C:\ngrok` 加白名单

## 运行说明

- ngrok 以**真后台方式运行**（无窗口、任务栏也不显示），运行日志写入 `C:\ngrok\ngrok_runtime.log`
- 关闭启动脚本的窗口**不会**断开 ngrok；要断开请运行 `停止ngrok.bat`
